- D 구현 전 범위와 비교 조건을 고정했다. 기존 fresh ABC와 평가 입력의 해시 및 코드 사본을 로컬에 보존했다.
- 기존 ABC 480행의 저장된 하이브리드 순위를 새 후보 병합 코드에 넣어 후보·추가 관계·상태를 재현했다. 불일치 0행. 모델 재실행이나 참고 근거 접근 없이 확인했다.
- D 실행 전 다른 GPU 계산 작업이 존재함을 확인했다. 이를 중단하지 않으며 GPU 공유 관측을 저장한다. D-only 측정과 과거 ABC의 지연은 통제된 쌍별 비교가 아니다.
- D 관계 투영 테스트 4개와 채점 arm 테스트 2개를 추가했다. 기존 후보 제외·역할 순서·페이지 중복 후 8쪽 상한·두 사건 교대·모호성 대안·D/A corpus 검증을 확인했다.
- D 160문항 검색을 완료했다. 전체 결과 저장 이전에는 이번 D 채점을 위한 참고 근거를 열지 않았다. 문서 벡터는 새로 만들지 않았고 A 배열만 읽었다.
- 병합 전 엄격한 순위 비교에서 DEV-109의 BM25 33·34위 교환 1건을 발견해 첫 병합 시도를 중단했다. 질문·dense Top 50·hybrid Top 20은 모두 동일했고 BM25 페이지 집합도 같았다. 두 페이지의 기여도 집합과 정밀 합산값이 같음을 별도 진단했다. 이 차이를 지문에 남기고 실제 D가 공유해야 하는 hybrid20 불변을 확인한 뒤 결과를 병합했다. 검색 코드·질문·평가 기준은 바꾸지 않았다.
- 기존 ABC 480행+D160행=640행을 새 파일로 합쳤다. 모델·입력·A벡터·검색예산의 동일성을 검사한 뒤 원래 근거와 독립검수 보강 근거를 별도 출력에 채점했다.
- 보강 근거 기준 개발 D 후보65/70·최종61/70, 검증 후보66/70·최종62/70이다. A 대비 개발4개 개선·0개하락, 검증6개개선·1개하락. C보다 최종이 각 split에서1개높다.
- FRESH-VAL-005는 기존17위의 필수 페이지가 새관계4개와 합쳐21위로밀려 리랭커전에누락됐다. FRESH-DEV-005는 기존16위가24위로밀렸다. 이번에 병합정책을 고치지는 않았다.
