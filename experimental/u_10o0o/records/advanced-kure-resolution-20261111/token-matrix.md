# 추가 요청: 두 입력 상한의 결합 효과

사용자가 질문과 리랭커 입력을 함께 늘린 조건도 요청했다. 기존 다섯 조건의 입력·결과·지문은 보존하고 F(64/1024), G(128/1024)를 추가한다. A/B/F/G는 범위 필터, 검색기별20 후보, Top3+RRF, 원문 조회, 최종8쪽·8000토큰이 동일하다. 기존 D도 두 입력을 늘렸지만 전체 리랭커 순서까지 바뀌므로 이 추가 비교로 교란을 분리한다.

512/1024 리랭커 점수는 같은 질문·원문·설정이면 저장값을 재사용하고 없는 쌍만 계산한다. G/D의 후보·리랭커 점수는 정확히 공유하며 후속 순위만 다르다. F/A 후보도 동일하게 고정한다. 전체 지연은 7조건을 순환하며 30문항×3회 새로 측정한다. 품질 계산에서의 캐시 사용은 지연 측정에 적용하지 않는다.

추가 결과도 먼저 저장한 후 원래 정답으로 채점한다. 모든 조건의 실패에 같은 사후 대체 근거 검수표를 적용한다. 기준선 자동 변경·외부 API 호출은 없다.
