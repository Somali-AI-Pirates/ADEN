# 검증 기록

- 공통 Ruff와 이번 Python 5개 파일의 별도 Ruff·서식 검사 통과.
- `pytest -q tests experimental/u_10o0o/embedding_ablation/test_kure_resolution.py`: **291 passed, 15 subtests passed**. 공통 테스트와 새 실험 테스트 7개를 함께 실행했다.
- 실험 CLI `prepare/retrieve/score`, 추가 매트릭스 `retrieve/score/timing`, 7조건 보고서 생성 실행 완료. 두 CLI의 `--help`도 확인했다.
- 7조건×280문항 = 1,960개 검색 문맥 저장. F/G는 기존 점수를 검증해서 재사용하고 누락된 1,024토큰 리랭킹 쌍 56개만 새로 계산했다. 품질 계산의 재사용과 온라인 지연 측정을 구분한다.
- 동일성 확인: B/C 리랭커 전체 후보·점수, C/D 후보, A/F 후보, B/G 후보, D/G 리랭커 전체 후보·점수가 각각 280/280 동일했다.
- 입력·기존 결과·모델 실행 코드 지문 검사 통과. 최종 8쪽·8,000토큰 예산을 전체 문항에서 확인했다.
- 사후 검수 59개 고유 문항의 판정 기록을 확인했다. 승인된 대체 인용은 복원 원본에 존재하며 실제 반환 문맥에도 포함되는 경우에만 점수를 부여한다. HG 대체 근거 묶음 10개는 구성 페이지가 같은 사건인지 추가 검사했다.
- 온라인 630회 측정 문맥을 저장된 최종 페이지에서 다시 조립하여 지문 630/630 일치. 품질 배치와 온라인 단건의 문맥 차이 18회(고유 조건·문항 6쌍)에서 원래 점수와 사후 검수 통과 여부 변화는 0회였다.
- 보고서·검수표·설계·과정 링크 및 표의 분모를 점검했다. 원문·정답 인용은 로컬 artifacts에만 보존한다.

이번 작업은 자체 리뷰했다. 이 별도 대화의 지침이 하위 에이전트 사용을 금지하므로 독립 리뷰는 하지 않았다. 사람 검수·미사용 검증 완료로 주장하지 않는다. 외부 API 호출, 문서 벡터 재생성, 기존 기준선 자동 교체, 커밋·푸시는 하지 않았다. 개인 실험은 배포 패키징 대상이 아니므로 패키지 빌드는 실행하지 않았다.
