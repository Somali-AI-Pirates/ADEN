# 공식 7문항 근거 누락 단계

2026-11-13. [공식 문맥 판정](official-context-review.json)에서 FP32·BF16 모두 답변 근거가 부족했던 7문항을 다시 확인했다. 공식 질문과 채점 지침으로 필요한 판단을 정한 뒤, 저장된 공통 후보 20쪽과 두 정밀도의 최종 문맥을 원문으로 복원해 대조했다. 지정 쪽이 없어도 같은 사실과 적용 조건을 확인할 수 있으면 인정했다. 원문에서 복원한 표의 행·열 관계도 함께 읽었다.

## 결과

| 후보 20쪽에 필요한 근거가 일부 없음 | 3 | 3 | AS-ADD02, AS-ADD06, AS-ADD09 |

## 검증 범위

- [문맥 판정에 기록한 입력 지문](official-context-review.json) 4개를 확인했다. 저장된 후보는 문항마다 서로 다른 20쪽이었고 두 리랭킹 결과는 같은 후보를 사용했다. 두 정밀도의 최종 문맥 14개를 실제 조립 함수로 복원해 원본 재생의 출처 순서·토큰 수·SHA-256과 모두 일치함을 확인했다.
- 최종 단계에서 탈락한 4문항은 진단용으로만 충분한 근거를 기존 후보에서 골라 앞에 배치했다. 두 정밀도 모두 각 문항의 필요한 근거를 8쪽에 담았고, 토큰 수는 AS-DEV02 6,148, AS-DEV06 6,013, AS-DEV09 5,898, AS-ADD05 5,521이었다. 실제 검색 결과와 채점 점수에는 이 배치를 반영하지 않았다.
- 이 판정은 [재생 코드](replay.py)로 실행한 단일 검색의 후보와 최종 원문에 대한 AI 자체 검토다. 후보 누락 3문항이 개별 BM25·벡터 결과에서부터 빠졌는지, RRF에서 20개로 줄일 때 빠졌는지는 이 재생에 개별 검색 순위가 저장되지 않아 확인할 수 없다. 실제 답변 생성과 제품의 후속 도구 호출은 평가 범위 밖이다.
