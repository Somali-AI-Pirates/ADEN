## 검색과 실제 문맥

인용문 Recall은 문항별로 원본과 페이지가 같은 완전 일치 인용문의 비율을 구해 평균했다. 근거 그룹 충족률은 각 그룹에서 인용문이 하나 이상 전달된 문항의 비율이다. 지연은 같은 RTX 5060 Laptop GPU에서 워밍업 후 공식 16문항으로 측정한 검색·재정렬·문맥 조립의 p95다.

| 조건 | 인용문 Recall 추가 280 | 공식 58 | 파일럿 40 | 공식 문맥 평균 토큰 | 검색 p95 |
|---|---:|---:|---:|---:|---:|
| 기준선 | 88.61% | 75.29% | 88.75% | 3,754 | 325ms |
| 제목 보너스 | **93.35%** | **79.31%** | **91.25%** | 3,752 | 390ms |
| 표 행 문맥 | 77.51% | 57.18% | 88.75% | 3,512 | 321ms |
| 근거 역할 | 88.61% | 75.29% | 88.75% | 3,754 | 319ms |
| 역할 보강 | 88.61% | 75.29% | 88.75% | 3,754 | 343ms |
| 유효 시점 | 88.25% | 75.29% | 86.88% | 3,780 | 330ms |

- 제목 보너스의 문서 Recall@8은 추가 **89.11 → 94.02%**, 공식 **86.64 → 88.07%**, 파일럿 **92.50 → 95.00%**였다. 후보 문서 Recall@20은 추가 **92.50 → 96.99%**, 공식 **91.24 → 90.23%**, 파일럿 **100 → 100%**였다. 공식 세트에서 후보 단계 회귀가 일부 있었고, 실제 문맥의 모든 근거 그룹 충족은 **30/58 → 34/58**이었다.
- 표 행 문맥은 추가 54개, 공식 34개의 최종 문맥을 바꿨다. 공식 평균 문맥은 약 241토큰 줄었고 인용문 Recall은 18.11%p 낮아졌다. 인용문 평가는 완전 일치여서 행의 구조를 바꾸는 경우 일부 의미 보존을 놓칠 수 있다. 파일럿에서는 같은 조건을 통과한 문맥 변경이 0건이었다.
- 초기 역할 규칙은 문맥 1건만 바꾸고 보강 후보는 0건이었다. 전체 본문의 어휘를 역할 단서로 사용하면 한 페이지가 여러 역할을 충족한다고 판단할 수 있어, 이 게이트는 별도 보완 검증 대상으로 두었다.
- 초기 유효 시점 조건은 100건의 계산 시도와 23건의 날짜 비교 시도가 모두 보류됐다. 문맥에 표시한 주석의 효과와 계산 기능 자체의 지원 범위를 구분한다.

아래 Recall은 문항별 비율의 평균이다. 페이지와 인용문 지표는 기본 근거 기준이다. 필수 사실 Recall은 한 사실의 기본 인용문 묶음 전체 또는 검증된 대체 묶음 전체가 올바른 출처 쪽의 최종 문맥에 들어왔는지 평가한다. 전체 충족률은 모든 필수 사실의 근거가 들어온 문항 비율이다. 정답 생성률은 별도의 위 답변 표본으로 평가했다.

- 유효 시점 조건은 계산 시도 2,928건과 기간 비교 시도 65건을 모두 보류했다. 주석을 붙인 문맥의 근거 손실은 확인했으며, 계산과 날짜 판정이 가능한 실제 자료에서의 효과는 남아 있다.

## 벤치 결론

**본문 Bigram-ID BM25에 제목 보너스만 추가하는 구성을 다음 검증 후보로 선정한다.** 후보 20쪽, KURE 상위 3쪽과 BM25 순서, 최대 8쪽과 4,000토큰을 유지했다. 겹침이 없는 증강 세트에서 모든 근거를 확보한 비율이 **67.79% → 76.99%**였고, 파일럿 답변 24문항의 판단 통과도 **19 → 20건**이었다. 공식 16문항의 초기 로컬 지연 측정에서는 p95가 **325 → 390ms**로 늘었다. 지연은 동일 GPU의 소표본이며 전체 서비스 지연을 포함하지 않는다.

표 행 변환과 유효 시점 주석은 이번 형태로 채택을 보류한다. 역할 순서와 역할별 추가 검색은 전체 근거 충족 개선이 작고, 기존 세트의 역할 보강은 회귀했다. 제목 보너스의 제품 적용 판단은 사람 검수를 거친 문항에서 답변 품질과 지연을 확인한 뒤 내린다.

저장소 루트의 가상환경에서 Advanced 원본 PDF, 복원 페이지 캐시, 로컬 KURE 모델과 CUDA를 준비한다. 전 페이지 증강 질문과 참고 파일은 원본 식별 정보를 포함해 로컬에 둔다. 각 실행에 새 결과 경로를 지정한다. [개인 실험 실행 안내](../../README.md#실행) · [전 페이지 증강 입력 설명](../../evaluation/advanced_full_coverage/README.md)

```bash
python -m app.ingestion.scripts.curate --datasets advanced \
  --output artifacts/u_10o0o/pattern-curation \
  --cache artifacts/u_10o0o/pattern-layout-cache
python -m experimental.u_10o0o.advanced_patterns \
  --output artifacts/u_10o0o/patterns-reproduction
python -m experimental.u_10o0o.advanced_pattern_full \
  --output artifacts/u_10o0o/full-coverage-reproduction
```

기존 340문항과 파일럿 40문항의 검색·문맥만 재실행하려면 위 기본 명령을 사용한다. 파일럿 답변까지 실행하려면 첫 벤치 명령에 `--live`를 붙인다. `advanced_pattern_focused`는 표 문맥 A/B와 유효 시점 재검증을, `advanced_role_refinement`는 역할 규칙의 보조 실험을 실행한다. `--live`는 `gpt-6-luna`로 실제 답변을 생성하고 채점한다. 전 페이지 증강 실행은 로컬 KURE만 사용한다.
