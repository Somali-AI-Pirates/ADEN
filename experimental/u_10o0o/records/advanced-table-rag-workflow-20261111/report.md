# TableRAG 단계 분리·중간 근거 보존 결과

하위 질문 검색 뒤 현재 스키마로 SQL을 생성하고, 별도 중간 답변의 인용을 검증해 다음 계획에 도구 결과로 전달했다. 질문별 필요 근거의 상태를 실행 중 관리하고 최종 포장 뒤 다시 확인했다. 기존 기준선과 이전 v5 결과는 보존했다.

**새 구성을 기준선으로 채택하지 않는다.** 이전 v5보다 원문 근거 충족이 낮고 지연이 늘었다. 기존 기준선 대비 답변 개선은 있었지만 모호한 두 후보의 해석은 해결되지 않았다. [판정과 해석](conclusion.md)

## 최종 원문 근거 비교

공식 60문항 중 페이지 근거가 있는 58개, 카테고리 220문항 중 범위 밖 대조 20개를 뺀 200개를 채점했다. 공식은 book_id+page로 허용 근거 그룹 적중을, 카테고리는 필수 사실과 대체 근거를 검사한다. 공식 페이지 적중만으로 답변의 의미적 완전성을 보장하지 않는다.

원문은 최대 8쪽, 답변용 근거 JSON은 총 8,000토큰이다. 중간 답변의 검증 인용과 SQL 결과는 출처 참조로 추가 보존한다. 전체 출처 수는 8개를 넘을 수 있으므로 원문 8쪽 점수와 추가 인용 반영 점수를 분리한다. 추가 인용 점수에는 SQL 출처 ID만 보고 원문 전체를 확보했다고 가산하지 않는다.

## 실행 중 근거 확인

실행 중 모두 충족으로 판단한 문항은 211개다. 그중 사후 참고 근거가 충족되지 않은 문항은 15개다. 이 차이는 요구 항목의 누락·의미 판단 오류 또는 참고 근거와 표현의 차이를 포함하며, 기계적 출처 확인만으로 완전성을 증명하지 않는다.
인용/셀 검증에서 제외한 참조 또는 무근거 충족 선언은 27건이다. 예산으로 빠진 중간 주장은 0건이며, 이 경우 최종 상태도 낮춘다.

## 해석 범위

논문의 검색→SQL→중간 답변 순서를 맞추고 ADEN용 필요 근거 확인을 추가했다. SQLite·하이브리드·HG 조회·IS 추가 표 색인·한국어 모델·원문 예산은 프로젝트의 선택이다. 페이지를 넘는 논리 표 자동 복원이나 모든 기록의 모집단 완전성을 보장하지 않는다. 같은 평가 세트의 개발 비교이며 미사용 검증 세트에 일반화됐다고 주장하지 않는다. 단계 분리와 근거 우선순위·포장을 함께 바꾼 실험이므로 어느 하나의 단독 효과로 해석하지 않는다.

출처 인용의 실제 존재와 SQL 셀 일치는 코드로 검사하지만, 요청에 맞는 근거인지의 판단은 모델이다. 중간 답변을 보존해도 잘못된 해석까지 옳아지는 것은 아니므로 사후 오확정과 답변 오류를 함께 본다.

사용자가 허용한 부대 대화에서 자체 검토했다. 독립 에이전트 리뷰·기본 구성 교체·커밋·푸시는 하지 않았다.
