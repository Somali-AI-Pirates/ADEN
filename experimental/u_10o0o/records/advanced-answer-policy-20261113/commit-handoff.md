# 커밋 범위와 분리 검증

2026-11-13. 실험 완료 후 사용자가 이번 변경의 커밋과 Notion 기록을 요청했다. 이전 실행 계획의 커밋 제외는 최초 실험 범위이며, 이번 요청으로 로컬 커밋을 추가한다. 푸시·PR·배포는 요청하지 않았다.

## 포함한 변경

- 최종 답변 프롬프트 D, 모델의 사용자용 `reason`, 보류·충돌 진단 전달과 기록.
- 이에 필요한 HTTP/SSE·모델·서비스 테스트와 서버 설계 문서의 답변 정책 설명.
- 개인 비교 실행 코드와 A/B/C/D 전체 점수·변경 근거·실패 검토·검증 기록.
- 현재 다른 작업의 미커밋 평가 모듈에 의존하지 않도록 참고 페이지 부착 함수만 개인 실험의 `answer_policy_reference.py`로 고정했다. 제품은 개인 실험 모듈을 가져오지 않는다.

Langfuse 표시명, 검색 관측 저장, 공통 평가기 개편, 프레젠테이션과 다른 실험은 제외했다. 같은 파일의 다른 변경은 작업 트리에 보존했다.

## 커밋할 내용만 분리한 검사

기준 HEAD: `f1e8a2f`. 최초 실험의 기준 HEAD·작업 파일 지문은 [provenance.json](provenance.json)에 그대로 보존한다. 실험 당시 작업 트리 전체와 이번 커밋은 동일하지 않으며, 당시 평가 조건을 새 커밋 전체에서 다시 실행했다고 주장하지 않는다.

스테이징한 파일을 별도 로컬 경로로 내보내어 검사했다. 아래 검사 이후에는 이 인계 문서와 기존 보고서의 인계 링크만 추가했다.

실험 당시 공통 평가기에는 템플릿 치환 변경이 있었다. 위 비교는 그 변경만 재구성해 확인한 것이다. 현재 별도로 진행 중인 공통 평가기 개편과의 동등성 검사는 아니며, 그 개편은 이 커밋에 포함하지 않는다. 새 유료 호출이나 원점수 수정은 하지 않았다.

검사 스냅샷(인계 문서 추가 전)의 Git tree는 `671ee9dcc20049ea5545cc454fd781e25bd73715`다. 실행 증거는 로컬 `artifacts/u_10o0o/advanced-answer-policy-20261113/commit-check-0.log`부터 `commit-check-3.log`, `commit-lock.log`, `commit-build.log`, `commit-dist/`에 있다. 695개 통과는 다른 미커밋 변경까지 있던 최초 전체 트리의 결과이고, **이번 커밋 대상만 분리한 결과는 694개**다.

## 전달할 결론

같은 검색 근거에서 D의 공식 문항 Faithfulness는 0.796→0.864였으나, 사실 점수는 51/60→48/60, 판단 점수는 60/60→56/60이었다. 전체 품질 우위는 확인하지 못했다. D는 자유 서술 검색 요약의 원문 밖 사실 유입을 줄이고 사용자용 보류 이유를 구체화한 변경이다. 경계 문항의 19/19에는 별도 평가 불가 1건이 있으므로 20개 전체 성공으로 표현하지 않는다.

독립 리뷰는 사이드 대화의 제약으로 수행하지 않았고 자체 점검만 수행했다. 원격 추적 게시와 운영 적용은 하지 않았다. Notion에는 결과·한계·참고 자료·로컬 커밋 식별자를 요약하며 원문·답변 전문·인증값은 복사하지 않는다.
