# Advanced GPT-6 Luna 질문 해석 비교

규칙만 사용한 현재 개인 Advanced 설정과 GPT-6 Luna 해석을 추가한 설정을 비교했다. 각 질문의 최초 후보 20쪽과 KURE 순위는 두 설정이 공유한다. 기존과 같은 5:5 RRF, KURE 상위 3쪽, 최종 최대 8쪽·8,000토큰을 사용했다. 달라지는 부분은 해석에 따라 검증된 원본 쪽을 보강하고 배치하는 단계다.

카테고리별 220문항과 기존에 고정한 두 사건 별도 검증 30문항을 사용했다. 두 묶음은 질문 ID와 문장, 정답에 연결된 HG 사건이 겹치지 않는다. 실제 답변을 만들거나 답변 채점 모델을 호출하는 단계는 실행하지 않았다. [별도 검증 표본의 작성 기록](../advanced-pair-holdout-20261109/report.md)

## 프롬프트와 호출

원본 PDF에서 HG 기록 역할 다섯 종류의 머리말과 IS 업무 자료의 표시를 대조했다. 프롬프트는 해상 수입 운송 회사의 운영 지원팀이라는 역할을 두고, 컨테이너 예약·현장 사건·계약 비용·청구·수납 기록과 업무 규정의 범위를 설명한다. 모델은 질문의 절별 대상, 원문 그대로의 단서, 포함·제외 여부, 요청 기록과 검색 분기를 구조화한다. API 입력은 질문과 고정 지침으로 제한한다. 대상과 날짜·식별자·역할은 로컬 검증을 통과해야 적용된다. [고정 프롬프트와 연결 코드](../../advanced_luna_interpreter.py)

`gpt-6-luna`, 추론 `low`, Responses API의 구조화 출력을 사용했다. 호출당 출력 한도는 1,600토큰이고 SDK 요청 시간 제한은 10초다. 자동 재시도 없이 질문당 최대 한 번 요청했고 첫 연결 확인 응답은 본 평가에 포함했다. [GPT-6 Luna 모델 문서](https://developers.openai.com/api/docs/models/gpt-6-luna) · [구조화 출력 문서](https://developers.openai.com/api/docs/guides/structured-outputs?api-mode=responses)

## 결과

| 지표 | 220문항 규칙 | 220문항 Luna | 별도 30문항 규칙 | 별도 30문항 Luna |
| --- | ---: | ---: | ---: | ---: |
| 대상 전체 일치 | 108/120 | 108/120 | 5/28 | 5/28 |
| 개별 대상 재현율 | 128/140 | 128/140 | 17/52 | 18/52 |
| 대상별 역할 전체 일치 | 65/108 | 69/108 | 1/28 | 2/28 |
| 역할 정밀도 | 194/202 | 194/198 | 18/32 | 21/30 |
| 역할 재현율 | 194/234 | 194/234 | 18/93 | 21/93 |
| 오확정 / 자동 확정 문항 | 0/108 | 0/108 | 0/15 | 0/16 |
| 최종 필수 근거 전체 충족 | 170/200 | 170/200 | 7/30 | 8/30 |

대상 전체 일치는 정답 사건이 특정된 문항의 사건 집합을, 역할 전체 일치는 정답에 역할이 있는 문항의 `(사건, 역할)` 집합을 비교한다. 역할은 참고 인용의 출처 쪽을 검증된 HG 역할과 대조해 정했다. 정답에 사건이 없는 80문항과 대상 확인이 필요한 22문항은 자동 확정 여부를 별도로 확인했고 두 설정 모두 오확정이 없었다. 범위 밖 20문항은 최종 근거 충족률의 분모에서 제외했다.

카테고리 220문항에서 두 설정 모두 상황별 140/140, 업무 규정 17/20, 일상 표현 13/40이었다. 별도 표본에서는 `P11` 한 건이 개선됐다. 규칙은 한 사건에 역할 네 개를 연결했고, Luna는 두 사건에 역할을 두 개씩 연결했다. 보강 후보에는 두 설정 모두 필수 근거 네 개가 있었고 최종 문맥은 3개 → 4개를 담았다. 별도 표본의 개별 근거 충족은 77/127 → 80/127이었다.

Luna 열은 검증된 해석을 적용하고 나머지는 규칙 결과를 사용하는 전체 흐름의 점수다. Luna 결정은 32/250문항에서 적용됐고 218문항은 규칙 결과를 사용했다. 적용된 결정의 개별 대상 33개와 역할 54개는 모두 참고 근거와 일치했다. 이 적용 결과만으로 정답 사건 집합을 29/148문항에서 모두 찾았다.

규칙 경로를 사용한 218문항은 대상·역할 검증에서 확정할 출처를 찾지 못한 116문항, 일반 문서 분기 55문항, 모델이 보류한 32문항, 절 범위 등 검증 충돌 14문항, 시간 초과 1문항이었다.

## 호출과 지연

규칙 설정은 API 호출 0회, Luna 설정은 250회였다. 구조화 응답 249건을 받았고 시간 초과 1건은 규칙 경로로 처리했다. Luna API 호출 지연은 p50 **4.08초**, p95 **8.25초**였다. 공통 검색을 제외한 로컬 규칙 판단·문맥 구성은 p50 **1.52ms**, p95 **2.77ms**였다. 두 설정의 후보 순서는 250/250문항에서 일치했고, 카테고리 규칙 대조군은 이전 기본 실행의 후보·최종 문맥과 220/220문항에서 일치했다.

응답에서 확인된 입력 212,603토큰과 출력 85,785토큰을 표준 단가로 환산하면 약 **$0.064**다. 시간 초과 요청의 사용량은 응답에서 확인되지 않았다. [GPT-6 Luna 표준 단가](https://developers.openai.com/api/docs/models/gpt-6-luna)
