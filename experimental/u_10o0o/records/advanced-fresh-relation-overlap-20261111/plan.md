# D 고정, 관계 중복을 인정하는 E

## 범위 계약

D의 저장된 초기 하이브리드20·대상 사건·새 관계 페이지 목록(최대8)을 재사용한다. E는 같은 원문 검증 관계에서 초기 하이브리드와 겹친 페이지를 추가로 관계 순위에 포함한다. D가 고르지 않은 새 페이지는 추가하지 않는다. 두 목록에 있는 페이지의 RRF 점수를 각각 더하고, 결과 후보는 중복 없이20개로 제한한다. 기존 A/B/C/D와 기본검색·운영 API·원본 결과를 유지한다.

기존 도구는 D의 조회·선정 경로를 재사용한다. 별도 replay 명령은 D의 저장된 질문 해시/입력 지문/모델/예산을 검증하고 E 후보를 KURE로 한 번만 리랭킹한다. 문서 재임베딩·질문 임베딩 재계산·새로운 BM25 실행·외부 API·답변 생성은 하지 않는다. 실험용 E는 저장된 D로만 실행하며 기본 retrieve의 ABC 선택은 그대로다.

## 고정한 관계 순위 정의

1. 기존 D 선정 알고리즘으로 저장된 새 페이지 목록을 재현해 ID와 순서가 같은지 확인한다.
2. 기존 관계 증거 중 그 새 페이지와 초기20에 이미 있는 관계 페이지를 허용한다.
3. 기존 사건 순서와 기록 종류(unit.kind)·출처·기록ID 순서로 각 사건 목록을 만들고 사건별로 교대한다. 원문 페이지 중복을 제거한다.
4. 관계 목록은 새페이지 최대8 + 겹치는페이지 최대20, 최대28개다. 같은 페이지는 각 목록에서 한 번만 투표한다.
5. 같은 가중치 RRF, k60, 최종후보20, 원질문 KURE1회, 원문최대8쪽/8000토큰을 유지한다.

겹치는 페이지가 관계 순위에 들어오면 새 페이지의 관계 순위도 뒤로 이동할 수 있다. 사건별 교대에 따라 새 페이지들의 상대 순서가 달라질 수도 있다. 이는 전체 관계 순위를 인정하는 E 정책의 일부이며, 새 페이지 자체를 다시 선정하는 변경은 아니다. D의 고정된 새 페이지 목록과 E의 실제 관계 순위를 별도로 기록한다. 관계가 모호하거나 명시 코드가 없거나 3사건 이상이면 D와 같은 대안을 유지한다.

## 평가

기존 fresh160문항 전체를 사용하고 D/E 결과320행을 모두 저장한 뒤 별도 score에서 참고 근거를 읽는다. 주 비교는 독립검수 대체 출처 보강본을 두 조건에 공통 적용하며 원래 동결 근거 채점도 별도 보존한다. 모호성10문항/세트는 일반전체충족률에서 제외한다.

전체·유형별 후보/최종 충족, 페이지Recall/MRR/nDCG, 필수사실별 회복·유실을 기록한다. 사실 개수가 같아도 서로 다른 근거를 교환한 경우는 변화로 남긴다. D에서 후보부족이었던3개 초기RRF문항이나 최종선택4문항을 위한 별도 규칙은 추가하지 않는다. 문항ID를 검색 규칙에 넣지 않는다.

현재 세트는 반복 관찰한 회귀 세트이고 사람검수/미사용채택검증은 아니다. 개선을 보장하지 않는다. D와E의 지연은 계산범위가 다르므로 전체성능의 속도우열을 주장하지 않는다. 기존기준선 채택·커밋·푸시는 범위밖이다.
