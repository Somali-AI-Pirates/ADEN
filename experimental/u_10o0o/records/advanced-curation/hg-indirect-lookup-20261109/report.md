# Advanced HG 간접 식별

2026-11-09에 [정제 계획의 3단계](../../../advanced-curation-plan.md#3-간접-식별을-별도로-추가)를 실행했다. [2단계 명시 조회](../hg-explicit-lookup-20261109/report.md)를 대조군으로 두고, HG ID가 없는 질문의 최종 근거 보강만 추가했다. 두 조건은 같은 제목 보너스 검색·KURE 순위, 최종 최대 8쪽, `o200k_base` 4,000토큰을 사용했다.

2,730개 사건의 현장 사건 수신대장과 비용 청구 명세에서 화주·화물·장비 규격을 추출하고, 두 역할에 기재된 값이 일치하는지 확인했다. 질문에서 세 필드가 각각 하나씩 일치하고 전체 인덱스에서 그 조합이 유일할 때만 사건 후보를 얻었다. 해당 사건의 원본 쪽이 검색 상위 20개에 있을 때 다섯 역할을 앞에 놓고 기존 순위로 나머지를 채웠다. 단서 부족·복수 후보·검색 후보 미발견, 다른 식별자나 지원 범위 밖 날짜·제외 조건을 발견한 질문에는 대조군 경로를 적용했다.

보강 대상에서는 대조군과 변경군에 같은 실행의 검색 순위를 사용했다. 두 조건이 동일한 문항은 2단계 점수를 재사용했다. 참고 파일은 검색과 문맥 조립을 마친 뒤 채점에만 사용했다. [설정과 입력 지문](config.json) · [진행 로그](run.log)

## 비교 결과

전체 충족은 문항의 모든 필수 사실에 대해 기본 또는 검증된 대체 인용문 묶음 전체가 최종 문맥에 들어왔다는 뜻이다.

| 문항 묶음 | 명시 ID 조회 | 명시 + 간접 조회 |
|---|---:|---:|
| 겹침 없는 간접 식별 1,211문항 | 306/1,211 · 25.27% | **1,211/1,211 · 100%** |
| 겹침 없는 비용 사건 2,407문항 | 1,502/2,407 · 62.40% | **2,407/2,407 · 100%** |
| 겹침 없는 전체 6,103문항 | 5,197/6,103 · 85.15% | **6,102/6,103 · 99.98%** |
| 블라인드 관련 간접 식별 169문항 | 38/169 · 22.49% | 169/169 · 100% |
| 증강 전체 6,500문항 | 5,463/6,500 · 84.05% | 6,499/6,500 · 99.98% |

- 간접 식별 1,380문항 모두에서 검색 상위 20개로 사건을 확인했고, **1,380/1,380**에서 보강이 발동했다. 모두 정답 사건과 일치하고 다섯 역할의 원본 쪽이 최종 문맥에 들어왔다. 겹침 없는 묶음에서 전체 근거를 추가로 확보한 문항은 905건이고 회귀와 오연결은 0건이었다.
- 미발동 5,120문항의 점수는 2단계와 일치했다. 보강 대상 중 블라인드 관련 1문항의 재계산 대조군은 보관 기록과 문맥 토큰 수가 8개 차이 났다. 나머지 지표는 일치했고, 이 문항도 같은 실행의 순위를 두 조건에 공유했다.
- 겹침 없는 간접 식별의 인용문 Recall은 71.94%에서 100%로, 평균 문맥은 3,703에서 3,671토큰으로 바뀌었다. 워밍업한 로컬 GPU에서 간접 질문 16문항의 검색·KURE·조회·조립 p95는 198.4ms에서 198.0ms였다. 이 차이는 작은 표본에서 얻은 값이다.

3단계 통과 조건을 충족했다. 현장과 청구에 기재된 화주·화물·규격이 2,730개 사건마다 고유한 조합이었고, 이 자료에서는 화물 이름도 사건별로 고유했다. 이번 결과는 그런 단서가 그대로 들어간 증강 질문에서 확인한 **검색·문맥 근거 확보율**이다. 별칭·생략·동일 조합이 반복되는 질문과 실제 답변 품질은 별도 검증 범위다. 다음 단계는 사건 연결 규칙을 고정하고 역할별 필드를 정규화하는 작업이다. ## 재현과 검증

저장소 루트에서 [실험 스크립트](../../../advanced_case_indirect.py)를 실행한다. 1단계 인덱스와 2단계 기록, Advanced 정제본·페이지 캐시, 로컬 KURE nano와 CUDA를 사용한다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.advanced_case_indirect \
  --output artifacts/u_10o0o/advanced-curation/hg-indirect-lookup-replay
```

5개 사건의 원본 PDF 10쪽을 재추출해 화주·화물·규격과 원본 지문을 대조했다. 합성 입력으로 단서 누락·중복·미등록 조합·날짜 조건·검색 후보 누락을 확인했다. Ruff 저장소·실험 파일 검사와 형식 검사, pytest 143건과 하위 검사 9건을 통과했다. 문항 ID 6,500개, 겹침 397개, 문맥 상한과 집계 재계산을 대조했다. 전체 실행은 약 4분 18초였고 외부 API 호출은 0회였다.
