# Advanced 명시 HG 사건 조회

2026-11-09에 [정제 계획의 2단계](../../../advanced-curation-plan.md#2-명시-id로만-사건-페이지-보강)를 실행했다. 같은 제목 보너스 검색과 KURE 순위를 두 조건에서 공유한다. 조회 조건은 질문에서 HG ID 하나가 확인되고 [1단계 인덱스](../hg-case-sources-20261109/report.md)에 다섯 역할이 모두 있는 경우다. 이때 다섯 원본 쪽을 먼저 배치한 뒤 기존 순위의 나머지 쪽을 중복 없이 채운다. 둘 다 최종 최대 8쪽, `o200k_base` 4,000토큰으로 조립한다.

증강 6,500문항 중 조회가 발동한 문항의 제목 보너스 순위를 재계산해 두 조건에 함께 썼다. 발동하지 않은 문항은 변경군도 제목 보너스 순위를 사용하므로, 보관된 점수를 두 조건에 재사용했다. 질문·원본 페이지·사건 인덱스만으로 조회와 조립을 먼저 마쳤다. 평가 정답은 채점할 때 읽었고, 오연결은 조회한 사건 ID와 참고 사건 ID를 대조해 셌다. 문항별 산출물에는 지표와 평가 문항 ID만 보관한다. [실행 설정](config.json) · [진행 로그](run.log)

## 비교 결과

전체 충족은 문항의 모든 필수 사실에 대해 기본 또는 대체 인용문 묶음 전체가 최종 문맥에 들어왔다는 뜻이다.

| 문항 묶음 | 제목 보너스 | 제목 보너스 + 명시 ID 조회 |
|---|---:|---:|
| 겹침 없는 명시 HG 조회 대상 1,196문항 | 698/1,196 · 58.36% | **1,196/1,196 · 100%** |
| 겹침 없는 비용 사건 2,407문항 | 1,004/2,407 · 41.71% | **1,502/2,407 · 62.40%** |
| 겹침 없는 전체 6,103문항 | 4,699/6,103 · 76.99% | **5,197/6,103 · 85.15%** |
| 블라인드 관련 명시 HG 조회 대상 154문항 | 81/154 · 52.60% | 154/154 · 100% |
| 증강 전체 6,500문항 | 4,892/6,500 · 75.26% | 5,463/6,500 · 84.05% |

- 명시 HG 조회가 발동한 1,350문항 모두 다섯 원본 쪽이 실제 문맥에 들어왔다. 오연결은 0건이었다. 겹침 없는 묶음에서 498문항의 전체 근거를 새로 확보했고, 회귀는 0건이었다.
- 발동하지 않은 5,150문항은 양쪽 점수가 동일하다. 발동 문항에서 재계산한 대조군의 비교 지표도 보관된 대조군과 모두 일치했다.
- 겹침 없는 조회 대상의 인용문 Recall은 91.37%에서 100%로, 평균 문맥은 3,635토큰에서 3,733토큰으로 바뀌었다.
- 워밍업한 로컬 GPU에서 조회 대상 16문항의 검색·KURE·조회·조립을 측정했다. 제목 보너스와 조회 추가 조건의 p50은 각각 190.6ms와 190.7ms, p95는 192.8ms와 193.9ms였다. 전체 실행은 4분 12초였으며 외부 API 호출은 0회였다.

단계 통과 조건을 충족했다. 다음 비교에서는 이 명시 ID 설정을 대조군으로 유지하고 간접 식별만 추가한다. 겹침 없는 간접 식별 1,211문항의 전체 근거 충족률은 두 조건 모두 25.27%였다. 이번 100%는 증강 세트에서 명시 HG ID로 찾은 필수 근거 충족률이며, 답변 품질과 다른 양식은 별도 검증 범위다. [유형·겹침별 집계](summary.json) · [문항별 점수](questions.jsonl) · [지연 기록](latency.json)

## 재현과 검증

저장소 루트에서 [실험 스크립트](../../../advanced_case_lookup.py)를 실행한다. 기존 페이지 캐시, 로컬 KURE nano와 CUDA, 1단계 사건 인덱스가 필요하다. 결과에는 새 출력 경로를 사용한다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.advanced_case_lookup \
  --output artifacts/u_10o0o/advanced-curation/hg-explicit-lookup-replay
```

Ruff 저장소 검사와 실험 파일의 별도 Ruff·형식 검사, pytest 143건과 하위 검사 9건을 통과했다. 합성 질문으로 단일·미등록·복수 ID와 대조군 반환, 페이지 중복 제거를 확인했다. 6,500개 결과 ID와 겹침 397개, 8쪽·4,000토큰 제한, 문항별 점수와 집계의 일치를 확인했다.
