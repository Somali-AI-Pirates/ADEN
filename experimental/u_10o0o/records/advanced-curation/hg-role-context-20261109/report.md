# Advanced HG 원본 페이지와 출처 발췌 문맥

2026-11-09에 [정제 계획의 5단계](../../../advanced-curation-plan.md#5-출처를-보존하는-문맥-렌더링-비교)를 실행했다. [3단계에서 확인한 사건 조회](../hg-indirect-lookup-20261109/report.md)와 검색 순위를 두 조건에 동일하게 사용했다. 한 조건은 복원 페이지를 전달하고, 다른 조건은 같은 HG 쪽을 출처 발췌로 바꿨다. 두 조건 모두 동일한 문맥 조립기로 최대 8쪽, `o200k_base` 4,000토큰을 적용했다.

발췌에는 원본 머리말과 사건 설명, [정규화 레코드](../hg-role-facts-20261109/report.md)가 가리키는 표 행과 머리글·절 제목, 같은 쪽의 규칙 및 조건·예외 단서가 있는 주석을 담았다. Poppler 레이아웃의 원본 줄을 순서대로 쓰고, 생략된 원문 사이에는 표시를 넣었다. 규칙·행·머리글 위치를 검증할 수 없거나 발췌가 복원 페이지보다 짧지 않으면 그 쪽의 원본을 사용했다. 평가 참고 파일은 두 조건의 조립이 끝난 뒤 채점에만 읽었다. [실행 설정과 입력 지문](config.json) · [진행 로그](run.log)

## 비교 결과

6,500문항 중 HG 사건 조회가 발동한 2,730문항은 같은 검색 순위를 두 조건에서 재사용했다. HG 조회가 발동하지 않은 3,770문항에는 보관 점수를 두 조건에 사용했다. 재계산한 원본 문맥의 지표는 3단계 보관 결과와 일치했다.

| 지표 | 원본 페이지 | 출처 발췌 |
|---|---:|---:|
| 겹침 없는 HG 2,407문항의 필수 근거 전체 충족률 | 100% | 100% |
| 같은 HG 문항의 인용문 Recall | 100% | 100% |
| 같은 HG 문항의 최종 문맥 평균 토큰 | 3,702 | 3,852 |
| 같은 HG 문항의 최종 문맥 평균 쪽 수 | 7.44 | 7.85 |
| 겹침 없는 전체 6,103문항의 필수 근거 전체 충족률 | 99.98% | 99.98% |

겹침 없는 HG에서 다섯 역할 모두 필수 사실을 2,407/2,407건 보존했다. 겹치는 HG 323문항도 두 조건에서 모두 충족했다. 검색 순위의 페이지·문서 Recall은 동일했고 전체 근거 충족에서 개선이나 회귀가 없었다.

| 역할 | 발췌로 바꾼 쪽 / 전체 | 쪽당 본문 토큰 원본 → 발췌 |
|---|---:|---:|
| 비용 조건 약정 | 0/2,730 | 509.7 → 509.7 |
| 현장 사건 수신대장 | 2,639/2,730 | 460.0 → 398.3 |
| 계약 조건 대조 회신 | 0/2,730 | 433.5 → 433.5 |
| 비용 청구 명세 | 91/2,730 | 472.1 → 470.6 |
| 수납 및 미결 인계 | 2,366/2,730 | 385.0 → 369.6 |

HG 13,650쪽 중 5,096쪽을 발췌로 바꿨다. 나머지 8,554쪽은 본문 토큰이 줄어들지 않아 원본을 전달했다. 다섯 역할 쪽의 본문만 세면 사건당 평균 2,260에서 2,182토큰으로 약 3.5% 감소했다. 최종 조립에서는 확보한 공간에 뒤쪽 후보가 더 들어가 평균 문맥 토큰이 약 150개 늘었다.

**현재 조립 설정에서는 원본 페이지를 유지한다.** 발췌는 근거 보존 기준을 통과했고, 최종 문맥 토큰 절감 기준에는 미달했다. 본문 단위로 절감 폭이 큰 현장 기록과 수납 기록은 역할별 후속 비교 후보로 기록한다. 이번 평가는 증강 질문의 검색·문맥 근거를 대상으로 했다. [유형·역할별 집계](summary.json) · [문항별 지표](questions.jsonl)

## 재현과 검증

저장소 루트에서 [실험 스크립트](../../../advanced_role_context.py)를 실행한다. 기존 페이지 캐시, 원본 레이아웃 캐시, 역할별 정규화 산출물, 3단계 기록과 로컬 KURE nano·CUDA가 필요하다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.advanced_role_context \
  --output artifacts/u_10o0o/advanced-curation/hg-role-context-replay
```

합성 표에서 머리글·행·규칙·조건 보존과 중간 생략 표시를 확인했고, 확인할 수 없는 행이나 규칙이 있으면 원본 경로를 선택하는 것을 확인했다. Ruff 및 pytest 143건과 하위 검사 9건을 통과했다. 6,500개 문항 ID, 겹침 397개, 문맥 상한, 두 조건의 검색 순위 지표 일치와 집계 재계산을 확인했다. 전체 실행은 약 8분 21초였고 외부 API 호출은 0회였다.
