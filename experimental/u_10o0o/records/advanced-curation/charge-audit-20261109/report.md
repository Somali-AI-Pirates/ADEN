# Advanced 원문 비용 재계산 실험

2026-11-09에 [정제 계획의 6단계](../../../advanced-curation-plan.md#6-계산과-다른-양식은-각각-별도-실험) 중 비용 계산을 실행했다. HA 198사건의 계약·사건 증빙·정산 세 페이지를 연결했다. 각 사건에서 보관료와 반납지연료를 따로 판정했다. HG 2,730사건은 [4단계 요율 필드](../hg-role-facts-20261109/report.md)에서 계산에 필요한 통화 확인 상태를 집계했다. 평가 질문과 정답은 계산에 사용하지 않았다. [입력 지문과 실행 조건](config.json) · [집계](summary.json) · [실행 로그](run.log)

HA의 계산 대상은 같은 예약·장비가 세 원본에 나오고, 적용 장비 규격, 계약의 서명 확인란, USD와 장비 1대, 달력일 산입 규칙과 확정된 실제 날짜를 확인한 비용이다. 보관료는 실제 양하에서 적입 반출까지, 반납지연료는 적입 반출에서 실제 공장비 반납까지 센다. 시작일을 빼고 종료일을 포함한다. 무료일을 뺀 유료일을 두 연속 구간에 나누고 각 일 단가를 곱한다. 계산액과 정산 표의 기재액을 별도 필드에 두고 `Decimal`로 대조했다.

개정 표시가 있는 계약, 실제 증빙을 확인할 수 없는 기간, 정정·할인·무료기간 추가·면제 같은 조정은 보류했다. HG는 약정 표의 단가 통화를 확정할 근거가 부족해 보류했다. 정산액의 USD 표기를 약정 단가에 소급 적용하면 계약과 정산이 서로 다른 통화를 쓸 가능성을 검증할 수 없다.

| HG 보관료 | 2,730 | 0 | 0 | 2,730 |
| HG 반납지연료 | 2,730 | 0 | 0 | 2,730 |

HA 비용 396건 중 **254건(64.14%)을 계산했고 254건 모두 일치**했다. HA 181사건에서 한 비용 이상, 그중 73사건에서는 두 비용을 모두 대조했다. HA 보류 142건의 첫 보류 사유는 정정·조정 확인 필요 76건, 실제 증빙 미확인 32건, 개정 적용 확인 필요 34건이었다. 계산 적합 범위는 현재 HA 원본의 기본 요율 사례다. HG와 HA 예외에는 정산 근거를 전달하는 기존 경로를 유지한다.

## 재현과 검증

저장소 루트에서 [계산 스크립트](../../../advanced_charge_audit.py)를 실행한다. 원본에서 생성한 Advanced 정제 자료와 4단계 HG 역할별 필드가 필요하다. 상세 결과는 로컬 `artifacts/u_10o0o/advanced-curation/charge-audit-20261109/charges.jsonl`에 보관했다. 계산 대상마다 계약·사건·정산 출처와 사용한 표 행 ID가 있다.

```bash
uv run --no-sync python -m experimental.u_10o0o.advanced_charge_audit \
  --output artifacts/u_10o0o/advanced-curation/charge-audit-replay
```

두 비용을 모두 계산한 HA 5사건을 고정 방식으로 표본 추출해 원본 PDF 15쪽의 파일 지문, 머리말, 표 110행의 값과 줄 범위, 계약 규칙 5세트를 대조했다. 표본의 비용 10건은 하루씩 요율을 더하는 별도 계산으로 기재액까지 확인했다. 당일, 무료기간 경계, 첫 구간 경계, 둘째 구간, 날짜 역전, 비연속 요율 구간, 예정일 입력을 포함한 합성 검증 8건을 통과했다. 외부 API 호출은 0회였다.
