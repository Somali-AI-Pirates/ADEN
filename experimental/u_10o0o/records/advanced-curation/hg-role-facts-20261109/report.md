# Advanced HG 역할별 필드 정규화

2026-11-09에 [정제 계획의 4단계](../../../advanced-curation-plan.md#4-역할별-필드-정규화)를 실행했다. [1단계에서 확인한 HG 사건–출처 인덱스](../hg-case-sources-20261109/report.md)로 대상을 고정하고, 다섯 역할의 기존 정제 표 행을 읽었다. 저장 단위는 한 원본 기록에 기재된 사실 하나다.

| 기록 역할 | 원본 표 행 | 정규화 레코드 | 검토 필요 |
|---|---:|---:|---:|
| 비용 조건 약정 | 5,460 | 16,380 | 10,920 |
| 현장 사건 수신대장 | 13,650 | 13,650 | 0 |
| 계약 조건 대조 회신 | 16,926 | 16,926 | 273 |
| 비용 청구 명세 | 16,380 | 43,680 | 5,642 |
| 수납 및 미결 인계 | 16,380 | 16,380 | 0 |
| **합계** | **68,796** | **107,016** | **16,835** |

2,730개 사건의 13,650쪽을 처리했다. 대상 필드의 값과 상태를 정규화 레코드로 남겼다. 각 레코드에는 사건 ID, 역할, 필드 이름, 타입이 있는 값, 단위·통화·상태, 추출된 셀 표기와 열 이름, PDF·쪽·줄 범위를 기록한다. 같은 쪽의 규칙 ID는 근거를 찾기 위한 참조로 저장했다.

- **약정과 회신.** 기본 무료일과 유료 구간을 분리했다. 약정 구간 10,920건에는 원문에 통화가 없어 검토 상태를 붙였다. 회신의 대조 사항은 기재 텍스트로 보존하고, 승인 기록과 명시된 개정 효력일은 별개 필드로 저장했다. 개정 요율 273건은 통화와 구간이 확인되지 않아 원문 표기를 검토 대상으로 남겼다.
- **현장.** 실제 양하·반출·반납, 반납 예약 예정, 전산 입력 날짜를 서로 다른 필드에 넣었다. 실제 지정 반납일을 확인할 수 없는 273건은 인수증 미수신 182건과 지정 외 야드 반입증만 있는 91건으로 구분했다.
- **청구와 수납.** 산입·무료·유료일과 청구액, 무료 추가·상한·정액 감액·면제, 거래 합계·수납·잔액을 구분했다. 통화가 없는 청구 조정값 5,642건에는 검토 상태를 붙였다. 수납액이 명시적으로 0인 1,973건은 0으로, 미확정은 값이 없는 상태로 보존했다. 명시된 환급 검토 금액 91건은 별도 필드에 두고, 방향이 명시되지 않은 잔액은 원문의 범주에 맞게 저장했다.

표 행이 구조적으로 정규화됐다는 결과다. 약정 효력, 조정 적용과 최종 금액은 원본의 적용 조건을 함께 확인해야 한다. 다음 단계는 이 정제값의 출처를 활용해 **원본 페이지 vs. 행·머리글·조건 문맥**을 같은 순위와 토큰 예산에서 비교하는 것이다.

## 검증과 재현

고정 해시와 예외 유형으로 고른 9개 사건의 원본 45쪽을 PDF 42개에서 다시 추출해, 353개 정규화 레코드의 셀 값·줄 범위·원본 지문을 대조했다. 전체 HG 약정 구간의 숫자와 구간 경계도 저장된 원문 셀과 대조했다. HG 대상 표 행은 모두 한 줄이었으며, 줄바꿈 증빙의 행 연결과 열 경계를 결정하기 어려운 병합 행은 합성 표로 확인했다. 복수·잘못된 날짜, 예정과 실제의 구분, 단위 누락, 미확정과 명시된 0, 잘못된 일수 합계도 합성 입력으로 확인했다. Ruff 및 pytest 143건과 하위 검사 9건을 통과했다.

첫 실행의 로컬 경로는 `artifacts/u_10o0o/advanced-curation/hg-role-facts-20261109/`다. `role_facts.jsonl`은 원문 값과 출처를 담고, `summary.json`은 수량과 입출력 지문을 담는다. `review_rows.jsonl`은 정규화할 수 있는 열 구성이 없는 행을 담는다. 필드 단위의 검토 사유는 각 정규화 레코드에서 확인한다.

저장소 루트에서 [생성 스크립트](../../../advanced_role_facts.py)를 새 출력 경로로 실행한다.

```bash
uv run --no-sync python -m experimental.u_10o0o.advanced_role_facts \
  --output artifacts/u_10o0o/advanced-curation/hg-role-facts-replay
```
