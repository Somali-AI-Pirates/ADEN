# Advanced HA·업무 자료집 조회 확장 실험

2026-11-09에 [정제 계획의 6단계](../../../advanced-curation-plan.md#6-계산과-다른-양식은-각각-별도-실험) 중 HA와 업무 자료집의 정확 키 조회를 비교했다. 대조군은 [3단계에서 기록한 개인 기준선](../hg-indirect-lookup-20261109/report.md)이다. Bigram-ID BM25 제목 보너스, 후보 20쪽, KURE nano CUDA FP16, 최종 최대 8쪽·4,000토큰과 기존 HG 조회를 고정했다. 변경군은 질문에 단일 지원 키가 있으면 해당 원본 쪽을 먼저 넣고 기존 후보 순서로 중복 없이 채웠다. 평가 정답과 근거 위치는 두 문맥을 만든 뒤 채점에 읽었다. [입력 지문과 실행 조건](config.json) · [진행 로그](run.log)

| 양식 | PDF에서 만든 출처 매핑 | 조회 조건 |
|---|---:|---|
| HA 터미널 | 198사건·594쪽 | 단일 HA ID와 일치하는 계약 조건, 사건·증빙, 비용별 정산 세 쪽 |
| 업무 자료집 `기록번호` | 고유 키 5,321개 | 해당 표의 키 열에 있는 번호 한 개 |
| 업무 자료집 `처리 기록` | 고유 키 5,752개 | 해당 표의 키 열에 있는 번호 한 개 |

자료집의 두 양식에서 찾은 11,073개 키의 중복은 0개였다. 자료집의 다른 양식과 기타 특수 페이지 6쪽은 원본 검색 경로를 쓴다. 기타 특수 페이지는 증강 세트에서 별도 품질을 측정할 표본으로 구성돼 있지 않다. HA와 자료집에서 키가 없거나 지원 키가 여러 개면 기존 경로를 쓴다.

## 비교 결과

증강 6,500문항 중 1,597개에서 새 조회가 발동했다. 해당 키로 찾은 쪽의 집합은 모두 참고 파일의 주 근거 쪽 집합과 일치했다. HA의 다른 사건 연결은 0건이었다. 발동 문항의 대조군 지표를 다시 계산한 결과 보관값과 모두 일치했고, 미발동 4,903문항의 두 조건에는 보관값을 적용했다.

블라인드 후보 관련 397문항에서는 HA 12건, 자료집 25건에 조회가 발동했다. 이 묶음의 전체 필수 근거 충족은 두 조건에서 모두 397/397이었다. 전체 6,500문항에서 페이지 Recall@8은 두 조건 모두 100%였고, 전체 필수 근거 충족의 개선·회귀는 각각 0건이었다. 기존 자료집의 미충족 한 건은 새 조회가 발동하지 않았다. [범위별 집계](summary.json) · [문항별 지표](questions.jsonl)

**현재 개인 기준선은 기존 검색과 HG 조회를 사용한다.** 새 매핑은 확인한 키에서 원본 출처를 정확히 찾았으나, 기존 검색도 그 문항들의 필수 근거를 모두 담았다. 이번 실험은 기존 검색 이후에 조회 결과를 추가하는 방식이다. 조회가 검색을 대체할 때의 지연시간과 생성 답변 품질은 별도 지표다.

## 재현과 검증

저장소 루트에서 [양식 실험 스크립트](../../../advanced_format_extension.py)를 실행한다. Advanced 정제본, 복원 페이지 캐시, 3단계 기록과 로컬 KURE nano·CUDA가 필요하다. 두 자료집 양식의 세부 행은 문항의 단일 기록번호를 로컬 `handbook_rows.jsonl`의 `key_column`에 연결해 나눠 집계했다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.advanced_format_extension \
  --local-index artifacts/u_10o0o/advanced-curation/format-index-replay \
  --output artifacts/u_10o0o/advanced-curation/format-extension-replay
```

HA 5사건의 원본 15쪽과 자료집 두 양식에서 뽑은 10행의 원본 쪽을 직접 다시 추출해 PDF 지문, 머리말, 행 값과 줄 범위를 대조했다. 합성 입력 6건에서 단일 HA, 단일 자료집, 복수 키, 키 생략, HG가 포함된 경우의 분기를 검사했다. 6,500개 문항 ID, 겹침 397개, 미발동 점수 일치, 문맥 상한과 집계 재계산을 확인했다. 실행은 약 6분 30초였고 외부 API 호출은 0회였다.
