# Advanced 두 사건 문맥 배치 별도 검증

새 업무 질문 원형과 필요한 근거를 먼저 고정하고 개발에 사용한 업무형 20문항의 사건과 페이지를 제외해 원문에 연결한다. 두 사건 질문 24개와 대조 질문 6개에서 기존 개인 검색을 한 번만 실행한다. 문맥 조립 직전 후보 20쪽을 공유하며 최종 8쪽·4,000토큰에서 두 배치를 비교한다. 기존 배치와 후보 검색 코드를 사용하고 새 배치의 검증 대상 코드도 평가 중 고정한다. 질문과 원문 근거는 로컬 실행 폴더에 보관한다.

평가 전에 판단 기준을 정했다. 두 사건 질문에서 전체 근거 충족이 늘고, 기존 완전 충족 문항의 하락과 대조 질문의 문맥 변경이 없어야 기본 배치 채택을 지지한다. 두 사건의 필요 근거를 모두 보유한 후보와 일부만 보유한 후보를 구분한다. 특정 유형이 발동하지 않으면 그 유형의 개선은 별도로 판단한다.

질문 원형 검토에서 두 사건 중 청구액을 묻는 절이 보관료로 범위를 좁히지 않은 문항 11개를 표시했다. 보관료 청구액을 원문 근거로 쓰는 전체 점수와 별개로, 이 11개를 뺀 결과도 확인한다. 대상은 P03·P05·P07·P10·P15·P16·P17·P20·P21·P23·P24다.

## 검증 표본

기존 배치 규칙과 개발 문항을 열람하지 않은 별도 작성자가 업무 질문 원형을 만들었다. 번호로 두 사건을 찾는 질문, 번호와 원문 단서를 섞은 질문, 양쪽을 원문 단서로 찾는 질문을 8개씩 넣었다. 대조군은 단일 사건 질문 4개와 화주·장비 규격·반출일만으로는 사건을 확정할 수 없는 질문 2개다. 두 사건 질문은 업무에서 서로 다른 기록을 함께 요청하는 형태에 집중했다. [고정 질문 원형](scenarios.json)

기존 업무형 20문항과 겹치지 않는 56개 HG 사건을 연결했다. 101쪽의 원본과 복원 페이지에서 127개 필수 근거를 확인했다. 정답 근거만 넣은 문맥으로 30문항 모두 채점할 수 있었고 최대 2,371토큰이었다. 문맥 조립을 끝낸 뒤 참고 근거를 읽었다. 질문과 근거, 페이지, 배치 규칙의 지문을 실행 결과에 기록했다. 검색에는 로컬 KURE 리랭커를 사용했고 외부 API 호출은 0회였다. [집계 및 입력 지문](results.json)

## 결과

| 질문 유형 | 문항 | 후보 20쪽에서 전체 근거 확보 | 두 사건 인식 | 기존 문맥에서 전체 근거 충족 | 새 배치에서 전체 근거 충족 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 두 번호 | 8 | 8 | 2 | 5 | 5 |
| 번호와 원문 단서 | 8 | 6 | 0 | 3 | 3 |
| 양쪽 모두 원문 단서 | 8 | 2 | 0 | 0 | 0 |
| 두 사건 합계 | 24 | 16 | 2 | **8** | **8** |
| 대조 | 6 | 4 | 0 | 4 | 4 |

두 사건 질문의 개별 필수 근거는 두 방식 모두 75/108이었다. 문항별 개선과 하락은 각각 0개였다. 대조군을 포함해 30개의 문맥 지문이 모두 일치했다. 청구액 범위가 모호한 질문을 뺀 13문항에서도 전체 근거 충족 5/13, 개별 근거 39/56으로 두 방식이 같았다.

후보 20쪽에 필수 근거가 모두 있던 16문항 중 8개는 최종 문맥에서 근거가 빠졌다. 이 8개 중 7개는 두 사건으로 인식하지 못했다. 나머지 P06은 두 사건을 찾았지만 `확정 보관료`를 청구 기록 요청으로 해석하지 못해, 현장 기록만으로 요청한 근거가 이미 들어왔다고 판단했다. 전체 24문항에서 18개는 정해진 비교 표현 검사를 통과하지 못했고, 4개는 각 절에 식별 단서와 요청이 배치된 형태를 처리하지 못했다. 후보에 근거가 빠진 8문항은 문맥 배치만으로 완전 충족을 만들 수 없었다.

## 채택 판단

개발 문항에서 관찰한 개선은 새 표본에서 재현되지 않았다. 대조군 보존 조건은 충족했고, 사전에 정한 개선 조건은 충족하지 못했다. 기본 배치 채택을 보류한다. 먼저 두 사건의 식별 단서와 요청 기록을 절별로 연결하는 문제를 다룬다. 문맥 조립 성능은 두 대상과 요청 기록을 정확하게 식별한 경우를 따로 집계해 판단한다. 이 표본은 원문으로 검증한 업무형 질문이며 실제 사용자 분포와 답변 품질은 별도 평가 범위다. [개발 문항 실험](../advanced-pair-context-20261109/report.md)

## 재현

기존 복원 페이지와 HG 사건·역할 색인, 개발 문항 참고 근거, 로컬 리랭커 캐시를 준비한다. 출력은 신규 로컬 경로에 쓴다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.advanced_pair_holdout \
  --output artifacts/u_10o0o/advanced-pair-holdout-replay
```
