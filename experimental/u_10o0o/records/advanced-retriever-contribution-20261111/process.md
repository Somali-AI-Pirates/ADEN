# 검색기별 근거 기여 분석

2026-11-11, 별도 대화에서 요청된 분석이다. 기존 코드·기준선·색인·실험 결과를 수정하지 않고 이 기록 폴더와 새 artifacts 경로에만 저장한다. 다른 에이전트나 메인 대화 작업에 개입하지 않는다.

대상은 직전 비교의 보관된 bigram-id + 제목 보너스 BM25·Snowflake-ko 5:5 기준선이다. 원 질문 검색의 일상 표현 40개·공식 60개를 주 분석으로 하고, 저장된 요청별 일상 표현 40개를 보조 분석한다. 최신 bigram-id-normalized 구성이나 IS 창 벡터의 점수를 섞지 않는다.

검색기마다 상위 20개를 사용한다. 주 표는 질문별 정답 `book_id+page`를 BM25만·벡터만·둘 다·둘 다 못 찾음으로 나눈다. 여러 문항에서 같은 페이지를 요구하면 각 문항의 필요 근거로 각각 센다. 전체 질문 충족은 공식의 근거 그룹과 일상 표현의 주·대체 근거 묶음 정의를 유지해 별도 집계한다. 한 검색기가 모든 근거를 못 찾았다는 이유로 그 검색기의 부분 기여를 0으로 취급하지 않는다.

원 질문 100개의 누락된 BM25·벡터 순위를 로컬 CPU에서 재생하고, 저장된 RRF 후보 20개의 순서까지 일치해야 채점한다. GPU·KURE·새 Luna·답변 생성은 실행하지 않는다. 요청별 검색은 저장된 질문별 원 질문+실행 요청들의 각 검색기 결과 합집합을 재사용한다. 이는 검색 호출이 늘어난 별도 경로이므로 원 질문의 단일 상위20과 같은 예산이라고 표현하지 않는다.

모든 새 순위를 저장한 뒤에만 참고 근거를 읽는다. HG 조회 직후와 추가 원문 조회 이후 및 최종 문맥은 기존 저장 결과로 분석한다. HG가 조회한 근거를 BM25나 벡터의 성과로 중복 귀속하지 않는다. 후보 집합의 보충과 순서 승격은 구분한다. 이 분석은 기록된 경로의 근거 출처 분석이며 검색기를 제거하고 전 과정을 다시 실행하는 인과적 절제 실험은 아니다.

## 완료 기록

원 질문 100개의 RRF 후보20 순서가 보관된 결과와 100/100 일치했다. 로컬 CPU float32·4스레드로 질문 벡터와 BM25 순위만 재생했다. 순위를 저장한 뒤 참고 근거를 읽었으며, 저장된 요청별 일상 표현 86개 쿼리 결과도 재사용했다.

총 140개 경로별 결과(고유 질문 100개)에 대해 후보·HG 직후·전체 조회 후·실제 최종 문맥의 페이지 적중 및 전체 근거 충족이 보관 점수와 모두 일치함을 확인했다. 공식의 근거 없는 2개는 미채점으로 유지했다. 페이지별 네 분류의 합과 단계별 생존 수 합도 검증했다.

Ruff 격리 검사와 서식, 실제 분석 스크립트 재생·채점, 모든 문항의 기존 점수 재현 및 로그 링크·JSON 검사를 수행했다. 애플리케이션·공통 검색 코드는 변경하지 않았으므로 전체 애플리케이션 테스트나 빌드는 재실행하지 않았다. 이 별도 대화의 경계에 따라 독립 에이전트 리뷰는 수행하지 않았고 자체 대조를 사용했다.

표와 해석은 report.md, interpretation.md에, 전 문항은 per-question.md 및 JSON에 남겼다. 원문과 정답 인용은 공유 기록에 복사하지 않았다. 원래 순위를 만든 분석 코드 사본은 로컬 run-v1/replay-script.py로 보존했고, 보고서 생성 코드 지문을 별도로 기록했다.
