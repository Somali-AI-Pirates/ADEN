# Advanced TableRAG 실험 종료와 최종 선택

2026-11-12 사용자 확정. 이 실험은 종료한다. 개인 구현·인계 기준은 **공통 SQLite DB 우선 통합 TableRAG, 요청별 원문 인용 검사 OFF**다. 추가 확인 지침과 관측한 선택 출처 보존은 유지한다. 종료 기록 작성 중 새로운 모델 호출이나 품질 벤치를 실행하지 않았다.

최종 설정은 `UnifiedAgent(..., db_first=True, verify_evidence=False)`이며 `integrated_runtime()` 안에서 실행한다. 이 경로를 운영 API에 연결하는 작업은 별도다. 과거 재현용 `table_rag run`의 HG 보강 경로와 새 `table_rag_workflow`를 최종 선택으로 혼동하지 않는다.

## 선택의 핵심 근거

- 명시 코드로 DB에서 시작한 109문항 중 108개는 하이브리드·리랭킹을 생략했다. 이 묶음의 근거 회수는 유지했고 p50은 4.77→4.08초였다. 코드가 없는 모든 질문까지 빨라졌다는 결과는 아니다.
- 요청별 인용 검사는 같은 공식 58문항에서 실제 근거 충족 56→57, p50 5.50→9.42초였다. 개선 2·하락 1문항이며, 동료·카테고리 전체에서 이 옵션의 추가 효과를 비교하지 않았다. 지연과 검증 범위를 고려해 OFF를 선택했다.
- 동료의 모호한 43문항에서 추가 확인 종료 25→41, p50 18.13→8.87초로 개선된 기능은 **추가 확인 지침·선택 출처 보존**이다. 요청별 인용 검사와 다른 기능이며 최종 구성에서도 유지한다.
- 요청 계획·근거 단위·선택을 함께 바꾼 마지막 workflow는 공식 53→46/58, 카테고리 188→158/200으로 하락하고 지연이 늘어 채택하지 않는다.

점수는 실제 반환 문맥의 사후 근거 충족이며 실제 답변 정확도가 아니다. 57/58이라는 과거 기록을 최종 OFF 구성의 재현 보장값으로 적지 않는다. 모든 선택의 세부 수치와 실행 ID는 아래 문서에서 구분한다. 별도 미사용 세트 일반화와 반복 실행 신뢰구간은 검증하지 않았다.
