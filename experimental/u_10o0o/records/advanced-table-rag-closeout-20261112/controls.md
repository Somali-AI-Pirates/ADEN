## 평가 데이터와 누수 방지

공식60 가운데 기존부터 참고 근거가 없는 AS-DEV12·AS-ADD12를 제외한58개를 검색 평가에 사용한 실행이 많다. 이 둘을 이번 결과를 보고 새로 제외한 것은 아니다. 초기 답변 실험의 공식60과58을 같은 분모로 취급하지 않는다. 카테고리220은 근거형200(상황140+업무규정20+일상표현40)과 범위 밖20을 분리한다.

동료304 전체, 그중 다문서 일반85·거짓 전제85, 원래 모호43개는 서로 다른 집계다. 보존 실험은 거짓 전제46문항에 식별자/계산 가정을 보충한 사본을 썼다. 원본 질문·참고답·PDF를 작성에 사용했으므로 미사용 검증 세트가 아니다. '동료 데이터'라는 이름만 보고304 전체 결과로 읽지 않는다.

질문/조건을 먼저 고정하고 검색 결과·원문·SQL을 모두 저장한 뒤 참고 근거를 별도 채점 단계에서 읽었다. 답변 생성, 자동 사후 채점, 자체 인용 대조는 검색 단계와 구분한다. 저장된 검수 재사용은 질문·참고 근거·최종 문맥 지문이 같을 때만 허용한다.

## 실제 반환 근거를 주 판단으로 삼는다

최종 선택은 실제 반환 문맥과 유지된 SQL 결과가 질문의 필수 대상·기록·날짜·단위·범위를 모두 뒷받침하는지로 판단한다. 같은 의미의 다른 출처도 인정한다. 지정 페이지에 없다는 이유만으로 실패라고 하지 않는다. 반대로 원본에 존재하더라도 그 실행에서 반환하지 않은 근거는 인정하지 않는다.

정답 파일의 book_id+page 전체 적중/Recall은 위치 진단용으로 별도 보존한다. 지정 페이지가 틀리거나 대체 원문이 있으면 실제 정답률로 사용할 수 없다. 요청별 확인의39→36 지정 일치를 품질 하락 근거로 쓰지 않는다. 공식58의 실제 검수56→57을 주 결과로 삼고, 미충족/모호성의 사유를 함께 읽는다.

모호 문항은 임의로 정답 처리하거나 분모에서 조용히 빼지 않는다. 추가 확인에 필요한 양쪽 후보 기록을 충분히 반환한 것과 한 사건의 금액을 확정해 답할 수 있는 것은 다른 판정이다. 원래 추가 확인 대조군은 종료 상태를 별도로 측정한다.

AI 보조 검수와 자체 대조다. 독립 사람 검수나 실제 사용자 답변 정확도로 표현하지 않는다. 원문 인용의 일치는 의미상 충분성의 필요조건 일부일 뿐이다. 모델이 필요한 업무 의무 자체를 빼먹는 문제는 남는다.

## 이번 종료에서 확인한 결론의 범위

- OFF가 모든 세트에서 ON보다 정확하다는 결과는 없다. 공식 한 문항 순증에 약3.9초 p50 증가, 전체 추가 검증 부재를 고려한 효율 선택이다.
- 동료에서25→41/43으로 개선된 것은 추가 확인·출처 보존 묶음이다. 최근 verify_evidence 옵션의 효과로 가져오지 않는다.
- 마지막 묶음 실험의 A는 통합 OFF이며 과거 HG 보강57/58 실행과 다르다. 53을 과거57의 정정으로 기록하지 않는다.
- 여러 요소를 함께 바꾼 실험은 해당 구성 전체의 결과다. 논문 자체의 성공/실패나 개별 모듈의 인과 효과로 확대하지 않는다.
- 마지막 workflow의 하락42문항 중30/3/9는 지정 근거 최초 누락 단계(조회 합집합/후보20/최종8)의 진단이다. 가능한 모든 대체 근거의 전수 존재 검사 결과가 아니다.
