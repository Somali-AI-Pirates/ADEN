# 종료 기록과 게시 과정

## 요청과 범위

사용자는 통합 DB 우선·요청별 인용 검사 OFF를 확정하고 실험을 종료하며, 선택 근거·변인 통제·참고 논문·과정을 상세히 기록하고 실험 변경만 커밋·푸시·PR 병합하도록 요청했다.

새 런타임 알고리즘, 유료 벤치, 운영 API 이식은 하지 않는다. 기존 명시적 옵션으로 선택을 표현한다. 원본·로컬 색인·과거 결과와 다른 작성자의 변경을 보존한다. 비교용 ON과 이전 TableAgent/workflow는 재현용으로 남긴다.

## 작업 분리

공유 작업 폴더에는 app/, tests/, 의존성·공통 문서의 운영 구현이 진행 중이었다. 최신 origin/main에서 별도 `chore/table-rag-experiment-closeout` 작업 경로를 만들고 실험 코드·기록만 복사했다. 원래 작업 폴더의 브랜치·인덱스·소스를 변경하거나 미완료 실행을 종료하지 않았다.

실험 폴더 안의 replay_product.py는 아직 main에 없는 app.rag에 의존하는 병행 운영 재생 작업이어서 이 PR에서 제외한다. 나머지 TableRAG 개인 코드와 15개 기존 실험 기록 묶음, 개인 평가 지침, 새 종료 문서를 포함한다. 원본 PDF·정답 인용·벡터·SQLite·.env는 게시하지 않는다.

## 기록 정합성

'추가 확인·선택 출처 보존'과 '요청별 원문 인용 검사'를 별도 기능으로 명명했다. 과거 채택57/58, 요청별 확인 OFF56/58·ON57/58, 마지막 재실행 OFF53/58은 각각 실행 ID로 연결한다. 과거 수치를 조용히 바꾸거나 가장 높은 값만 합치지 않는다.

실험 보고서에서 읽기 쉬운 현재 선택 링크를 추가하되 과거 프로토콜·모델 지문·검수 기록을 유지한다. 생성 보고서의 안내는 생성 스크립트에도 반영한다. 새 종료 문서의 참고 자료는 원 출판사/저자 자료를 확인했으며, 사용자 제공 조사문에 등장한 배경 논문과 실제 구현한 요소를 구분한다.

## 자체 검토와 검증

이 사이드 대화에서는 독립 에이전트가 금지되어 저장소·원문 보존/공개 범위와 실행·도구 경계를 자체 검토한다. 이를 독립 리뷰라고 표시하지 않는다. PR 팀원 리뷰는 별도 저장소 규칙에 따른다.

최종 검사·공개 자료 점검 결과는 verification.json에 기록한다. 검사는 공유 작업 폴더의 운영 변경이 아닌, PR에 게시할 독립 작업 경로의 코드로 수행한다. 소스 원본 해시와 복사 목록은 로컬 artifacts/u_10o0o/table-rag-closeout-20261112/snapshot.json에 보존한다.

## 완료한 로컬 검사

독립 작업 경로에서 공통·개인 pytest **462개와15개 subtest**를 통과했다. 원래 공유 경로의 이전464개 기록과 분모가 다른 이유는 미커밋 운영 테스트를 이 PR에 복사하지 않았기 때문이다. 과거 벤치 검사 로그의 숫자를 수정하지 않는다.

공통 Ruff, 개인 코드의 프로젝트 동일 오류 규칙(E4/E7/E9/F), Python 구문, 새/기존 CLI 도움말, 일반·보안 가상 샘플, wheel/sdist 빌드와 필수 리소스·실험 제외 검사를 통과했다. 첫 가상 샘플 명령의 ID 접두사가 잘못돼 실행 전에 거절됐으며 요구한 sample- 접두사로 고쳐 통과했다. 유료 호출은 없었다.

공개 JSON의 질문·원문 인용 필드를 검사했다. 마지막 묶음 실험 difference-flows.json의58개 plan에는 질문 재작성·대상 값이 포함되어 있어 공개 사본에서 제외했다. 원본 결과는 로컬에 보존했고 모든 점수·집계 JSON은 복사 시점과 동일하다. 같은 문제가 재생성되지 않게 공개 scorer의 plan 내보내기도 제한했다. 원본 실행 코드는 로컬 executed-code로 재현하며, 종료 후 공개용 처리·문서 편집을 과거 실행 코드와 같은 해시라고 주장하지 않는다.

순수 스타일 권고까지 확대하는 Ruff 검사는 종료 기준으로 사용하지 않았다. 저장소 CI와 같은 오류 규칙을 개인 실험에 명시 적용했다. 공통 운영 코드를 포함하지 않았으며, Git diff 범위와 비밀키 패턴·문서 링크를 확인했다.
