# TableRAG 제외 실험 게시 과정

## 요청 범위 확대

처음에는 fresh A/B/C→D/E/F→기록 선택→기존 평가만 커밋하려 했다. 사용자가 진행 중인 TableRAG 리서치를 제외한 나머지 실험도 함께 커밋·푸시하도록 요청했다. 첫 fresh 묶음은 별도 커밋으로 보존하고, 나머지는 같은 `chore/advanced-experiments-closeout-20261111` 브랜치의 후속 커밋으로 모은다. main 병합은 이번 요청에 없다.

진행 중인 `table_rag/`와 `records/advanced-table-rag-*`는 코드·기록 모두 제외한다. 이미 완료된 검색 기초 조사에서 TableRAG 논문을 참고문헌으로 인용한 부분은 과거 조사 기록이므로 다른 자료와 함께 보존한다. TableRAG 작업 파일·프로세스는 변경하지 않는다.

## 최소 수정 경계

implementation-strategy에 따라 이번 수정은 게시 전 검사에서 발견한 결함만 대상으로 한다. 기존 검색 정책·모델·평가 점수·운영 API·영속 형식은 바꾸지 않는다. `pattern_retrieval`의 가짜 자원 테스트가 실제 로컬 curation manifest를 요구하는 문제는 테스트 임시 디렉터리에 Advanced 식별 manifest를 만들어 기존 생성자 인자로 전달해 해결한다. 이는 지원하는 기존 입력 경로를 사용하는 검사 보완이며 런타임 대체 경로를 추가하지 않는다. `advanced_structured_gold.py`의 미정의 함수와 미사용 변수는 호출부·기존 도우미를 확인한 뒤 최소 수정하고 집중 검사한다.

새 체크아웃에서 첫 추가 테스트는 243개 통과·1개 실패였으며, 실패 원인은 가짜 자원 테스트가 Git 밖 manifest에 의존했기 때문이다. 이 실패를 통과로 기록하지 않고 수정 전 결과와 최종 검사 결과를 구분한다.

## 최종 검사와 결과 보존

공통 테스트와 추가 개인 실험을 합쳐 656 passed, 15 subtests passed, 2 skipped를 확인했다. 건너뛴 두 항목은 fresh 원본 자료 검사이며 원본 환경에서는 앞서 123개 fresh 검사가 모두 통과했다. 공통 Ruff와 후보 Python 126개에 프로젝트와 같은 E4/E7/E9/F 규칙을 적용한 검사도 통과했다. 주요 CLI 14개 도움말을 확인했으며 모델·외부 API는 새로 호출하지 않았다.

구조화 평가 생성기의 미정의 `_narrative_rows`는 같은 파일의 `_narratives_by_page` 결과를 펼치는 코드로 교체했다. 불필요 import·변수를 제거했으며 기존 manifest JSON 구문 검사만 유지했다. 새 스키마나 추가 검증 정책을 도입하지 않았다. 로컬 manifest에 의존하던 가짜 자원 테스트는 임시 manifest를 생성하도록 바꿨다. 이번에 수정한 검색 동작은 없고 과거 점수를 다시 계산하지 않았다.

독립 범위 감사에서 TableRAG import는 0건, 바이너리·API 키 패턴은 0건이었다. JSON/JSONL의 질문·정답·원문 필드 후보를 검사했고, 하나 있는 prompt는 `advanced_query_plan.py`의 고정 지침 문자열과 일치했다. 문항별 입력이 아니라 당시 사용한 해석 지침을 보존한 것이다. 공유 문서 링크 823개에서 공개 대상 누락은 없었고, 새 체크아웃에 없는 비공개 산출물 링크 42개는 로컬 자료 경로로 구분했다.

이미 작업 트리에 채택돼 있던 `bigram-id-normalized` 기본값과 그 선택 기록도 이번 추가 범위에 포함한다. 이는 fresh A~F 실험 결과로 기준선을 교체한 결정이 아니다. 운영 app/shared/공통 테스트·패키징 설정의 새 변경은 없다.

게시 중에도 제외한 TableRAG 기록 일부의 지문은 외부 작업으로 바뀌었다. 이 작업은 TableRAG 파일을 수정하거나 복사·stage하지 않았고, 원본 작업 트리와 진행 중인 프로세스는 그대로 둔다. 원본·질문·정답 인용·모델·색인은 Git에 넣지 않는다.
