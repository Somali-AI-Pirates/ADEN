# BM25 완전 코드 표기 정규화: 기존 기준선과 비교

2026-11-11. 공식 60문항과 카테고리 220문항을 두 조건에서 각각 새로 실행했다. 기존 기준선의 대문자 완전 코드 보존을 소문자·하이픈 주변 공백·유사 하이픈 표기까지 확장했다. 코드 문법의 길이·분절 수 제한은 기존과 같고 일반 bigram 토큰은 바꾸지 않았다.
