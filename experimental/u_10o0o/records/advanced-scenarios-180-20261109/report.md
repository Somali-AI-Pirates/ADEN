# Advanced 상황별·업무 규정 180문항 비교

개인 Advanced 기본 실행에 두 사건 원문 조회를 포함한다. 상황별 140문항에서 앞선 두 사건 실험의 결과를 재현한 뒤, 상황별 검색 140문항과 업무 절차·규정 20문항, 범위 밖 대조 20문항을 개인 기준선과 동료 `team_graph` 무 LLM 설정으로 검색한다. 두 설정의 최종 문맥은 최대 8쪽·8,000토큰이다. 범위 밖 대조는 근거가 있는 160문항과 분리한다.

## 기본 실행 재현

`advanced_search --suite scenarios`에서 **140/140**을 재현했다. 모든 문항의 후보 순서, 최종 페이지, 문맥 지문이 앞선 두 사건 실험 B와 일치했다. 단일 사건 조회는 20문항, 모호 후보 조회는 20문항, 두 사건 비교 조회는 12문항에서 조건을 충족했다. [기본 실행 설정과 재현 지문](baseline-reproduction.json) · [채택 결정](../decisions.md#2026-11-09--두-사건-원문-조회를-개인-advanced-기준선에-채택)

## 필수 근거가 있는 160문항

각 값은 해당 단계에서 필수 인용을 모두 확보한 문항 수다. 개인 후보는 기존 HG와 원문 조회를 합친 20쪽이다. 동료 후보는 `team_graph`의 20청크를 쪽 단위로 중복 제거한 결과다. 두 설정 모두 복원 원본을 같은 8쪽·8,000토큰 조건으로 조립했다. [평가 가이드](../../evaluation/advanced_scenarios/README.md#다음-비교의-데이터와-집계)

| 평가 묶음 | 개인 후보 | 개인 최종 | 동료 후보 | 동료 최종 |
| --- | ---: | ---: | ---: | ---: |
| 1. 직접 조회 | 20/20 | 20/20 | 20/20 | 20/20 |
| 2. 번호 없이 한 사건 식별 | 20/20 | 20/20 | 6/20 | 6/20 |
| 3. 한 사건의 여러 기록 연결 | 20/20 | 20/20 | 20/20 | 20/20 |
| 4. 서로 다른 사건 비교 | 20/20 | 20/20 | 11/20 | 10/20 |
| 5. 적용되는 기록·조건 판정 | 20/20 | 20/20 | 20/20 | 20/20 |
| 6. 대상이 모호해 추가 확인 필요 | 20/20 | 20/20 | 0/20 | 0/20 |
| 7. 대상은 명확하지만 확정 근거 부족 | 20/20 | 20/20 | 20/20 | 20/20 |
| **상황별 140문항** | **140/140** | **140/140** | **97/140** | **96/140** |

본 평가의 최종 개별 근거는 개인 **327/333**, 동료 **244/333**이었다. 문항별 평균 페이지 Recall@8은 **97.81% / 73.75%**, 문서 Recall@8은 **99.06% / 83.39%**였다. 문항별 전체 근거는 개인만 46개, 동료만 3개, 둘 다 109개, 둘 다 미충족 2개였다. [문항별 점수](scores.jsonl) · [전체 집계](results.json)

업무 규정에서 두 설정 모두 13문항을 충족했고 개인만 2개, 동료만 3개, 둘 다 미충족 2개였다. 개인의 실패 5개 중 4개는 후보 단계부터 빠졌고 `AS-WR-20`은 필수 쪽이 후보 11위라 최종 8쪽에서 빠졌다. 동료는 후보 단계에서 3개를 놓쳤고 `AS-WR-19`의 필수 쪽 하나가 13위에서 빠졌다. 두 문항 모두 토큰 한도로 제외된 페이지는 없었다.

## 범위 밖 대조 20문항

두 설정 모두 20문항 전부에 **8쪽씩** 반환했다. 아래 판정은 최종 문맥의 첫 페이지를 질문과 대조한 결과다. 보관 실행에서 두 설정의 첫 페이지를 검토했고, 새 실행에서도 40개 페이지 위치가 전부 같음을 확인했다. [첫 페이지 판정과 문항별 근거](negative-top1-review.jsonl)

| 대조 유형 | 개인 · 무관 | 개인 · 주제만 유사 | 동료 · 무관 | 동료 · 주제만 유사 |
| --- | ---: | ---: | ---: | ---: |
| 완전히 무관한 질문 10개 | 10 | 0 | 10 | 0 |
| 물류 업무와 유사한 질문 10개 | 0 | 10 | 2 | 8 |

주제만 유사한 페이지는 요청한 사실을 뒷받침할 수 없다. 예를 들어 반입 준비 안내는 현재 항만 통제 상태를 확인해 주지 않는다. 이 대조군은 Recall과 전체 근거 충족 분모에서 뺐다. 범위 밖 문맥을 걸러내는 필터나 생성 답변의 보류 행동은 이 비교에 적용하지 않았다.

## 재현과 해석 범위

두 설정 모두 180문항을 새로 검색해 문맥 360개를 저장한 뒤 참고 근거를 읽었다. 개인의 상황별 140문항 후보·최종 문맥은 기본 명령 실행과 전부 일치했다. 동료는 `team_graph`의 E5-small·BGE 리랭킹과 그래프 연결을 사용했고, 3,600청크에서 중복을 제거해 문항별 합계 3,552쪽으로 복원했다. 외부 API 호출은 0회였다. [실행 로그](run.log) · [입력·코드·설정 지문](results.json)

180문항의 ID와 문맥 360개의 후보·최종 페이지·토큰 상한을 대조했다. Ruff, 변경 파일의 포맷 검사, pytest 160개와 하위 검사 9개를 통과했다.

상황별 140문항은 이전 조회 규칙 검증에도 쓰인 합성 표본이다. 업무 규정 20문항은 상황별·대조 묶음의 근거와 겹치지 않지만 공식 평가와 13쪽을 공유한다. 6번의 되묻기와 7번의 확정 보류는 검색 근거를 채점했으며 실제 답변 행동은 별도 평가 범위다. [업무 규정 데이터 설명](../../evaluation/advanced_scenarios/work_rules/README.md)
