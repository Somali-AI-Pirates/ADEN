# Advanced 요청별 검색 후속 검증 조건

동료 304문항과 일상 표현 40문항은 대상·요청 진단, 최초 후보, 보강 후보, 최종 근거를 분리해 재집계한다. 새 검증은 단일 요청 12개와 복합 요청 12개를 원본으로 작성한다. 질문과 근거는 검색 출력 전에 별도 검토하고 지문을 고정한다. 이전 비교에서 인용된 원본 쪽과 해당 HG 사건은 제외한다. 같은 코퍼스를 사용하는 별도 에이전트 작성·검수 표본이다.

비교군은 기존 HG 라우팅·전체 5:5 복귀 기준선과 같은 기준선에 앞선 B의 Luna 계획·요청별 검색을 더한 설정이다. 개인 실험 진입점과 저장 형식은 기존 코드를 재사용한다. 후보 최대 20쪽·최종 최대 8쪽·8,000토큰을 공통으로 적용한다. 각 설정은 새 문항을 한 번 실행하며 홀수·짝수 순서로 먼저 실행할 설정을 번갈아 배치한다. 두 실제 요청의 공통 라우팅 결과가 다르면 품질 비교에는 기준선의 결정과 요청별 검색의 저장 계획을 사용한다. 이 로컬 재생은 실제 요청 지연에서 제외한다. 품질 집계는 후보와 최종 출처를 저장한 뒤 참고 근거를 읽는다.

주 지표는 복합 질문에서 모든 요청의 근거를 확보한 문항 수다. 문항별 개선·하락의 정확 양측 검정과 단일 요청 회귀를 함께 기록한다. 복합 개선이 양측 정확 검정에서 p≤0.05이고 단일 요청의 완전 충족 수가 줄지 않으면 채택 후보로 본다. 전체 적용 판단에는 실측 지연과 호출량을 반영한다. 현재 운영 지연 상한이 정해져 있지 않아 표본 개선만으로 전체 적용을 결정하지 않는다.

지연은 워밍업 후 동시 요청 1개로 API를 포함한 각 검색 요청의 벽시계 시간을 잰다. 두 설정에 GPT-6 Luna low의 기존 HG 라우터를 각 24회 실행하고 요청별 검색에만 기존 계획기 24회를 추가한다. 개인 실험의 새 외부 호출 상한은 72회이며 첫 문항을 사전 확인에 포함한다. 권한·잘못된 요청·제한 응답에서 중단하며 자동 재시도는 0회다. 기존 호출 설정의 시간 한도는 HG 라우터 10초와 요청 계획기 25초다. 질문과 기존 지침·스키마만 전송한다. 답변 생성과 외부 평가 호출은 0회다.
