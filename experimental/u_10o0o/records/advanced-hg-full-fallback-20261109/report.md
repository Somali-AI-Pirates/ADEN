# Advanced HG 조회와 전체 5:5 검색 복귀

2026-11-09 · 공식 60문항과 동료 304문항

기존 HG 분리는 공식 평가에서 근거를 더 잘 찾았지만, 동료 문항에서는 HG 전용 검색이나 AS057~AS120을 제외한 일반 검색으로 넘어갈 때 다른 문서의 근거를 놓쳤다. 이번 비교에서는 검증된 HG 사건에만 DB 원본을 연결하고, 문서 검색이 필요한 요청은 전체 5:5 검색으로 보냈다. [공식 HG 분리 기록](../advanced-hg-partition-20261109/report.md) · [동료 HG 분리 기록](../advanced-hg-partition-peer-20261109/report.md)

전체 검색은 제목 보너스 Bigram-ID BM25와 Snowflake-ko를 5:5 RRF로 합치고 KURE nano로 상위 순위를 조정한다. 세 설정 모두 검색 후보 20쪽, 최종 문맥 최대 8쪽·8,000토큰을 적용했다. 이전 실제 Luna 호출 364회의 검증된 분기와 저장 순위를 고정했다. 기존 두 설정의 문맥 지문과 문항별 점수 728건이 일치했고, SQLite 조회 원본도 기록된 출처와 대조했다. 새 API 호출과 답변 생성은 0회였다.

최종 전체 근거 충족은 각 문항의 필수 근거가 최종 문맥에 모두 들어온 경우다. 공식은 인용 근거가 있는 58문항을 채점했다. 동료는 한 근거 그룹 안에서 대체 인용 하나를 충족하면 해당 그룹을 충족한 것으로 계산했다. 페이지 Recall@8은 `(book_id, page)` 일치의 문항별 Recall을 평균했다. 검색·조회 결과를 파일에 기록한 뒤 참고 근거를 읽어 채점했다.

공식에서는 새 경로가 기존 HG 분리와 문항별 충족 여부까지 같았다. 기존 전체 5:5와 비교하면 11문항을 더 충족했다. 동료 304문항은 기존 HG 분리 대비 24문항을 회복했고 10문항이 하락해 14문항이 순증했다. 기존 전체 5:5와는 304문항 모두 충족 여부가 같았다. 회복과 하락은 모두 미확정 질문의 검색 범위 변경에서 나왔다. 하락 10건 중 9건은 3~4문서 합성이었고, 10건 모두 이전 HG 전용 검색에서 근거를 더 잘 모았던 경우다. ## 분기 확인

| 새 경로 | 공식 | 동료 | 확인 방법 |

| 확정 HG 혼합 | 5 | 4 | 전체 5:5 후보와 SQLite 원본을 같은 문맥에 포함 |
| 전체 5:5 복귀 | 30 | 284 | 기존 전체 5:5의 후보·선택 쪽·문맥 지문과 일치 |

혼합 9문항 모두 최종 문맥에 DB 원본과 별도 검색 출처가 들어갔다. 공식 혼합 5문항은 5건 모두 근거를 충족했다. 동료 혼합 4문항은 세 설정 모두 필수 근거 2개 중 1개만 충족했다. 실행 전체에서 최종 문맥은 공식 최대 8쪽·6,214토큰, 동료 최대 8쪽·7,067토큰이었다. 이 비교는 검색과 근거 조립을 검증한다. 새 Luna 판단의 정확도, 되묻기 품질, 실행 지연은 이 기록의 측정 범위 밖이다. [공식 집계](official/results.json) · [동료 집계](peer/results.json)

## 재현

기존 페이지·벡터 캐시와 `build-hg-codes` SQLite 스냅샷을 준비하고 비어 있는 새 결과 경로를 지정한다. 재생 입력, 질문, 문서 자원, 평가 근거의 SHA-256은 설정 파일에 기록했다. 보관된 혼합 기록은 모두 단일 HG 사건이다. [공식 설정](official/config.json) · [동료 설정](peer/config.json)

```bash
uv run --no-sync python -m experimental.u_10o0o.advanced_experiment compare hg-partition \
  --suite official \
  --replay-from experimental/u_10o0o/records/advanced-hg-partition-20261109 \
  --output-dir artifacts/u_10o0o/advanced-hg-full-fallback-official-replay

uv run --no-sync python -m experimental.u_10o0o.advanced_experiment compare hg-partition \
  --suite peer \
  --replay-from experimental/u_10o0o/records/advanced-hg-partition-peer-20261109 \
  --output-dir artifacts/u_10o0o/advanced-hg-full-fallback-peer-replay
```
