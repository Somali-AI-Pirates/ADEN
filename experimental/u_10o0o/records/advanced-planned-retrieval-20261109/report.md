## 실험 구성

최신 HG 조회와 전체 5:5 검색 기준선의 공식·동료 결과를 저장 기록에서 복원했다. 동료 표본은 거짓 전제 8문항, 2문서 합성 16문항, 3~4문서 합성 24문항이다. 3~4문서 표본은 정상 질문과 거짓 전제 변형이 공유하는 근거 쌍에서 한 문항씩 골랐다. 원문 기반 대조는 서로 다른 사건의 독립 요청, 조건에 맞는 여러 건, 이전 조회의 계약번호를 쓰는 순차 조회, 사건 조회와 규정이 섞인 질문을 각 6문항씩 구성했다. 대조의 요청별 계획은 문항 구성 시 명시했으며 해당 문항의 채점 인용을 복원 원문과 대조했다. 별도 사람 검수를 거친 실사용 문항으로 집계하지 않았다.

| 설정 | 적용한 방식 |
| --- | --- |

| R 규칙 | 구두점과 식별자 규칙으로 절을 나누고 E와 같은 로컬 실행기·선택기 사용 |

| D 순차 조회 | C에 앞 작업의 원문에서 확인한 계약번호·실제 반납일을 뒤 작업에 전달하는 기능 추가. [IRCoT](https://aclanthology.org/2023.acl-long.557/) |
| E 요청별 근거 선택 | D의 조립 후보를 그대로 사용해 필요한 사건·기록 역할을 먼저 담고 기존 선택 결과로 나머지를 채움. [SetR](https://aclanthology.org/2025.acl-long.861/) |
| F 명시 계획 | 대조 문항의 작업·역할·의존성을 직접 명시해 E와 같은 실행기에서 비교 |

후보 최대 20쪽, 최종 8쪽·8,000토큰, 동일 복원 PDF와 로컬 검색 모델을 사용했다. E는 D와 최초 후보 및 조립 후보가 문항별로 동일하다. A의 공식·동료 108문항은 이전 채점과 일치했고, 확정 HG 단독 조회 결과는 변형 간 공유했다. 순차 조회에 쓰는 값은 앞 작업이 원문을 확보하고 SQLite에서 그 출처에 기록된 값 하나를 확인한 경우에 전달했다. 검색 결과를 먼저 저장한 뒤 정답 근거를 읽어 채점했다. ## 단계별 해석

- **Luna의 질문 계획이 가장 먼저 효과를 냈다.** 동료에서 B는 A 대비 개선 4문항, 하락 0문항이었다. 조립 후보의 전체 근거 충족도 25/48에서 28/48로 늘었다. E와 F의 대조 문항별 완료 여부는 24개 모두 같았다. Luna의 작업 유형·요청 역할·조건·의존성이 명시 계획과 모두 일치한 것은 21/24, SQLite에서 고른 사건과 역할별 원문 연결까지 대조해 일치한 것은 23/24였다.
- **SQLite의 효과는 조건 조회에서 분명했다.** 조건에 맞는 사건의 원문을 조립 후보에서 모두 확보한 문항은 B 2/6에서 C 6/6으로 늘었고 최종 충족은 2/6에서 5/6으로 올랐다. 동료 표본에서는 C가 B 대비 3문항 하락했고, 세 문항 모두 조립 후보에 필수 근거가 남아 있었다. E가 같은 후보에서 이 세 문항을 모두 회복했다. 이 표본에서 B와 E의 문항별 완료 여부는 48개 모두 같았다.
- **순차 조회는 작동했으나 추가 적중은 없었다.** 공식 2건에서 확인된 실제 반납일을 후속 규정 검색에 넣었고, 대조 6건에서 회신의 계약번호를 후속 약정 조회에 사용했다. C와 D의 최종 전체 근거 충족은 모든 문항에서 같았다. 순차 대조 6건은 기존 검색부터 모두 충족했다. 이 대조는 의존성 전달이 동작한다는 증거이며, 검색에 의존성이 꼭 필요한 별도 표본에서 효과를 확인할 필요가 있다.
- **채택 판단.** 동료 표본에서는 Luna 계획을 병렬 실행한 B가 E와 같은 성적이었다. 업무 유형 중 조건에 맞는 사건을 나열할 때는 SQLite와 요청별 선택의 이득이 추가로 확인됐다. 기존 기준선의 교체 여부는 동료 전체와 별도 업무형 표본에서 재현한 뒤 판단한다. ## 사용량과 재현

GPT-6 Luna `low`는 질문과 검색 계획 지시만 받았다. 132회 모두 계획을 반환했고 입력 97,343토큰, 출력 42,744토큰을 사용했다. 요청 지연 p50은 4.09초, p95는 6.92초였다. 표준 텍스트 단가 기준 추정 비용은 $0.031이다. 원문 조회·검색·채점은 로컬에서 실행했다.
