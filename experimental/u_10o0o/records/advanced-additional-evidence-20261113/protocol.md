# 추가 30문항: 평가 고정과 후속 근거 확보 비교

2026-11-13 사용자 요청. 기존 기준선을 유지하고 PR #62에서 확인한 조기 종료·후보 미열람을 개인 실험에서 검증한다.

## 범위 계약

- A는 PR #62 실행 커밋 `92e8c038a432c334400619ff38e603be5d863c2e`의 DB 우선 제품 그래프다. 다른 작업의 수정과 분리하기 위해 해당 코드를 로컬 artifacts에 복사해 고정한다.
- B는 같은 그래프·도구·검색·문맥 조립을 사용한다. 계획 지침에 요청한 절차·필수 전달 정보·적용 조건의 미충족 확인을 추가하고, 검색 후보 중 본문이 노출되지 않은 쪽에 원문 서두 미리보기를 붙인다. 후속 검색 또는 read_sources는 기존 도구로 수행한다.
- B는 미노출 후보마다 최대384토큰의 서두를 추가한다. 최종 문맥8,000토큰은 같지만 계획 모델의 입력량은 증가할 수 있다. 같은 후보 수를 같은 호출 비용으로 해석하지 않고 실제 토큰·지연을 별도 보고한다.
- 후보의 원문 미리보기는 검색이 이미 발견한 출처에만 허용한다. 정답 페이지, 문항 ID별 분기, 참고답, 과거 성공 검색어를 계획 입력에 주지 않는다. B의 두 변경을 묶어 평가하며 개별 효과로 주장하지 않는다.
- BM25·KURE-v3 벡터·5:5 RRF(k=60)·KURE nano, 검색별 및 병합 후보20·최종8쪽·8,000토큰, 최대5작업 후 종료를 고정한다. 임베딩 CPU BF16, 리랭커 GPU FP32, CPU 스레드2. A/B가 같은 장치를 사용한다. 과거 CPU 실행과 절대 지연을 비교하지 않는다.
- 양쪽 모두 Luna medium. 30문항×2조건×3회, 결과를 보며 프롬프트·규칙 변경 없음. 반복·문항별 A/B 순서를 교대한다. 초기 질문 임베딩부터 매번 새 검색하며 LLM 응답·검색 결과 캐시를 재사용하지 않는다.
- 답변 생성·운영 코드 변경·기본 구성 채택·커밋·푸시는 범위 밖이다. 외부 Langfuse 전송 없이 실험 artifacts에 요청·응답·도구·본문을 저장한다.

## 평가 고정

공식 additional.json을 보존하고 별도의 평가 기준을 동결한다. 질문이 요구한 필수 사실을 모두 지원하면 대체 원문도 인정한다. 지정 페이지 회수는 보조 위치 진단으로 남긴다.

- ADD03: 미회신 취소 요청은 완료가 아니라는 판단을 필수로 한다. 질문하지 않은 특정 부서명은 별도 필수 조건으로 강제하지 않는다.
- ADD10: 기존 이메일 접수분에 전환 후 정정일만을 이유로 신규 포털 등록을 요구하지 않는다는 판단과 적용 범위를 필수로 한다. 정확한 정정 이메일 주소·별도 정정 절차는 추가 요구하지 않는다.
- 나머지는 질문과 공식 required_facts를 대조해 유지한다. ADD02 요청처·필수 전달 정보, ADD06 날짜·규격별 제출 창구, ADD09 운송사 포함 전달 대상·이전/새 번호·신규 접수 적용 기준은 생략하지 않는다.
- ADD12는 원래 근거 없는 추가 확인형이다. 29문항 근거 점수와 분리하고, 30문항 전체에서는 올바른 추가 확인 종료 여부로 함께 보고한다.
- 최종 반환 원문에 있는 연속 인용과 출처를 검증한다. 모델 충분 선언·계획 요약·참고답 자체는 근거가 아니다.
- 모든 검색 결과 저장 후, 같은 질문·같은 출처별 본문 지문인 출력은 한 번의 검수를 재사용한다. 조건명을 검수 모델에 주지 않는다. 모든 고유 최종 문맥을 같은 고정 기준으로 검수하며 오류·인용 불일치는 자체 대조한다. 독립 사람 검수가 아니다.
- 문항별 후보·최종 지정 근거, 의미상 전체 충족, 종료 상태, 호출·토큰·지연과 회복/유실을 기록한다. 진단 세 문항뿐 아니라 나머지 문항의 회귀도 보고한다.

## 권한과 한계

기존 .env 키·비용 한도 없음 승인(2026-11-13). 최대 계획1,080회+검수180회. 자동 재시도 없음. API 인증/한도 오류는 실행을 중단하고 완료 결과를 보존한다. API에는 질문·검색된 문맥·계획 지침, 사후 검수에는 고정 평가 기준과 최종 문맥이 전송된다. 비밀값은 기록하지 않는다.

기존 반복 사용 세트에서 문제를 발견하고 수정한 개발·회귀 실험이다. 새 검증 세트의 일반화·답변 정확도·운영 채택을 입증하지 않는다. 사이드 대화의 사용자 지침에 따라 하위 에이전트를 사용하지 않고 자체 검토한다.
