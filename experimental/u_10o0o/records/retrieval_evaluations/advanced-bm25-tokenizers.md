# Advanced BM25 토크나이저 비교

같은 복원 페이지 18,000쪽에서 일반 평가 60문항의 상위 3쪽을 검색했다. 근거 페이지가 있는 58문항을 채점했다. 두 실행의 페이지·질문·근거 파일 해시가 일치했고, bigram은 기존 기준선의 문항별 순위와 지표를 재현했다.

| 방식 | Hit@3 | Recall@3 | Precision@3 | 색인 생성 | CPU 검색 p50 | CPU 검색 p95 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| [Bigram BM25](advanced-bm25-bigram-page-top3-20261108-194056-559597/report.md) | 87.93% | 49.57% | 47.70% | 1.31초 | 43.5ms | 58.1ms |
| [Kiwi BM25](advanced-bm25-kiwi-page-top3-20261108-194207-443549/report.md) | 86.21% | 59.05% | 59.77% | 66.47초 | 66.1ms | 85.6ms |

Kiwi는 50문항, bigram은 51문항에서 근거를 찾았다. Kiwi만 적중한 문항은 1개, bigram만 적중한 문항은 2개였다.

## 실행 조건

두 방식에 BM25 k1=1.5, b=0.75를 적용했다. Kiwi는 kiwipiepy 0.24.1과 모델 0.24.0으로 형태소를 분석하고 소문자로 정규화했다. 글자와 숫자가 없는 토큰을 제외했다.

단일 CPU 작업으로 각각 한 번 측정했다. 색인 생성 시간에는 토크나이저 초기화가 포함된다. 검색 시간은 색인 생성 후 3문항 예열을 거쳐 질문 토큰화부터 Top 3 선택까지 측정했다.
