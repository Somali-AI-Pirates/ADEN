# Advanced 페이지 벡터 검색 기준선

모델 `dragonkue/snowflake-arctic-embed-l-v2.0-ko` · 페이지 단위 · 코사인 유사도 · 상위 3쪽

`development`와 `additional`은 Advanced의 일반 평가 묶음이며, 둘 다 같은 모델과 검색 조건으로 평가했다. `overall`은 두 묶음에서 근거가 있는 58문항을 모아 계산한 결과다.

| 묶음 | 전체 | 채점 | 제외 | Hit@3 | Recall@3 | Precision@3 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| overall | 60 | 58 | 2 | 0.6724 | 0.3305 | 0.2701 |
| development | 30 | 29 | 1 | 0.7241 | 0.3420 | 0.2759 |
| additional | 30 | 29 | 1 | 0.6207 | 0.3190 | 0.2644 |

근거는 `evidence_groups`에서 중복을 제거한 (문서 ID, 쪽 번호) 집합이다.
Hit은 일치 근거가 하나라도 있으면 1이다.
Recall은 일치 수를 근거 쪽 수로 나눈 값이다.
Precision은 상위 3쪽 중 근거와 일치한 비율이다.
근거 페이지가 있는 문항에 대해 지표별 단순 평균을 계산했다.

보관한 [results.json](results.json)에는 문항별 검색 순위·점수·지표와 입력 지문이 있다. 근거 위치 목록은 아카이브에서 제외했다.

## 실행 시간

원본 PDF 120개, 18,000쪽을 페이지별로 임베딩했다. 질문 임베딩과 코사인 유사도 전수 검색은 CPU에서 실행했다.

| 단계 | 전체 실행 시간 |
| --- | ---: |
| PDF 전처리 | 70.07초 |
| GPU 문서 벡터 생성 | 1256.66초 |
| CPU 검색 및 채점 | 12.59초 |

단계 시간에는 입력 읽기, 모델 로딩, 결과 저장이 포함된다. [실행 조건](runtime.json)

## CPU 검색 지연 시간

모델과 색인을 불러오고 3문항으로 예열한 뒤 60문항을 한 번씩 검색했다. 질문 임베딩부터 상위 3쪽을 고르기까지 p50은 100.4ms, p95는 113.7ms였다. 같은 60문항의 순위가 재현됐다.

문서의 최대 입력 길이는 897토큰이었고, 8,192토큰을 초과한 페이지는 0쪽이었다.
