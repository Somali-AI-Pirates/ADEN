## 해석 범위

이 시간은 API 대기를 제외한 로컬 재생 시간이다. 기존 12.31/33.53초에서 단순히 빼거나 새 서비스 지연이라고 부르지 않는다. API 없이 4개 요청을 계속 실행하는 부하이며 공유 GPU 상태도 기록했다. 반복 표본은 정답/성능을 보지 않고 세트별 ID 해시로 고정했다.
검색 일치는 후보 쪽 순서·표 후보·조회 경로·입력 길이 정보다. 점수의 미세 수치 차이는 허용하되 순위와 최종 입력은 별도로 검사한다. SQL은 실제 실행하고 값/출처가 동일한지 확인한 뒤, v5에서 근거 JSON에 포함했던 시간 메타데이터만 저장값으로 고정했다.
수치가 같아도 새 질문 전체에서 정확도가 보장됐다는 뜻은 아니다. 이번에는 기존 평가 입력과 모델 호출을 바꾸지 않는 로컬 실행 최적화를 검사했다.

독립 에이전트는 부대 대화에서 금지되어 자체 검토했다. 기본 실행·기준선은 변경하지 않았다.
