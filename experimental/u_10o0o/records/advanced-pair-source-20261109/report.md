# Advanced 두 사건 원문 조회 비교

개인 Advanced 기본 실행에 단일·모호 사건 원문 조회를 채택한다. 기존 조회와 선택 조건을 포함한 상황별 v2의 두 조회 설정을 재현하고, 같은 140문항에서 간접 대상이 있는 두 사건 비교의 원문 조회만 추가한 설정을 시험한다. 후보 20쪽·최종 최대 8쪽·8,000토큰과 기존 선택기는 공통으로 사용한다. 두 사건 조회는 실험 비교군에 둔다.

후속 실행에서는 이 보고서의 B를 개인 기본값으로 채택했다. 기본 명령 재현과 업무 절차·규정 및 범위 밖 대조를 포함한 결과를 별도로 기록한다. [채택 결정](../decisions.md#2026-11-09--두-사건-원문-조회를-개인-advanced-기준선에-채택) · [180문항 비교](../advanced-scenarios-180-20261109/report.md)

새 기준선 A는 앞선 실험에서 두 조회를 함께 켠 설정이다. 비교군 B는 질문의 첫 번째와 두 번째 대상을 별도 절로 읽는다. 번호가 없는 절에서는 화주·화물·규격의 교집합이 원문 색인에서 한 사건일 때 그 대상을 확정한다. 두 절이 각각 요청한 기록을 읽고, 두 대상을 소개한 뒤 `각각` 같은 범위 표현과 함께 요청하면 같은 기록 목록을 양쪽에 적용한다. 두 사건의 요청 쪽을 번갈아 후보 앞에 합치고 남은 순서를 유지한다. 필요한 쪽이 이미 최종 문맥에 모두 들어 있으면 A 문맥을 사용한다.

## 결과

| 범위 | 새 기준선 A | B 두 사건 원문 조회 | 동료 무 LLM | 개선 / 하락 |
| --- | ---: | ---: | ---: | ---: |
| 4번 · 두 대상 모두 번호 | 8/8 | 8/8 | 8/8 | 0 / 0 |
| 4번 · 번호와 원문 단서 혼합 | 4/6 | **6/6** | 2/6 | 2 / 0 |
| 4번 · 두 대상 모두 원문 단서 | 1/6 | **6/6** | 0/6 | 5 / 0 |
| **4번 합계** | **13/20** | **20/20** | **10/20** | **7 / 0** |
| 나머지 120문항 | 120/120 | 120/120 | 86/120 | 0 / 0 |
| **전체** | **133/140** | **140/140** | **96/140** | **7 / 0** |

값은 최종 8쪽·8,000토큰 문맥에서 전체 필수 근거를 충족한 문항 수다. 4번은 후보 단계부터 전체 근거가 **13/20 → 20/20**으로 늘었다. 최종 개별 근거는 **52/66 → 66/66**, 문항별 평균 페이지 Recall@8은 **80.00% → 100.00%**였다. 전체 140문항의 개별 근거는 **292/306 → 306/306**이었다.

간접 대상을 포함한 4번 12문항 모두에서 두 대상이 평가표와 일치했다. 그중 다섯 문항은 기존 문맥에 이미 필요한 쪽이 들어 있었다. 이전 미충족 7문항에서만 후보와 최종 문맥이 바뀌었고, 전체 또는 개별 근거를 잃은 문항은 없었다. 나머지 120문항은 후보 순서와 최종 문맥 지문이 같았다. [140문항 로그](questions.jsonl) · [유형별 집계](results.json)

| 개선 문항 | 대상 표기 | 최종 개별 근거 A → B |
| --- | --- | ---: |
| `AS-S04-10` | 혼합 | 2/4 → 4/4 |
| `AS-S04-13` | 혼합 | 2/4 → 4/4 |
| `AS-S04-15` | 두 간접 | 1/2 → 2/2 |
| `AS-S04-16` | 두 간접 | 1/4 → 4/4 |
| `AS-S04-18` | 두 간접 | 1/2 → 2/2 |
| `AS-S04-19` | 두 간접 | 1/4 → 4/4 |
| `AS-S04-20` | 두 간접 | 2/4 → 4/4 |

`AS-S04-10`과 `AS-S04-13`은 번호가 없던 상대 사건의 현장·청구 기록을 확보했다. `AS-S04-19`는 후보 9위에 있던 한 사건의 청구 기록과 후보에 없던 상대 사건의 두 기록을 모두 담았다.

## 실행과 해석 범위

기본 명령의 `--suite scenarios`에서 이전 두 조회 실험의 140문항 후보 순서와 최종 문맥 지문을 모두 재현했다. 기본 공식·holdout 340문항도 실행했다. 두 사건 실험은 기존 개인·동료 보관 순위를 재생하고 새 순위와 문맥을 저장한 뒤 참고 근거를 읽었다. 로컬 원문 색인을 사용했고 외부 API 호출은 0회였다. 동료 설정은 보관된 20청크를 페이지로 중복 제거한 결과를 사용했다. [기본 실행 안내](../../README.md#현재-advanced-구성) · [실행 로그](run.log)

공통 조회 함수로 옮긴 뒤 앞선 네 설정의 문항별 순위와 채점이 일치했다. 두 사건 실험을 두 번 실행해 같은 집계를 확인했다. 가상 문형 다섯 개에서 공통·개별 요청 연결, 번호 두 개, 기록 미지정, 간접 대상의 중복을 검사했다. Ruff와 pytest 160개 및 하위 검사 9개를 통과했다.

이 결과는 실패를 확인한 동일한 합성 평가 세트에서의 검색 검증이다. 두 대상을 순서 표현으로 구분한 문형과 화주·화물·규격이 각각 한 사건으로 좁혀지는 경우를 시험했다. 새 문형과 사람 검수 표본에서의 재현, 생성 답변 품질은 별도 범위다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.advanced_pair_source_ab \
  --output artifacts/u_10o0o/advanced-pair-source-check
```
