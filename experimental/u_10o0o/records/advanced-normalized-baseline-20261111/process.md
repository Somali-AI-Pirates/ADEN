# 코드 표기 정규화 기준선 채택과 공식 누락 분석

2026-11-11 사용자 요청: 앞선 BM25 코드 표기 정규화 조건을 개인 Advanced 기본 기준선으로 채택하고 공식 문항에서 놓친 근거를 분석한다. 구현은 기존 BM25 모듈에 정규화 토크나이저를 추가하고 Advanced PatternIndex 기본값을 연결한다. 이전 `bigram-id`는 비교군으로 유지하며, 앞선 실험의 원래 조건과 새 조건이 계속 분리되도록 실행 어댑터도 맞춘다. 문서·벡터·모델·제목 보너스·RRF·조회·후보 및 문맥 예산은 바꾸지 않는다.

현재 조건의 채택 근거는 코드 표기 변형 지원과 공식/카테고리 회귀 없음이다. 점수 향상을 입증한 변경으로 표현하지 않는다. 이전 실험 기록은 당시 결과로 보존한다. 기본 경로에서 280문항을 새로 실행하여 앞선 정규화 조건과 최종 문맥·후보가 같은지 확인한다. 이후 공식 58개 유효 문항의 누락 근거를 초기 검색, 조회 이후 목록, 최종 8쪽 선택으로 나눠 분석한다.

새 기본값이 적용될 코드의 변경 전 사본을 로컬 artifacts에 보존한다. 코드는 현재 작업 트리를 기준으로 필요한 부분만 수정하고 다른 대화의 변경을 덮어쓰지 않는다. 이 별도 대화의 제한에 따라 에이전트 위임은 하지 않고 자체 검토한다. 커밋·푸시·운영 API 변경·답변 생성·외부 모델 호출은 범위 밖이다.

## 완료 결과

- `bm25.py`에 `bigram-id-normalized`를 추가하고 `advanced_field_roles.TOKENIZER_NAME`으로 기본 토크나이저를 지정했다. 본문·제목 색인 및 질의가 같은 함수를 사용한다. `legacy_baseline`의 실행 metadata도 이 상수를 따르도록 맞췄다.
- 이전 `bigram-id`는 그대로 보존했다. `bm25_code_normalization`은 기본값이 바뀐 뒤에도 이전/정규화 색인을 각각 명시적으로 구성해 비교군이 같은 조건으로 변하지 않도록 했다. 정규화 구현은 `bm25.py` 한 곳에서 관리한다.
- 기본 경로에서 280문항을 실행한 `default-v1`은 앞선 정규화 실행과 초기 후보의 페이지·점수, 조회 후 순서, 실제 최종 문맥이 280개 모두 일치했다. 참고 근거를 읽기 전에 결과를 저장했다. 공식 근거 전체 충족 32/58, 페이지 Recall@8 77.01%, 카테고리 170/200을 유지했다.
- 공식 60개를 BM25·벡터 각각 다시 검색했고, 재구성한 RRF 후보가 저장된 기본 경로의 후보와 60개 모두 일치했다. 이 결과를 저장한 다음 정답 근거를 읽어 초기 검색기 누락과 RRF 탈락을 구분했다. 새 API 호출이나 리랭커 학습은 없었다.
- 실패 26문항의 정답 누락 36쪽은 두 검색기 Top20 바깥 18쪽, RRF 결합 탈락 3쪽, 최종 8쪽 밖 15쪽이었다. 문항 단위로는 후보 부족만 13개, 후보와 최종 선택 모두 부족 6개, 최종 선택만 부족 7개다.
- 최종 선택에서 빠진 근거가 있는 13문항은 모두 8쪽을 채웠고, 문맥이 3,716~5,905토큰이었다. KURE 순위에서도 9위 밖인 근거는 12쪽, KURE 4~8위지만 RRF 잔여 순서에서 밀린 것은 3쪽이었다.
- HG 역할 근거를 놓친 11문항을 실제 프로필 매처로 점검했다. 모두 화주 1개·화물 1개·장비 규격 0개, 날짜 2개였다. `AS-DEV22`의 “모두”와 `AS-ADD19`의 “전체”는 현재 복수 대상 정규식에도 걸린다. 여기서 조회 조건을 임의로 완화하거나 사건을 강제 확정하지 않았다.
- 누락 페이지의 정확한 출처·정답 인용은 private-missing-evidence.json에만 보존했다. 공유 문항별 기록은 업무 의미를 요약한 설명과 단계별 수량만 포함한다.

## 검증과 작업 경계

이 별도 대화에서는 독립 에이전트가 금지되어 `implementation-final-review`에 따른 자체 검토를 수행했다. 기존 토크나이저 유지, 새 기본값의 본문·제목 일치, 이전 비교군 유지, 기본 실행 재현, 정답과 검색 입력의 분리를 확인했다.

- 공통 `ruff check .`, 변경 Python 파일의 Ruff(E4/E7/E9/F/I), format --check 통과.
- 공통 `tests` + 개인 `experimental/u_10o0o/tests` + `pattern_retrieval/tests`: 최종 337 tests, 9 subtests 통과.
- 전체 개인 검사 첫 실행에서 다른 작업이 수정 중인 IS 윈도·semantic 실험 테스트 4개가 실패했다. 해당 파일들을 수정하지 않았고, 외부 변경이 반영된 뒤 같은 전체 명령을 다시 실행해 위 통과를 확인했다.
- BM25 CLI help에서 새 옵션을 확인했고, 기본 검색 실행과 공식 누락 진단 CLI를 실제 실행했다. 코드·질문·데이터·결과 지문과 보고서 링크를 확인했다.
- 공통 앱·API·패키징·원문·벡터·모델은 변경하지 않았다. 커밋·푸시는 하지 않았다. 별도의 답변 정확도 평가나 사람의 의미 동등성 판정은 수행하지 않았다.
