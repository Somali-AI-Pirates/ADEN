# Advanced 최종 8쪽 순위 비교 · 8,000토큰

질문 표현 비교에 사용한 Advanced 268문항을 다시 채점했다. 같은 36개 사건에 대한 원문식·일상식·대조 질문이 각각 36개, 기존 블라인드의 번호가 있는 답변형 질문이 160개다. 복원 원본 페이지를 최대 8쪽, 8,000토큰까지 문맥에 담았다. 검색과 문맥 조립에는 질문과 색인을 사용했고, 참고 근거는 조립 뒤 채점에만 사용했다. [이전 질문 표현 비교](../advanced-vocabulary-20261109/report.md)

## 비교 조건

| 설정 | 순위 결정 |
| --- | --- |
| 개인 기준선 | 제목 보너스 Bigram-ID BM25 후보 20쪽 → KURE nano 상위 3쪽 → 나머지는 BM25 순서 |
| KURE Top 3 + RRF | 제목 보너스 BM25·Snowflake-ko 5:5 RRF 후보 20쪽 → KURE 상위 3쪽 → 나머지는 RRF 순서 |
| KURE Top 3 + BM25 | 같은 RRF 후보 20쪽과 같은 KURE 상위 3쪽 → 남은 후보 중 BM25 상위 20쪽과 겹치는 쪽을 BM25 순서로 배치하고, 나머지는 RRF 순서 |
| KURE 전체 | 같은 RRF 후보 20쪽을 KURE 점수순으로 정렬 |
| RRF 순서 | 같은 RRF 후보를 1차 순서대로 사용 |
| 동료 v2 · API 제외 | `base+graph6+gfix+gfloor0.05+mmr0.2`. p800 청크에 E5-small·Bigram BM25·RRF, BGE 리랭킹, 문서 다양화 0.2, 식별자 그래프 확장 최대 6문서 적용 |

개인 설정은 모두 기존 명시·간접 HG 조회를 적용했다. 네 하이브리드 변형은 HG 조회 전 후보 20쪽의 구성원이 문항별로 같다. RRF는 두 검색 순위를 0.5씩 반영하고 상수 60을 쓴다. KURE 입력 한도는 기존 512토큰이다. 8,000토큰은 최종 문맥에 적용했다.

동료 v2에서 질문 분해(`mq_decomp`)와 근거 집합 선택(`sel30`)을 제외했다. 동료 검색의 정렬 단위는 p800 청크다. 비교표에서는 정렬 결과 20청크를 고유 PDF 페이지로 합치고 같은 복원 페이지를 사용해 최대 8쪽·8,000토큰으로 채점했다. 동료의 원래 p800 문맥과 비교표의 문맥 단위는 다르다. [동료 단계별 설정](../../../ysl727727/overnight/table2.py), [동료 보고서](../../../ysl727727/overnight/REPORT_v2.md)

## 결과

문항별 필수 근거를 모두 확인할 수 있는 경우를 충족으로 집계했다. 문서 Recall@8은 문항별 정답 문서 비율의 평균이며, 페이지 Recall@8은 전체 문항의 정답 페이지 합계 403쪽 중 실제 문맥에 포함된 비율이다.

| 설정 | 원문식 36 | 일상식 36 | 대조 36 | 번호 160 | 전체 268 | 문서 Recall@8 | 페이지 Recall@8 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 개인 기준선 | 36 | 25 | 36 | 160 | 257 | 96.08% | 97.02% |
| KURE Top 3 + RRF | 36 | 30 | 36 | 156 | 258 | 98.00% | 97.52% |
| **KURE Top 3 + BM25** | **36** | **31** | **36** | **160** | **263** | **98.69%** | **98.76%** |
| KURE 전체 | 36 | 31 | 36 | 148 | 251 | 97.44% | 95.78% |
| RRF 순서 | 36 | 28 | 36 | 146 | 246 | 96.96% | 94.29% |
| 동료 v2 · API 제외 | 35 | 28 | 32 | 158 | 253 | 96.46% | 95.78% |

- **같은 RRF 후보 20쪽에서 BM25 순서를 뒤에 쓰면** RRF 순서를 그대로 쓸 때 놓친 번호 질문 4개와 일상식 질문 1개를 회복했다. 새로 놓친 질문은 없었다. 개인 기준선 대비 일상식 7개를 새로 충족했고 1개를 놓쳤다. 번호 160개는 모두 유지했다.
- **KURE 전체 재정렬**은 일상식에서 31/36으로 같은 수를 충족했지만, 번호 질문에서 148/160으로 떨어졌다. 두 설정의 번호 질문 정답 페이지는 최초 RRF 후보에 271/271쪽 모두 있었다. 이 차이는 후보 확보 뒤에 생겼다.
- **8,000토큰에서 예산으로 제외된 페이지는 0개**였다. 모든 설정과 질문을 합쳐 가장 긴 문맥은 5,896토큰이었다. 기존 `Top 3 + RRF`의 번호 질문은 4,000토큰에서 154개, 8,000토큰에서 156개를 충족했다. 8,000토큰에서도 남은 4개는 최종 8쪽 순서의 영향을 받았다.
- 동료 무 API 설정은 번호 158/160, 일상식 28/36을 충족했다. 동료 청크 5,360개가 중복 제거 후 페이지 5,316쪽에 대응했고, 복원 페이지 누락은 0건이었다.

이 평가에서는 `5:5 RRF 후보 → KURE Top 3 → BM25 순서`가 가장 높은 전체 근거 충족률을 보였다. 이전 실패 사례를 포함한 같은 표본에서 비교한 결과이므로, 별도 표본이나 실제 답변 정확도로 일반화할 수 없다. [집계 데이터](results.json) · [실행 로그](run.log)

## 공식 60문항과 동료 304문항

같은 여섯 설정을 과제 제공 Development·Additional 각 30문항과 동료 Advanced 304문항에 적용했다. 기존 268문항과 합쳐 632문항을 검색했다. 공식 세트에서 근거 라벨이 없는 2문항은 검색만 하고 근거 지표는 58문항으로 집계했다. 동료 세트는 거짓 전제 20문항, 2문서 합성 114문항, 3~4문서 합성 170문항으로 나눴다. 2문서 세트의 모호 표시 45문항은 전체에 포함하고 따로도 집계했다. [동료 문항과 원문 인용 감사](../advanced-target-retrieval-20261109/report.md#원본-대조와-검수-자료)

공식과 동료 세트의 전체 근거 충족은 최종 문맥에 각 근거 그룹의 인용이 하나 이상 들어온 문항을 센다. 동료 인용은 기존 감사에서 확인한 같은 쪽의 원본 줄 재연결을 적용한다. 기존 268문항은 사실별 기본·대체 근거 묶음으로 채점했으므로 세 점수를 나눠 기록한다.

정답 쪽만 문맥에 넣어 채점 경계를 확인했다. 동료 304문항은 전부 충족했다. 공식 세트는 정답 쪽이 모두 들어간 경우에도 2문항에서 제공 인용문과 복원 텍스트가 일치하지 않아 56/58이었다. 공식 세트의 인용 그룹 충족 수는 제공 인용문 기준으로 기록하고 문서 Recall@8을 함께 제시한다.

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 개인 기준선 | 257/268 | 34/58 | 88.07% | 153/304 | 67.41% | **148/259** |
| KURE Top 3 + RRF | 258/268 | 32/58 | 85.34% | 129/304 | 65.57% | 121/259 |
| KURE Top 3 + BM25 | **263/268** | 36/58 | 89.37% | **155/304** | **68.26%** | 146/259 |
| KURE 전체 | 251/268 | 29/58 | 85.49% | 131/304 | 66.26% | 124/259 |
| RRF 순서 | 246/268 | 31/58 | 85.06% | 113/304 | 60.91% | 110/259 |
| 동료 `team_graph` · API 단계 제외 | 253/268 | **48/58** | **96.84%** | 136/304 | 66.26% | 133/259 |

| 설정 | 별도 거짓 전제 20 | 2문서 114 | 3~4문서 170 | 모호 표시 45 |
| --- | ---: | ---: | ---: | ---: |
| 개인 기준선 | 18 | 54 | **81** | 5 |
| KURE Top 3 + RRF | **19** | 53 | 57 | 8 |
| KURE Top 3 + BM25 | 18 | **58** | 79 | **9** |

| RRF 순서 | **19** | 44 | 50 | 3 |
| 동료 `team_graph` · API 단계 제외 | 16 | 53 | 67 | 3 |

- **공식 세트**에서는 동료의 `team_graph`가 전체 인용 그룹과 문서 Recall@8 모두 가장 높았다. 개인 설정 중 `Top 3 + BM25`는 기준선 대비 3문항을 새로 충족하고 1문항을 놓쳤다.
- **동료 세트**에서 `Top 3 + BM25`는 개인 기준선보다 전체 2문항을 더 충족했다. 모호 표시 45문항에서 4개 늘었고, 나머지 259문항에서는 2개 줄었다. 3~4문서 질문에서 기준선이 81개, `Top 3 + BM25`가 79개였다. 정상·거짓 전제 변형이 같은 정답 근거를 공유하는 합성 쌍도 있어 이 수치를 독립적인 실사용 질문으로 해석하기는 어렵다.
- **같은 하이브리드 후보에서 뒤쪽을 BM25 순서로 정렬한 효과**는 두 추가 세트에서도 확인됐다. `Top 3 + RRF` 대비 공식은 4문항, 동료 세트는 26문항을 더 충족했다. 공식과 모호 표시 제외 동료 세트의 결과까지 보면 개인 기준선 교체에 대한 증거는 세트별로 갈린다.

추가 364문항은 269.4초에 실행됐다. 여섯 설정의 문맥 2,184개가 모두 최대 8쪽·8,000토큰 이하였다. 가장 긴 문맥은 7,127토큰이었고, 예산으로 제외된 페이지와 동료 복원 페이지 누락은 0건이었다. 모든 하이브리드 비교군의 후보 집합이 질문별로 일치했다. 문서 Recall@8은 공통 평가기와 같은 값으로 확인했다. 외부 API 호출은 0회였다. [공식·동료 결과 데이터](reference-suites-results.json) · [추가 실행 로그](reference-suites-run.log)

## 문서와 페이지 Recall@8

최종 문맥에서 문서는 `book_id`, 페이지는 `(book_id, page)`로 비교했다. 아래 표에서는 두 지표 모두 문항별 Recall의 평균이다. 앞 표의 페이지 Recall@8은 정답 페이지 수를 모두 합친 비율이다. 이 표는 보관된 문항별 검색 결과로 다시 집계했다.

| 설정 | 기존 268 문서 | 기존 268 페이지 | 공식 58 문서 | 공식 58 페이지 | 동료 304 문서 | 동료 304 페이지 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 개인 기준선 | 96.08% | 96.08% | 88.07% | 79.89% | 67.41% | 62.97% |
| KURE Top 3 + RRF | 98.00% | 98.00% | 85.34% | 77.01% | 65.57% | 59.65% |
| KURE Top 3 + BM25 | **98.69%** | **98.69%** | 89.37% | 82.04% | **68.26%** | **63.24%** |
| KURE 전체 | 97.44% | 97.06% | 85.49% | 75.86% | 66.26% | 59.32% |
| RRF 순서 | 96.96% | 93.97% | 85.06% | 74.43% | 60.91% | 54.96% |
| 동료 `team_graph` · API 단계 제외 | 96.46% | 94.78% | **96.84%** | **88.94%** | 66.26% | 59.24% |

공식 58문항의 정답 페이지를 합친 170건 중 동료 `team_graph`는 154건, `Top 3 + BM25`는 145건, 개인 기준선은 143건을 확보했다. 동료 304문항에서 모호 표시 45문항을 빼면, 페이지 Recall의 문항 평균은 개인 기준선 67.73%, `Top 3 + BM25` 67.47%였다.

[문항별 페이지 누락 분석](official-page-diagnosis.md)에 공식 복합질문의 전체 근거 충족률, 개인 후보·최종 순위의 누락 위치, 동료 식별자 연결을 켜고 끈 결과를 정리했다. 동료 304문항 중 4문서 합성 78개는 나머지 226개와 분리해 동료 보고서 기준으로 비교했다.

## 재현

기존 [질문 표현 비교의 재현 절차](../advanced-vocabulary-20261109/report.md#실행과-재현)에서 만든 질문, 참고 근거, 후보 순위를 사용한다. 질문·근거·원문·색인의 해시를 맞추고, KURE는 이전 실행과 같은 후보와 배치 순서로 다시 점수를 계산한다. 동료 색인의 PDF 추출과 E5 문서 벡터를 기존 로컬 색인에서 복사하고 BGE 점수는 새로 계산한다. 두 모델 모두 로컬 GPU를 사용한다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.advanced_rank_policy \
  --data artifacts/u_10o0o/advanced-vocabulary-20261109-data-verified \
  --archive artifacts/u_10o0o/advanced-vocabulary-20261109 \
  --output artifacts/u_10o0o/advanced-rank-policy-8000-replay \
  --context-tokens 8000
```

개인 기준선과 `Top 3 + RRF`의 기존 4,000토큰 문맥 536개에서 최종 순서와 문맥 지문이 일치했다. 네 하이브리드 변형의 RRF 후보가 268문항 모두에서 동일함을 확인했다. 여섯 설정의 문맥 1,608개가 모두 8쪽·8,000토큰 이하였다. 외부 API 호출은 0회였고 검색·채점에 172.8초가 걸렸다. Ruff와 pytest 160개 및 하위 검사 9개가 통과했다.

공식·동료 세트는 [원본 인용 감사 절차](../advanced-target-retrieval-20261109/report.md#재현)에서 생성한 인용 감사 파일을 사용한다. 공식·동료 질문의 BM25와 Snowflake 질의 벡터, RRF 후보, KURE 순위를 새로 계산한다. 기준선과 하이브리드가 공유하는 질문·페이지의 KURE 점수는 한 번만 계산한다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.advanced_rank_policy \
  --quote-audit artifacts/u_10o0o/advanced-evidence-audit-20261109-canonical/peer_quote_audit_private.json \
  --output artifacts/u_10o0o/advanced-rank-policy-8000-reference-suites-replay \
  --context-tokens 8000
```
