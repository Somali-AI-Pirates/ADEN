# 기대 ID와 실제 사건 연결을 구분한 점검

동결 채점기의 `relation_wrong_count`는 예상 ID 집합 밖에 있는 앵커 수다. 다른 사건으로 연결했는지를 원문 의미로 판정하는 검사와는 다르다. 원래 점수와 골드는 수정하지 않았다.

| 세트 | 기대 ID 평가 문항 | ID 집합 일치 | 기대 ID 밖 연결 문항 |
|---|---:|---:|---:|
| 개발 | 54 | 53 | 1 |
| 검증 | 42 | 40 | 0 |

DEV-126의 C 앵커는 질문이 가리킨 DL 기록 ID에서 원문에 함께 적힌 GR 예약 키로 연결됐다. 독립 원문 대조에서 별도 사건으로 넘어간 것이 아니라 같은 예약을 서로 다른 ID로 표시한 것으로 확인했다. 이1건을 실제 다른 사건 오확정1건으로 해석하지 않는다. 원문의 출처는 AS023:002와 같은 예약 키가 연결된 관련 쪽들이다. 상세 원문은 로컬 `private/diagnostic-dev126.md`에만 보관한다.

검증의 FRESH-VAL-015/030은 기대 대상이 있지만 C가 명시 관계 대상을 찾지 못했다. 두 문항 모두 원래 B 검색을 사용해 최종 필수 근거는 충족했다. 따라서 관계 기능의 ID 미인식과 전체 검색의 근거 누락도 구분해야 한다.

C가 실제로 새 후보를 넣은 문항은 개발43·검증33개이며, 단순히 대상 ID가 연결된54·41개와 다르다. 해당 집계는 [stage-diagnosis.md](stage-diagnosis.md)를 따른다.

모호성20문항은 일반 근거 충족률 분모에서 제외했다. 질문에 확실한 ID는 있지만 요청한 값이 없는 경우에는 대상 연결을 별도로 평가하며, 목표가 없는 빈 집합을 맞혔다고 성공을 주지 않는다. 답변·보류 판단·계약 효력 판정은 구현하지 않았다.
