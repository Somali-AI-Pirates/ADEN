# 진행 기록

## 1. 비교 경계 확인

- 이전 조사에서 구분한 “코드 표기 정규화”, “유일한 사건 식별”, “기록 역할”, “IS 규정 검색”을 각각 추적하도록 범위를 고정했다.
- 개인 기본 실행은 결정론적 원문 조회를 사용한다. 최근 24문항 보고서의 A는 Luna+SQLite 경로이므로 이번 기본 실행과 같은 이름으로 집계하지 않는다.
- 기준선 소스는 수정하지 않는다. 새 진단 실행기가 기존 BM25, Snowflake, RRF, KURE, 원문 조회와 문맥 조립 함수를 호출한다.

## 2. 입력 작성과 분리

- 별도 에이전트에 검색 결과를 보지 않는 고정 시드 표본 작성을 맡겼다.
- 다른 에이전트는 보관된 혼합 6문항의 출처와 질문 절, 이전 계획 질의를 대조했다.
- 질문 파일과 정답·인용 파일을 분리했다. 공유 기록에는 질문과 원문을 복사하지 않는다.
- 간접 단서의 유일성과 정보 부족 질문의 다중 후보 여부를 전체 사건 집합에서 확인한다. 표기 변형은 원래 완전 코드로 복원되는 경우만 포함한다.

## 3. 실행기 점검

- 조회가 실제 실행된 경로와 참고용 계획기의 인식 결과를 구분했다. 이번 인식 지표에는 실제 원문 조회 경로를 사용한다.
- 최종 후보 순서와 실제 전달 문맥을 구분했다. 원문 조회 후 후보는 최대 20쪽, 문맥은 최대 8쪽이다.
- IS 진단은 책 범위가 아닌 검증된 3,750쪽을 사용한다. 전체 코퍼스의 BM25 IDF·길이 정규화·제목 보너스 적용 대상을 유지한 채 IS 쪽만 선택한다.
- 확장 BM25 진단 순위의 상위 20쪽이 기존 검색과 일치하는지 실행 중 검사한다.

- 실행 전 확인: 혼합 6문항 × 원문·원문 IS절·이전 계획 질의의 18개 입력에서, 확장 진단 순위의 상위 20쪽과 기존 `PatternIndex.fielded(top_k=20)`의 페이지·점수가 모두 같았다. 범위 제한으로 BM25 색인을 다시 만들지 않는다.

- 독립 실행기 리뷰에서 지적한 두 평가 경계를 수정했다. 정보 부족 질문의 단일 오확정과 복수 확정을 별도 집계하고, 조회가 읽는 정제 레코드 및 식별자·문맥 코드 지문을 추가했다. 입력 지문을 읽기 전후로 비교하며 24그룹×6조건과 혼합 6문항의 구조를 모델 준비 전에 확인한다.
- 이전 혼합 기록의 해석도 점검했다. H-C08은 계획 검색이 최초 후보만 개선했고 최종 문맥은 두 조건 모두 이미 충족했다. 대체 근거가 등록되지 않았다는 사실은 코퍼스에 다른 유효 근거가 없다는 뜻이 아니므로 제한으로 남겼다.

## 4. 입력 고정과 독립 검수

- 24사건·144문항을 생성했다. HG/HL/CT/EV 각 6건, 청구·수납·현장 역할 각 8건, 장비 규격 두 종류 각 12건이다.
- 날짜로 식별하는 12건은 청구·수납을 요청하게 하여, 질문에 이미 준 날짜를 답으로 다시 묻지 않도록 했다.
- 독립 리뷰에서 표본 생성기의 도달 불가능한 역할·규격 검사와 불필요한 import 경로 수정을 발견해 바로잡았다. 실제 표본 선택을 다시 실행해 대상 집합이 같음을 확인했고 질문·참고 파일 바이트는 그대로 유지했다.
- 독립 검수자는 96개 코드 표기의 역복원·유일 연결, 간접 24건의 유일성, 불충분 24건의 전체 후보 집합을 다시 계산했다. 원본 PDF 50개 해시와 지정 쪽의 324개 인용도 대조했다. 검색 결과는 보지 않았다.
- 요청 근거 채점은 requested_fact에만 적용했다. 프로필·식별 날짜·다른 사건의 인용은 질문 검수 자료이며 필수 반환 근거에 넣지 않았다.

- HF_HUB_OFFLINE와 TRANSFORMERS_OFFLINE을 사용했다. 외부 API 0회, 답변 생성 0회.
- 18,000쪽·2,730사건을 준비한 뒤 순차 검색했다. 약 67초에 완료했다.
- 모든 검색 순위·문맥 파일을 저장한 다음 참고 근거를 읽었다. 실행 전후의 입력·기준선 소스 지문이 모두 같았고, 최초 후보 20쪽·최종 8쪽·8,000토큰을 넘지 않았다.

- 혼합 질문의 원문은 HG 최종 6/6, IS 최종 1/6이다. 원문 IS 요청 절만 검색하면 IS 4/6, 이전 계획 검색어면 3/6이다. 이는 규정 검색 진단이며 혼합 문맥 전체의 새 성능이 아니다.
