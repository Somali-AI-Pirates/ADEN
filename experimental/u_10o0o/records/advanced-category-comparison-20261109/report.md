# Advanced 전체 평가 카테고리별 비교

상황별 140문항, 업무 규정 20문항, 일상 표현 40문항과 범위 밖 대조 20문항을 집계한다. 기존 180문항의 5:5 하이브리드를 추가 실행하고 개인 기준선 순위와 문맥을 보관 결과와 대조했다. 동료 `team_graph` 무 LLM은 보관 문맥을 다시 조립했다. 일상 표현 40문항은 이미 같은 세 설정으로 실행한 점수를 사용했다. [평가 가이드](../../evaluation/advanced_scenarios/README.md)

## 근거형 카테고리

표는 필수 근거를 모두 확보한 문항 수다. 화살표는 원문 조회 적용 전의 최초 후보에서 최종 문맥으로의 변화를 나타낸다. 최종 조건은 최대 8쪽·8,000토큰이다. 동료는 20청크를 뽑은 뒤 쪽 단위로 중복 제거했다.

| 카테고리 | 이전 BM25 후보 → 최종 | 5:5 하이브리드 후보 → 최종 | 동료 무 LLM 후보 → 최종 |
| --- | ---: | ---: | ---: |
| 1. 직접 조회 | 20/20 → 20/20 | 20/20 → 20/20 | 20/20 → 20/20 |
| 2. 번호 없이 한 사건 식별 | 8/20 → 20/20 | 10/20 → 20/20 | 6/20 → 6/20 |
| 3. 한 사건의 여러 기록 연결 | 20/20 → 20/20 | 20/20 → 20/20 | 20/20 → 20/20 |
| 4. 서로 다른 사건 비교 | 10/20 → 20/20 | 10/20 → 20/20 | 11/20 → 10/20 |
| 5. 적용 기록·조건 판정 | 20/20 → 20/20 | 20/20 → 20/20 | 20/20 → 20/20 |
| 6. 대상이 모호해 추가 확인 필요 | 0/20 → 20/20 | 0/20 → 20/20 | 0/20 → 0/20 |
| 7. 대상은 명확하지만 확정 근거 부족 | 20/20 → 20/20 | 20/20 → 20/20 | 20/20 → 20/20 |
| 업무 규정 · 절차·필요 서류 | 8/10 → 8/10 | 9/10 → 9/10 | 9/10 → 9/10 |
| 업무 규정 · 적용 조건·예외 | 8/10 → 7/10 | 9/10 → 8/10 | 8/10 → 7/10 |
| 일상 표현 · 한 문서 업무 절차 | 3/10 → 3/10 | 6/10 → 6/10 | 3/10 → 2/10 |
| 일상 표현 · 한 문서 적용 조건 | 2/10 → 2/10 | 5/10 → 4/10 | 3/10 → 3/10 |
| 일상 표현 · 여러 문서 업무 단계 | 2/10 → 2/10 | 2/10 → 2/10 | 2/10 → 2/10 |
| 일상 표현 · 여러 문서 조건 결합 | 1/10 → 0/10 | 1/10 → 1/10 | 2/10 → 2/10 |
| 근거형 전체 | 122/200 → 162/200 | 132/200 → 170/200 | 124/200 → 121/200 |

5:5 하이브리드는 최종에서 9문항을 개선하고 1문항을 놓쳤다. 상황별 140문항은 두 개인 설정 모두 전부 충족했고, 업무 규정은 15/20 → 17/20, 일상 표현은 7/40 → 13/40이었다. 개별 필수 근거는 이전 BM25 344/395, 하이브리드 356/395, 동료 무 LLM 265/395다. [카테고리 집계](results.json) · [점수 원본](scores.jsonl)

## 범위 밖 대조

완전히 무관한 질문 10개와 물류 업무와 유사한 질문 10개에서 세 설정 모두 문항당 8쪽씩 반환했다. 대조군에는 정답 근거가 없어 위 표의 분모에서 분리했다.

## 재현

기존 180문항에서 개인 기준선의 최초 후보 순서, 조회 후 후보 순서, 최종 쪽과 문맥 지문을 재현했다. 동료는 보관 순서로 같은 문맥을 조립했다. 5:5 RRF는 BM25와 Snowflake-ko 각 20쪽, 상수 60을 사용했고 이후 KURE nano·HG·원문 조회는 기준선과 동일하다. 순위를 저장한 뒤 참고 근거를 읽었다. 일상 표현의 입력 지문과 설정을 확인해 기존 40문항의 점수를 합쳤다. 외부 API 호출은 0회였다. [실행 로그](run.log) · [일상 표현 실험](../advanced-semantic-queries-20261109/report.md)

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.evaluation.advanced_scenarios.compare_categories \
  --output artifacts/u_10o0o/advanced-category-comparison-check
```

## 기준선 채택 후 기본 실행 검증

5:5 하이브리드를 개인 기본값으로 채택했다. `--suite categories`로 220문항을 다시 실행해 위 표의 하이브리드 후보·최종 점수를 전부 재현했다. 최초 후보 순서와 최종 문맥에 담긴 페이지 집합은 220문항에서 일치했다. [실행 방법](../../evaluation/advanced_scenarios/README.md#개인-기준선의-카테고리별-220문항-실행)

기본 실행은 하이브리드 후보만 KURE로 리랭킹한다. 앞선 A/B는 BM25 후보를 먼저 리랭킹한 뒤 겹치는 페이지의 점수를 재사용했다. 두 방식에서 `AS-S01-02`의 최종 문맥 3~6번째 페이지 순서가 달라 문맥 지문은 219/220문항에서 일치했다. 해당 문항의 페이지 집합과 근거 충족은 같았다.

`--suite categories --compare`에서도 두 개인 설정의 점수를 재현했다. 이전 BM25는 162/200, 하이브리드는 170/200이었고 두 설정 모두 보관 순서와 최종 문맥 지문이 220/220문항에서 일치했다. 외부 API 호출은 0회였다. [검증 집계와 파일 지문](baseline-reproduction.json) · [기본 및 비교 실행 로그](baseline-reproduction.log)

팀원 열은 기존 무 LLM 기록을 사용했다. 범위 밖 대조는 반환 쪽 수를 확인했다.
