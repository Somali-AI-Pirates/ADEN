# Advanced 리랭커 CPU 비교

Advanced 원본 PDF에서 복원한 18,000쪽과 Development·Additional 60문항을 사용했다. 검색은 60문항 모두 수행하고, 근거가 있는 58문항에서 고유 `(문서 ID, 쪽)` 단위로 지표를 집계했다.

Kiwi BM25와 Snowflake-ko에서 각각 상위 20쪽을 찾았다. RRF 상수 60과 가중치 0.6 / 0.4로 결합하고, 결합 순위 상위 20쪽을 문항마다 고정했다. 리랭킹 기준선은 이 순위의 상위 3쪽이다. 리랭커에는 고정한 페이지 본문과 질문을 전달하고, 정답 라벨은 채점에 사용했다.

Intel Core Ultra 9 275HX CPU, PyTorch FP32, 8스레드, 입력 상한 512토큰, 추론 배치 8로 비교했다. 각 검색·리랭킹 단계에서 3문항을 예열했다. 지연 시간은 예열 뒤 60문항을 순차 실행해 측정했다. 모델 버전·입력 지문과 실행 조건은 [설정](config.json) 및 개별 결과에, 시각별 진행 내역은 [실행 로그](run.log)에 기록했다.

## 후보 커버리지

[고정 후보](candidates/report.md)의 Hit@20은 94.83%로 55문항에서 근거를 찾았다. Recall@20은 83.76%다. 이 후보를 사용한 Top 3 리랭킹의 Hit 상한은 55문항이다.

## 최종 Top 3

적중 증감은 같은 문항의 RRF Top 3와 비교한 값이다. 각 모델의 `results.json`에 새로 적중한 문항과 적중을 잃은 문항 ID를 기록했다.

| 방식 | 적중 | Hit@3 | Recall@3 | Precision@3 | 적중 추가 / 상실 |
| --- | ---: | ---: | ---: | ---: | ---: |
| [Kiwi BM25 단독](kiwi/report.md) | 50 / 58 | 86.21% | 59.05% | **59.77%** | — |
| [Kiwi + Snowflake-ko RRF 6:4](rrf/report.md) | 51 / 58 | 87.93% | 51.44% | 48.28% | — |
| [RRF + BAAI BGE](BAAI-bge-reranker-v2-m3/report.md) | 54 / 58 | 93.10% | 53.30% | 49.43% | 3 / 0 |
| [RRF + KURE nano](nlpai-lab-KURE-Reranker-nano/report.md) | **55 / 58** | **94.83%** | **60.20%** | 56.32% | 4 / 0 |
| [RRF + Horizon small](Horizon-Labs-multilingual-reranker-small/report.md) | **55 / 58** | **94.83%** | 57.76% | 53.45% | 4 / 0 |

세 리랭커 모두 RRF 기준선이 적중한 51문항을 유지했다. KURE와 Horizon은 근거가 후보에 들어온 55문항 전체에서 최종 Top 3에 근거를 올렸다. KURE는 Kiwi 단독과 비교해 5문항을 더 적중했고, Recall@3는 1.15%p 올랐으며 Precision@3는 3.45%p 낮았다.

## CPU 지연과 입력 길이

검색과 리랭킹은 각각 실측했다. 리랭커 행의 전체 검색 지연은 같은 문항의 RRF 검색 시간과 리랭킹 시간을 더한 뒤 집계한 추정치다. 모델 로딩과 Kiwi 색인 생성은 지연 시간 집계와 분리했다. 입력 상한 초과 수는 잘라내기 전 각 모델의 토크나이저로 계산했다.

| 방식 | 리랭킹 p50 / p95 | 전체 검색 p50 / p95 | 512토큰 초과 쌍 |
| --- | ---: | ---: | ---: |
| Kiwi BM25 단독 | — | 0.077 / 0.096초 실측 | — |
| RRF 6:4 | — | 0.212 / 0.352초 실측 | — |
| BAAI BGE | 13.53 / 16.22초 | 13.66 / 16.62초 추정 | 500 / 1,200 (41.67%) |
| KURE nano | 5.31 / 5.79초 | 5.52 / 6.03초 추정 | 564 / 1,200 (47.00%) |
| Horizon small | 2.21 / 2.37초 | 2.40 / 2.67초 추정 | 1,198 / 1,200 (99.83%) |

## 판단

KURE nano를 품질 후속 검증 후보로 둔다. 세 리랭커 중 Recall@3와 Precision@3가 가장 높았고 후보 Hit 상한에 도달했다. Horizon small은 추가 지연이 가장 짧았고 KURE와 적중 수가 같았다. Horizon은 동일한 512토큰 상한에서 본문이 잘린 쌍이 많아, 페이지 입력 길이의 영향을 함께 고려해야 한다.

서버 기본 채택은 보류한다. KURE의 Kiwi 단독 대비 Recall 개선은 1.15%p였고, Precision과 CPU 지연에는 비용이 있었다. Advanced 60문항은 이전 가중치 선택에도 사용했다. 운영 채택 판단에는 새 문항과 실제 서버 청크·문맥 예산에서의 답변 품질과 요청 지연 측정이 필요하다. [선택 기록](../decisions.md)
