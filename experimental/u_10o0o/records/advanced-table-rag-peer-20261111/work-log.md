# TableRAG 동료 304문항 비교 — 범위와 과정

## 고정 범위
사용자는 동료가 만든 여러 문서 조합 문항도 같은 TableRAG 비교로 실행하고, 자동 실패 판정의 실제 대체 근거를 검토하도록 요청했다. 개인 실험 기록 아래 전용 실행기와 새 artifacts 경로만 추가한다. 기존 기본값·운영 API·다른 사람의 코드·데이터·과거 결과는 변경하지 않는다. 기존 Retriever/KureV2Retriever, TableAgent 및 문맥 조립 경로를 재사용한다. 새 모델·새 프롬프트·후보 확대·답변 생성·추가 튜닝은 지원 범위 밖이다.

질문 파일만 읽어 동료 304문항(거짓 전제20, 두 문서 계열114, 다문서170)을 고정한다. 두 문서 계열은 기존 모호성 항목을 별도 표시하고, 다문서는 채점 단계에서 요구 문서 수별로 나눈다. 검색 입력은 질문으로 제한한다. 계획 모델은 현재 질문과 검색 중 확보한 발췌·표 설명·도구 결과를 사용하며, 참고 정답은 두 설정의 모든 결과 저장 후 읽는다.

- A: 기존 TableRAG v5 검색(KURE-v3, 임베딩/리랭커2048/2048).
- B: 직전 별도 실험(KURE-v2 MaxSim, 질문128/floor64, 리랭커1024).
- 공통: GPT-6 Luna medium, 5:5 RRF k60, 검색별 후보20쪽, 최종8쪽·8000토큰(SQL 포함), 동시4.
- API 키·예산: 이 대화에서 승인한 기존 .env 키, 비용 상한 없음. 최대3648회 계획 호출, 자동 재시도와 답변 생성 없음.
- A→B 순서로 각각 새 계획을 실행한다. API 응답은 동일하게 강제하지 않으므로 모델 계획 변동도 포함되는 전체 경로 비교다. 두 조건의 기기 배치도 다르므로 임베딩 모델만의 인과 효과로 해석하지 않는다.
- GPU 유휴 상태 확인 후 실행. 색인 재생성 없음.
- 자동 지표: 지정 문서/쪽 Recall, 필수 근거 그룹 전체 회수, 실제 반환 인용.
- 사후 검토: 실제 최종 문맥·유지된 SQL만 사용. 대상·시점·조건·수치가 다른 사건으로 대체하지 않는다. 충분/부분·부족/질문·범위 모호를 분리한다. 지정 페이지 지표 자체는 덮어쓰지 않는다.
- 독립 리뷰는 이 사이드 대화의 위임 금지에 따라 미실시. 자체 점검과 실행·출처 검증을 수행한다.

## 준비
직전 B 실행과 현재 런타임 파일의 지문이 모두 일치한다. A의 과거 실행 대비 일부 공통 파일이 변경되어 있지만, 직전 A/B 비교에서 검증한 현재 공통 Retriever를 두 조건에 같이 사용한다. 실행 코드와 입력 지문은 새 경로에 보존한다.

준비 단계의 import 정렬 검사 후 v2 경로로 실행 코드를 다시 고정했다. v1은 준비 메타데이터만 있으며 모델 호출·결과가 없는 미실행 경로다.

실패 사후 검수 기준을 검색 완료 전에 review.py에 고정했다. 실패 문항은 Luna medium으로 최종 반환 근거만 인용하게 하고, 로컬에서 모든 인용의 존재를 검사한 뒤 보정 후보를 직접 재검토한다. 이는 답변 생성·독립 사람 검수가 아니다. 최대608회 추가 검수 호출이며 실제 실패 건만 실행한다. API 키·무제한 비용 승인은 같은 대화의 검색/평가 요청에 적용한다.

## 검색 완료
A/B 각각 304문항 저장과 입력·런타임 지문 검증 후 정답 파일을 처음 파싱했다. 계획 API 호출은 A 773회, B 809회이며 API 오류는 모두 0회다. 지정 페이지 기준 실패 260개 arm-context를 사후 검수 대상으로 고정했다.

실행 후 자체 점검에서 로컬 실행기의 인증/속도 제한 중단 조건이 문자열 status 대신 실제 http_status를 읽어야 함을 수정했다. 이번 실행은 해당 오류가 0건이어서 점수 영향이 없다. 실행 당시 코드는 artifacts/v2/executed-code에 보존하며, 수정 후 실행기를 이번 실행 코드와 동일하다고 주장하지 않는다.

## 사후 검수와 결론
260개 실패 결과(142개 고유 문항)를 GPT-6 Luna medium으로 검수했다. 검수 API 오류0회. 자동 충분58건은 모두 원문 인용·대상·범위를 다시 확인해9건을 기각했고, 자동 부족/불확실2건은 다른 설정에서 인정한 동일 인용이 실제 문맥에도 있음을 검증해 추가 인정했다. 최종 회복은 A27·B24건이다. 기준선 자동 교체·튜닝·답변 생성·커밋·푸시는 하지 않았다.

보정 후 A198/304·B201/304. 기존 모호성45 제외 집계는 A183/259·B182/259다. 다문서 일반85문항은 A72·B71로 별도 보고했다. 정답 그룹이 변형 전후85쌍 모두 동일하고, 질문 대상 누락 가능성51건을 사후 표기했지만 이를 제외해 점수를 다시 만들지는 않았다.

자동 충분 판정에 포함됐던 다른 사건 금액 전용과 날짜 역할 혼동을 기각했다. 대표 원문3쪽은 원본 PDF layout과 직접 대조했다. 검수는 AI 보조 및 자체 점검이며 독립 사람 검수로 표현하지 않는다. 원래 지정 근거 성공 항목은 전수 의미 검수하지 않았다.
