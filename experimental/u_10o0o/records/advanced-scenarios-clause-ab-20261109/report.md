# Advanced 상황별 140문항의 절별 연결 A/B

상황별 평가 v2의 1~7번을 사용한다. 개인 설정의 저장 후보 20쪽과 공통 선택기를 고정하고, A는 기존 두 사건 연결 규칙, B는 직전 실험의 절별 연결 규칙을 사용한다. 최종 문맥은 두 비교군 모두 최대 8쪽·8,000토큰이다. 4번의 문항별 변화를 기록하고 1~3·5~7번의 근거 손실을 확인한다. 동료 무 LLM 설정은 같은 평가 파일에서 이미 저장한 문맥을 참조한다. 질문만으로 A/B 문맥을 저장한 뒤 참고 근거를 읽는다.

## 결과

| 유형 | A 기존 규칙 | B 절별 규칙 | 동료 무 LLM | A → B 개선 / 하락 |
| --- | ---: | ---: | ---: | ---: |
| 1. 직접 조회 | 20/20 | 20/20 | 20/20 | 0 / 0 |
| 2. 번호 없이 한 사건 식별 | 8/20 | 8/20 | 6/20 | 0 / 0 |
| 3. 한 사건의 여러 기록 연결 | 20/20 | 20/20 | 20/20 | 0 / 0 |
| 4. 서로 다른 사건 비교 | 13/20 | 12/20 | 10/20 | 0 / 1 |
| 5. 적용되는 기록·조건 판정 | 20/20 | 20/20 | 20/20 | 0 / 0 |
| 6. 대상이 모호해 추가 확인 필요 | 0/20 | 0/20 | 0/20 | 0 / 0 |
| 7. 대상은 명확하지만 확정 근거 부족 | 20/20 | 20/20 | 20/20 | 0 / 0 |
| **합계** | **101/140** | **100/140** | **96/140** | **0 / 1** |

표는 필수 인용을 전부 담은 문항 수다. 개인 설정의 종전 100/140은 두 사건 선택기를 적용하기 전의 점수다. 이번 A는 기존 규칙으로 `AS-S04-02`를 재배치해 101/140이 됐다. B의 문맥 140개는 모두 이 종전 개인 문맥과 같았다.

| 유형 | 후보 20쪽에 전체 근거 | 전체 근거 A | 전체 근거 B | 동료 무 LLM |
| --- | ---: | ---: | ---: | ---: |
| 4번 · 두 대상 모두 번호 | 8/8 | 8/8 | 7/8 | 8/8 |
| 4번 · 번호와 원문 단서 | 4/6 | 4/6 | 4/6 | 2/6 |
| 4번 · 두 대상 모두 원문 단서 | 1/6 | 1/6 | 1/6 | 0/6 |

4번에서 두 대상을 정확히 인식한 문항은 A와 B 모두 8/20이었다. 두 대상에 필수 기록을 모두 연결한 문항은 8/20에서 0/20으로 줄었다. 최종 개별 근거는 A 52/66, B 51/66, 동료 41/66이다. 정확한 원본 페이지의 문항별 평균 Recall@8은 각각 80.00%, 78.75%, 63.75%였다. B와 동료의 전체 근거 충족을 문항별로 대조하면 B만 3개, 동료만 1개, 둘 다 9개, 둘 다 미충족 7개였다.

### 하락 원인

4번의 번호형 8개는 두 대상을 먼저 나열하고, 공통 요청 뒤에 `각각`을 붙이는 문형을 공유한다. B는 `각각` 뒤에서 공통 기록 요청을 찾으므로 이 문형에서는 앞에 나온 기록을 두 번째 대상에만 연결했다. 첫 번째 대상에 연결한 기록이 비어 선택기가 기준 문맥을 유지했다. `AS-S04-02`에서는 후보에 네 근거가 모두 있었고, A와 동료가 네 근거를 담았다. B는 첫 번째 대상의 현장 반출 근거를 빼고 세 근거를 담았다. 나머지 번호형 7개는 기준 문맥에서 이미 모든 근거를 담고 있어 이 기록 인식 하락이 최종 점수로 이어지지 않았다.

번호와 원문 단서를 섞거나 두 대상 모두 원문 단서로 지정한 12개는 화주·화물·규격으로 사건을 가리킨다. B가 간접 대상을 확인할 때 요구하는 실제 반출일이 질문에 없어 두 대상 연결을 반환하지 않았다. 이 12개 중 7개는 개인 후보 20쪽에서부터 필수 근거가 빠져 있었다.

### 다른 유형의 회귀

1~3·5~7번의 120문항에서 선택기가 작동한 경우는 A와 B 모두 0개였다. 두 문맥의 지문, 전체·개별 근거, 원본 페이지 및 문서 Recall@8이 문항별로 모두 같았다. 6번은 두 후보 사건의 근거를 모두 찾는 검색 지표에서 세 설정 모두 0/20이었다. 7번은 확정을 보류할 근거를 세 설정 모두 20/20 확보했다. 실제로 되묻거나 확정을 보류하는 답변은 이 실험의 채점 범위 밖이다.

## 재현 및 비교 범위

개인·동료 보관 문맥 280개의 지문과 쪽·토큰 수, 종전 개인·동료의 문항별 채점값을 재현했다. A/B 모두 개인의 동일한 후보 20쪽을 사용했다. 동료 `team_graph`는 기존 20청크를 쪽 단위로 중복 제거한 결과를 사용했다. 최종 문맥과 채점 기준은 세 설정에 동일하게 적용했다. 외부 API 호출은 0회였다. 8번 20문항은 범위 밖 대조로 분리했다. 질문과 원문 연결은 평가 파일 기준이며 업무 담당자의 검수는 아직 대기 중이다. [집계](results.json) · [문항별 로그](questions.jsonl) · [실행 로그](run.log)

Ruff, 새 실험 파일 검사, pytest 160개와 하위 검사 9개를 통과했다. 보관 순위와 A/B 순위를 다시 대조해 후보 20쪽, 최대 8쪽·8,000토큰, 회귀 문항의 동일한 문맥을 확인했다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.advanced_scenarios_clause_ab \
  --output artifacts/u_10o0o/advanced-scenarios-clause-ab-check
```
