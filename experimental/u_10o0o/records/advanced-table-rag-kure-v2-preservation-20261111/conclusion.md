# KURE-v2에서 추가 확인·선택 근거 보존을 적용한 결과

추가 확인 지침은 모호한 질문에 효과가 있었다. 선택한 근거를 최종 문맥에 남기는 동작도 확인했다. 다만 두 변경을 합친 B가 공식·카테고리의 검색 품질까지 일관되게 높이지는 않았다. 이번 결과만으로 기본 KURE-v3 A를 KURE-v2 B로 교체할 근거는 부족하다.

A는 기존 정책, B는 추가 확인 지침과 선택 근거 보존을 함께 적용한 정책이다. 아래는 최종 반환 근거의 보정 후 충족 건수다. 답변 생성 정확도가 아니다.

| 평가 묶음 | KURE-v2 A | KURE-v2 B | KURE-v3 A | KURE-v3 B |
|---|---:|---:|---:|---:|
| 공식 58 | 57 | 56 | 57 | 57 |
| 카테고리 근거형 200 | 195 | 195 | 195 | 196 |
| 동료 일반 85 | 70 | 72 | 73 | 71 |
| 거짓 전제 85 | 84 | 84 | 83 | 83 |
| 원래 모호한 43: 추가 확인 종료 | 25 | 42 | 25 | 41 |

카테고리의 나머지 20개는 범위 밖 대조군이며 네 설정 모두 충분하다고 확정한 사례가 없다. 공식은 이전 비교와 동일하게 채점 가능한 58개를 사용했다. 거짓 전제 85개 중 46개는 이전 실험에서 식별자·가정 조건을 보충해 고정한 질문이고, 39개는 원래 질문이다. 원래 모호한 43개는 별도 대조군으로 평가했다. 모두 재사용 개발·회귀 자료이며 새 블라인드 검증이 아니다.

## 추가 요청한 두 유형에서 드러난 효과

모호한 질문의 추가 확인 종료는 v2에서 25/43(58.1%)에서 42/43(97.7%)로 늘었다. 충분 판정은 18건에서 1건으로 줄었다. 남은 문항은 `clarify:SYF4-adv-003`이다. 검색 지연 p50/p95도 16.81/36.48초에서 8.56/17.00초로 줄었다. 이는 식별하지 못한 대상을 계속 추측하며 검색하는 반복이 줄어든 관측 결과다. 실제 사용자에게 무엇을 되묻는지는 이번에 생성하지 않았다.

거짓 전제형은 대체 근거와 질문 범위까지 확인하면 v2 A/B 모두 84/85(98.8%)다. B가 낮아 보였던 `SYF4-adv-039`는 한 사건만 지정하고 같은 화주의 나머지 두 사건을 요구한다. 원문 제목의 화주 필드를 전수 대조하면 같은 화주에 91개 계약이 있어 정답의 세 건을 유일하게 확정할 수 없다. 네 설정 모두 모호성 판정을 적용했으며 85개 분모는 유지했다. B의 추가 확인 종료를 검색 실패라고 단정하지 않는다. 이 항목의 원래 질문·정답 파일은 수정하지 않았다.

일반 여러 문서 질문에서는 `SY3-adv-027`과 `SY4-adv-011`을 회복해 70/85에서 72/85로 올랐다. 후자는 네 대상 중 하나를 빠뜨리던 실행이 그 대상의 기록을 추가로 찾고 최종 문맥에 넣었다. 이 변화는 지침과 계획 경로도 달라진 결과이므로 근거 보존만의 효과로 주장하지 않는다.

## 보존 효과와 검색 품질을 구분한다

v2의 실제 실행에서 관측하고 선택한 출처의 최종 유실은 총 15개에서 0개로 줄었다. 별도로 A의 검색 결과와 계획을 그대로 둔 문맥 재생 491개에서도 15개 모두 보존됐다. 따라서 관측한 선택 출처를 버리던 문제를 고쳤다는 근거는 있다. B가 검색에서 보지 않은 출처를 선택한 사례는 1개이며 보존하지 않았다. 이는 유실과 구분했다.

그러나 선택 목록 자체가 모든 요청을 충족한다는 보장은 없다. 공식 `AS-DEV09`의 SI 정정 절차와 `AS-ADD06`의 날짜별 제출 규정은 B의 검색별 상위 20개 후보에 있었으나 선택되지 않았고 최종 8쪽에서도 빠졌다. 선택한 페이지를 그대로 보존해도 이 누락은 해결되지 않는다. 공식은 1개 회복·2개 하락으로 순감 1개, 카테고리는 2개 회복·2개 하락으로 동일했다.

같은 A 검색으로 문맥 포장만 재생한 보조 점수는 지정 근거 기준으로 core +2/−1, peer +0/−1이었다. 이 재생은 보존 동작 진단이며 대체 근거 검수까지 수행한 추가 품질 비교군으로 사용하지 않는다. 실제 A/B의 지정 실패와 거짓 전제 전체는 아래 검수 절차를 완료했다.

## 이전 100% 설명의 정정

이전에 말한 KURE-v2 공식 58/58은 철회한다. 동일한 과거 출력의 `AS-DEV06`을 다시 확인하면 VGM 제출과 중량 구분 근거는 있지만 신규 SI 제출처의 온전한 근거가 부족하다. SI 정정 또는 BOL 재송부 연락처를 신규 제출 규정으로 넓혀 인정했던 판정이 문제였다. 이번 공통 검수 기준에서는 과거 v2 A도 57/58이다. 따라서 이전 100%와 현재 98.3%의 차이를 모델 차이나 단순 오차로만 설명한 것도 정확하지 않았다.

동료 일반 `SY4-adv-021`도 같은 예약의 서로 다른 문서 역할에 상이한 등록 상태가 있어 네 설정 모두 모호성으로 정리했다. 이 때문에 이전 v3 일반 74/72는 이번 통일 기준에서 73/71이다. 범위가 다른 상태를 하나의 현재 상태로 합치지 않았다. 원래 보고서는 보존하고 이 기록에서 판정 변경을 명시한다.

## 검수와 판단 범위

지정 실패 문항은 비교 상대도 함께 확인하고 거짓 전제형은 지정 정답 일치 여부와 관계없이 전부 검수했다. 총 568개 문항·설정 조합 중 309개는 새 GPT-6 Luna 검수, 259개는 질문·출력 지문이 같은 검수 기록을 재사용했다. 불확실한 판정, 인용 오류, 알려진 범위 문제 등 128개 조합은 원문을 자체 재확인했다. 모델이 짧은 표 셀을 인용해 검증에서 거절된 경우에는 실제 연속 행으로 고쳤다. 참고답의 이중 감액 오류도 원문을 우선했다. 독립 사람 검수는 수행하지 않았다.

v2는 질문 128·리랭커 1,024토큰과 GPU 질문 인코딩, v3는 기존 2,048/2,048토큰과 CPU 질문 인코딩 설정이다. 따라서 표는 각각의 저장된 구성 비교이며 모델만 바꾼 인과 실험은 아니다. 공식·카테고리 v2 A와 v3 A/B는 과거 실행이고 v2 B 및 동료 v2 A/B는 이번 실행이다. 지연도 단회 관측으로 해석한다.
