# KURE-v2 추가 확인·선택 근거 보존 비교

## 범위 계약

사용자 요청에 따라 KURE-v2 질문128·리랭커1024와 기존 표/원문 토큰 색인을 재사용하고 TableAgent의 preserve_evidence=True 흐름을 검증한다. 공식58·카테고리220개에서는 저장된 기존 KURE-v2 A와 새 B를 비교한다. 기존 KURE-v3 A/B는 저장된 동일 질문 출력을 함께 대조한다. 추가 요청의 거짓 전제85·원래 모호한43·일반85개에서는 KURE-v2 A/B를 둘 다 새로 실행한다. 질문 총491개, 새 검색704개다. 질문·참고답·검색 코드·운영 API·기준선은 바꾸지 않는다. KURE-v3의2048/2048과 다른 모델별 설정 비교임을 명시한다. 순수 임베딩 효과라고 주장하지 않는다.

기존 실험의 실행기·검색기·계획기·채점 함수를 재사용하는 개인 기록 진입점만 추가한다. 기존 결과는 덮어쓰지 않고 새 artifacts 경로에 기록한다. 전역 모델 변경·추가 학습·답변 생성·커밋·푸시는 범위 밖이다. 추가 확인 종료와 실제 사용자 답변 품질은 구분한다.

## 실행·검수

기존 .env 키·비용 제한 없음 승인을 재사용한다. GPT-6 Luna medium, 자동 재시도0,4워커와 GPU를 사용한다. 새 검색 계획 상한704×6=4224회. 모든 검색 결과 저장 후에만 참고 근거를 읽는다. 실패 문항은 비교하는 양쪽 출력을 같은 기준으로 검수하고 거짓 전제형은 지정 점수에 관계없이 전체 최종 근거를 검수한다. 기존 검수는 출력·질문 지문과 범위가 같을 때만 재사용한다. 실제 부족·적용 범위 모호·검수 오류를 구분하고 지정 점수와 보정 점수를 별도 저장한다. 이전 채팅의100%를 그대로 확정값으로 복사하지 않는다.

추가213문항은 기존 보정 질문 사본과 모호성 대조군을 그대로 재사용하며 새로운 미사용 검증 세트가 아니다. 같은 A 검색 결과의 문맥 재생으로 선택 출처 유실 감소를 별도로 확인한다. 독립 에이전트를 사용하지 않고 자체 검토한다.

준비 단계의 첫 v1은 과거 결과 사본 디렉터리 누락으로 중단됐다. 모델/API 호출 전이며 디렉터리 생성 순서를 고쳐 새 v2 경로에서 시작한다. 실패 산출물은 보존한다.

## 완료 기록

1. 새 검색 704개를 완료했다. 계획 API 1,458회, 오류 0회이며 답변은 생성하지 않았다. 고정한 질문과 실행 스냅샷의 지문을 검사했다.
2. 모든 검색 저장 후 지정 근거를 채점했다. 검수 대상 568개 조합을 고정해 새 검수 309회와 지문이 일치하는 이전 검수 259개를 사용했다. 자체 재확인은 128개 조합이다. 검수 API 오류는 0회였다.
3. 과거 공식 100% 판정을 재검수했다. AS-DEV06의 SI 정정/BOL 연락처를 신규 SI 제출처로 과도하게 인정한 문제를 확인해 같은 과거 출력을 57/58로 정정했다.
4. SY4-adv-021의 문서 역할별 상태 충돌, SYF4-adv-039의 대상 미특정을 네 설정에 대칭 적용했다. 후자는 원문 제목의 화주 필드를 전수 대조해 91개 계약을 확인했다. 원래 질문·정답과 과거 보고서는 보존했다.
5. 같은 A 검색 재생 491개가 기존 문맥을 재현하며 관측·선택 출처 유실 15개를 모두 보존했다. 실제 B의 미관측 선택 1개는 별도 분류했다.
6. 공식 −1개, 카테고리 변화 없음, 동료 일반 +2개, 거짓 전제 변화 없음, 원래 모호성 추가 확인 +17개다. 두 변경과 LLM 계획 변화가 함께 있어 모든 차이를 보존만의 효과로 주장하지 않았다.
7. 실행 중 상대 import 방식과 진단 출력 키를 바로잡았다. 저장된 검색 결과나 실행 코드 스냅샷에는 영향이 없으며 재호출하지 않았다. 기존 기준선·운영 API·원본 데이터셋은 변경하지 않았다.
