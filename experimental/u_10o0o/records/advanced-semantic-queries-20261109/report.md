# Advanced 일상 표현 40문항 검색 비교

문서 제목이나 예약·장비·계약 번호 없이 업무 상황을 설명한 문항을 평가했다. 한 문서 20문항과 여러 문서 20문항을 따로 집계했다. 현재 개인 기준선과 후보 생성 단계에 Snowflake-ko를 추가한 설정을 주 비교로 삼았다. BM25 20쪽과 Snowflake-ko 20쪽을 5:5 RRF로 합쳐 20쪽을 골랐고, 상수는 60이다. 두 개인 설정 모두 KURE nano 상위 3쪽 뒤에 각 후보의 순서를 유지하고 같은 HG·원문 조회와 최종 8쪽·8,000토큰 선택을 사용했다. 팀원 `team_graph` 무 LLM은 별도 참고 설정으로 새로 실행했다. [데이터 가이드](../../evaluation/advanced_scenarios/semantic_queries/README.md)

## 결과

각 값은 필수 근거를 모두 담은 문항 수다. 화살표는 최초 후보에서 최종 문맥으로의 변화를 뜻한다. 팀원은 20청크를 뽑은 뒤 페이지로 중복 제거했다. [집계](results.json) · [문항별 점수](scores.jsonl)

| 유형 | 개인 기준선 후보 → 최종 | 5:5 하이브리드 후보 → 최종 | 팀원 무 LLM 후보 → 최종 | 하이브리드 최종 개선 / 하락 |
| --- | ---: | ---: | ---: | ---: |
| 한 문서 · 업무 절차 | 3/10 → 3/10 | 6/10 → 6/10 | 3/10 → 2/10 | 3 / 0 |
| 한 문서 · 적용 조건 | 2/10 → 2/10 | 5/10 → 4/10 | 3/10 → 3/10 | 2 / 0 |
| **한 문서 합계** | **5/20 → 5/20** | **11/20 → 10/20** | **6/20 → 5/20** | **5 / 0** |
| 여러 문서 · 업무 단계 | 2/10 → 2/10 | 2/10 → 2/10 | 2/10 → 2/10 | 1 / 1 |
| 여러 문서 · 조건 결합 | 1/10 → 0/10 | 1/10 → 1/10 | 2/10 → 2/10 | 1 / 0 |
| **여러 문서 합계** | **3/20 → 2/20** | **3/20 → 3/20** | **4/20 → 4/20** | **2 / 1** |
| **전체** | **8/40 → 7/40** | **14/40 → 13/40** | **10/40 → 9/40** | **7 / 1** |

최초 후보의 개별 근거는 기준선 **18/62**, 하이브리드 **29/62**, 팀원 **23/62**였다. 하이브리드는 후보에서 기존에 없던 근거 14개를 찾고 3개를 잃었다. 최종 문맥의 개별 근거는 **17/62 → 26/62**로 늘었고, 팀원은 **21/62**였다. 최종 페이지 Recall@8은 기준선 **27.08%**, 하이브리드 **44.58%**, 팀원 **32.08%**였다. 개인 두 설정의 원문 조회는 40문항에서 발동하지 않았으며, 최초 후보와 원문 조회 후 후보의 근거 수가 같았다.

## 개선과 하락

- 전체 근거를 새로 확보한 문항은 `AS-SEM-05`, `AS-SEM-07`, `AS-SEM-09`, `AS-SEM-12`, `AS-SEM-17`, `AS-SEM-25`, `AS-SEM-37`이다. 순증 6개 중 5개가 한 문서 유형이다.
- `AS-SEM-29`는 기준선 후보 18위의 근거가 KURE를 거쳐 3위로 올라왔지만, 하이브리드 후보 20쪽에서는 그 페이지가 빠졌다. 두 근거 중 하나만 최종 문맥에 남았다.
- `AS-SEM-13`은 하이브리드에서 필요한 페이지를 새로 찾았지만 10위에 머물러 최종 8쪽에 들어오지 못했다. `AS-SEM-40`은 기준선에서 후보 단계에 두 페이지가 있었지만 하나가 20위에 머물렀고, 하이브리드에서는 그 페이지가 후보에서도 빠졌다. 두 설정 모두 이 문항의 최종 전체 근거를 충족하지 못했다.

## 재현과 해석 범위

새 질문 40개를 모두 임베딩했고, 이전 5:5 비교와 지문이 같은 문서 벡터를 사용했다. 질문으로 세 설정의 문맥 120개를 저장한 뒤 참고 근거를 읽었다. 외부 API 호출은 0회였다. Ruff와 pytest 160개 및 하위 검사 9개를 통과했다. [실행 로그](run.log)

이 세트는 일상 표현으로 말한 업무와 여러 문서의 근거를 함께 찾는 능력을 측정한다. 모든 문항에 답할 수 있는 근거가 지정돼 있다. 실제로 두 뜻 중 하나를 골라야 하거나 되물어야 하는 상황은 별도 평가가 필요하다. 기존 상황별 140문항과 정답 페이지는 겹치지 않으며, 업무 규정 20문항과는 23쪽, 공식 60문항과는 15쪽이 겹친다. 사람 검수는 대기 중이다.

```bash
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
  uv run --no-sync python -m experimental.u_10o0o.evaluation.advanced_scenarios.semantic_queries.compare \
  --output artifacts/u_10o0o/advanced-semantic-queries-check
```
