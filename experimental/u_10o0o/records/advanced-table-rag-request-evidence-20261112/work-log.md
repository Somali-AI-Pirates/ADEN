# 요청별 근거 확인 실험 작업 기록

## 범위
- 사용자 요청: 질문의 각 요구를 근거와 연결하고, 필요한 후보 원문을 확인한 뒤 최종 문맥에 보존한다. 결과는 문항 전체 근거 충족과 실제 반환 문맥 검수를 중심으로 보고한다.
- 개인 통합 TableRAG에 선택 옵션으로 추가한다. DB 우선, 모델, 검색·리랭커, 후보20·최종8쪽·8,000토큰, 최대5작업+종료는 고정한다. 운영 API·기존 기본 실행·과거 결과는 변경하지 않는다.
- 질문 요구별 질문 원문 구절·지원 상태·실제 읽은 출처와 인용을 종료 스키마에 추가한다. 후보9~20의 짧은 탐색용 미리보기로 원문 읽기를 안내한다. 미리보기만을 본문 인용으로 인정하지 않는다.
- 코드 검증은 원문·관측·최종 문맥의 인용 존재와 출처 보존까지다. 요구 누락과 의미적 충분성은 모델 판단이며 사후 검수로 측정한다. 평가 정답이나 특정 문항·페이지 규칙을 넣지 않는다.
- 공식58 전부에서 기존 DB 우선 A와 요구별 확인 B를 새로 실행한다. 지정 근거 실패와 비교 상대를 모두 검수하고, 지정 통과도 이번에는 검수에 포함한다. 독립 사람 검수로 표현하지 않는다.
- OpenAI 키 재사용·비용 한도 없음은 이 대화의 기존 승인에 따른다. Luna medium, 답변 생성 없음, 자동 재시도 없음. 검색 최대696회 API(58×2×6), 사후 검수 최대116회. 인증·요율 오류는 중단한다.
- 호환: 옵션을 끄면 기존 프롬프트·도구·처리를 유지한다. 오래된 산출물은 덮어쓰지 않는다. SQL 계산 결과의 숫자 자체를 원문 인용으로 위장하지 않는다.
- 서브에이전트 금지 지침에 따라 자체 리뷰하며 독립 리뷰 미실시를 보고한다.

## 진행
- 기존 실패 두 문항은 필요한 후보를 확보했으나 관측·선택에서 누락됨을 확인했다.
- 기존 작업 트리에는 운영 TableRAG 등 다른 작업 변경이 있어 개인 패키지와 새 기록에 범위를 제한한다.

- 구현 자체 리뷰와 개인28개 테스트 통과. 공통·TableRAG 합계408개와15개 하위 테스트 통과. 전역 Ruff는 범위 밖 app/rag/cli.py의 F841로 실패했고 해당 파일은 수정하지 않았다. 개인 수정 범위 Ruff와 CLI 도움말은 통과했다.
- 첫 A/B 표본의 실제 API 연결·종료·저장을 확인한 후58문항 양쪽 실행을 진행했다. 실행 중 규칙·프롬프트는 고정한다.

- 58문항×2조건의 검색116개를 모두 저장했다. 계획 API는 A84회·B130회이며 전부 정상 완료했다. 원문 읽기는4→36회, 하이브리드는59→48회다. B의 종료 인용 검증 거절29회는 API 오류와 구분했다.
- 검색을 모두 저장한 뒤 참고자료를 읽었다. 지정 전체 근거는39→36문항이었다. 양쪽116개 문맥을 새로 AI 검수했다. 자동 검수 원본105충족·11미충족 및 인용 문제5건을 보존했다.
- 실제 원문·질문 범위를 대조하여15건 교정(판정 변경8개 출력)을 남겼다. 최종 실제 전체 근거는 A56/58·B57/58, 개선2·하락1이다. 복합질문은49/51→50/51이다. SI 최초 접수 표의 분리된 주소는 원문 행으로 확인했고, 질문 밖 요구의 확대는 제거했다. 요청 날짜의 신규 경로 규정 부족과 운송사 통지 누락은 실패로 유지했다.
- p50은5.50→9.42초, p95는18.00→25.71초다. 후보 읽기·인용 확인을 늘려도 새로운 의무를 빠뜨릴 수 있어 전면 교체는 보류하고 선택 옵션으로 남긴다. 실행 조건을 결과 확인 후 수정하지 않았다.
- 최종 코드·입력·DB 지문, 동일 초기 후보58개, 최대8쪽·8,000토큰,116개 검수 및 인용, 문서 링크를 확인했다. 모든 JSON 수치가 유한함을 검사했다. 신규 보고서와 명령의 Ruff·서식도 통과했다. 전체 Ruff의 별도 작업 파일 F841은 남아 있다.
- 서브에이전트 금지에 따라 자체 리뷰만 수행했다. 커밋·푸시·기본 검색 교체는 하지 않았다.

- 최종 확인 중 다른 작업자가 app/rag/cli.py를 갱신한 것을 확인하여 전역 검사를 다시 실행했다. 전역 Ruff 통과, 공통·개인 테스트408개 및 하위15개 모두 재통과했다. 초기 F841 실패는 해소됐으며 이 작업에서 해당 파일을 수정하지 않았다.
