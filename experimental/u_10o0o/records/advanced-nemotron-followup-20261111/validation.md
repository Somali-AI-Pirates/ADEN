# 검증 결과

이번 작업은 개인 실험의 nemotron_followup.py 한 파일과 새 결과·기록 경로를 추가했다. 앞선 KURE-v2 실험, 기존 Nemotron 벡터와 검색 기록, 정답 및 기본 검색 설정은 유지했다.

| 검사 | 결과 |
|---|---|
| 공통 Ruff check | 통과 |
| 새 nemotron_followup.py의 Ruff check --isolated | 통과 |
| 새 파일의 Ruff format --check --isolated | 통과 |
| pytest -q tests experimental/u_10o0o/embedding_ablation | 296 passed, 15 subtests passed |
| 새 CLI --help, prepare/retrieve/score/timing/report | 실제 실행 완료 |
| 기존 Nemotron 후보·순위·최종 문맥 재현 | 280문항, 차이 0건 |
| 같은 조건에서 KURE-v2와 BM25 순위·범위 판정 | 1,120/1,120건 일치 |
| 후보 상한, 최종 최대 8쪽·8,000토큰, 문맥/출처 일치 | 4조건 × 280문항 통과 |
| 원래 입력·코드·결과·정답 및 검수 패킷 지문 | 일치 |

| 온라인 근거 점수 | 채점 대상 300회 중 품질 평가 대비 전체 근거 충족·페이지 Recall 변화 0건 |

독립 에이전트를 사용할 수 없는 별도 대화이므로 자체 리뷰했다. 독립 리뷰와 사람 검수는 수행하지 않았다. 범위 판정 실패 사례와 배치별 문맥 차이를 결과에서 제외하지 않고 별도 기록했다. 범위 밖 20문항은 검색을 실행했지만, 답변 생성이나 추가 확인 정확도를 채점하지 않았다.

공통 패키지·빌드 설정·의존성은 변경하지 않았고 개인 실험은 배포 패키지에서 제외되므로 패키지 빌드는 반복하지 않았다. 기존 5개 후속 실험 집중 테스트와 이번 1,120건 통합 실행을 활용했다. 완료 후 문서의 링크·수치·민감 원문 포함 여부를 점검했다.
