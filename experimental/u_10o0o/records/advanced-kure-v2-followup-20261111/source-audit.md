# 차이가 난 10문항의 출처 검수

새 검색 조건의 결과를 보기 전에 고정한 자체 검수다. 고정 복원 원본 캐시를 사용했으며 PDF를 새로 추출하거나 사람·독립 에이전트 검수를 수행하지 않았다. 원래 정답 파일은 유지한다.

| 문항 | 판정 | 근거 |
|---|---|---|
| official_development:AS-DEV20 | retain | 양쪽 후보에 있던 특정 사건 기록의 최종 순위 차이. 대체 출처를 추가하지 않음. |
| official_additional:AS-ADD05 | retain | SI 마감과 수하인/통지처 구분을 각각 요구. 두 번째 근거가 RRF 후보에서 탈락한 차이. |
| official_additional:AS-ADD13 | retain | 동일 사건의 계약·사건·정산 기록이 필요하며 최종 9위 탈락이 차이를 만듦. |
| official_additional:AS-ADD27 | retain | 조건부 연장에 필요한 사건 기록이 9위로 밀림. 후보에서는 양쪽 모두 충족. |
| semantic_queries:AS-SEM-14 | retain | 일반 요율 대상 안내만으로 특정 개정의 20GP 제외를 충족했다고 인정하지 않음. |
| semantic_queries:AS-SEM-18 | retain | 다른 사건의 감액 규정은 적용 범위를 확인할 수 없어 대체 출처로 인정하지 않음. |
| semantic_queries:AS-SEM-25 | retain | AS011 6쪽은 개별 대장의 배차·반입승인 구분을 제공하지만 일반 반입 절차 전체의 대체 근거로 확정하지 않음. |
| semantic_queries:AS-SEM-26 | retain | 서류 수신/내용 승인 근거만으로 실제 선적 상태 근거까지 충족했다고 인정하지 않음. |
| semantic_queries:AS-SEM-32 | scope_ambiguous | 질문에 터미널·계약 대상이 없는데 정답은 특정 일반 규정의 달력일을 전제함. 다른 계약에는 주말 제외 조건이 존재. |
| semantic_queries:AS-SEM-40 | alternative_sensitivity | 동일 회사·부산–LA 범위의 AS046 72쪽에 냉동 별도 조건이 명시됨. AS017 1쪽의 시간 범위와 함께 사용 가능. |

AS-SEM-40의 대체 출처는 별도 민감도 채점에만 사용한다. AS-SEM-32 제외 집계도 별도다. 다른 문항의 미등록 대체 출처까지 모두 검수했다고 해석하지 않는다.
