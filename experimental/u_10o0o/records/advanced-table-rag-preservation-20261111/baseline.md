# 개인 TableRAG 기준선

> 이 문서는 HG 보강 KURE-v3 B를 선택했던 과거 결정이다. 2026-11-12 최종 종료 선택은 [통합 DB 우선·인용 검사 OFF](../advanced-table-rag-closeout-20261112/decision.md)다. 아래 과거 실행 기록은 보존한다.

2026-11-12 사용자 최종 선택: **KURE-v3 B**. KURE-v3 임베딩에 추가 확인 지침과 관측한 선택 출처 보존 정책을 적용한다. KURE-v2와 A의 코드·자산·결과는 비교·재현용으로 보존한다.

| 항목 | 기준 |
|---|---|
| 임베딩 | nlpai-lab/KURE-v3, revision 73d5e710bc0b1f324a60746922cbad6d38f480d4 |
| 희소 검색 | 전체 코드 보존 BM25 + 제목 보너스 |
| 결합 | BM25·벡터 5:5 RRF, 상수60 |
| 리랭커 | KURE-Reranker-nano |
| 질문/리랭커 입력 | 2,048 / 2,048토큰 |
| 검색별 후보 / 최종 후보 | 20 / 20쪽 |
| 최종 문맥 | 최대8쪽·SQL 포함8,000토큰 |
| 계획 모델 | GPT-6 Luna medium |
| 정책 | B: 추가 확인 지침 + 관측한 선택 출처 보존 |
| 기본 실행 | table_rag run — 새 출력 경로 |

`table_rag.retrieval.Retriever`의 기본 모델은 이미 KURE-v3다. 별도 KURE-v2 실행기를 기본 경로로 연결하지 않는다. 운영 API나 다른 개인 검색 실험의 기준선을 이 문서로 덮어쓰지 않는다.

새 `table_rag run`은 B 지침과 보존 옵션을 명시적으로 연결하고 실행 프로토콜·출처 보존 감사에 기록한다. `TableAgent`의 저수준 기본값과 독립 workflow 경로는 과거 재현을 위해 유지한다. `advanced_search`와 운영 API에는 적용하지 않는다. 기존 결과 경로는 지문 불일치 시 재개하지 않으며 새 출력 경로를 사용한다.

KURE-v3 B의 직전 보정 결과는 공식 57/58, 카테고리 근거형 196/200, 동료 일반 71/85, 거짓 전제 83/85, 모호성 추가 확인 41/43이다. 범위 밖 카테고리 20개는 별도다. 모든 지표의 우위를 주장하는 선택은 아니며, 확인하지 못한 대상을 되묻고 선택한 출처를 보존하는 동작을 포함해 사용자가 최종 채택했다.
