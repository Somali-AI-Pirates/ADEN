# KURE-v3 근거 보존 A/B

## 범위 계약

개인 TableRAG의 KURE-v3 + 전체 코드 BM25 5:5·KURE nano를 기준선으로 고정한다. v2는 실행하지 않는다. A는 기존 계획/병합, B는 모호한 대상 확인 지침과 관측한 출처 선택의 보존을 추가한다. 모델·검색별 후보20·최종 후보20·최종8쪽·SQL 포함8,000토큰을 유지한다. 운영 API, advanced_search, 기존 결과와 원본 데이터셋은 변경하지 않는다. 기존 명령과 저장 형식은 유지하고 비교 실행은 새 경로에만 저장한다. 미관측 출처나 예산을 넘는 근거를 확정으로 취급하지 않는다. 구형 실행은 명시적 기존 정책을 지원한다.

## 평가 계획

동료 다문서170문항을 대상으로 한다. 거짓 전제85개 중 이전 분석에서 확인한46개는 대상 ID 또는 계산 가정/범위를 보충한 별도 사본을 만든다. 모호한 원래43문항은 추가 확인 대조군으로 별도 유지한다. 일반형85문항은 회귀 확인용이며 이미 모호성이 확인된 일반형은 따로 표시한다. 총213개의 동일 질문에 KURE-v3 A/B를 실행한다. 새 질문 작성에 참고자료를 사용한 사실을 기록하고, 실행기에는 ID/질문만 전달한다. 기존 점수와 보정 데이터 점수는 같은 분모처럼 비교하지 않는다. 모든 출력 후 지정 근거와 최종 문맥의 대체 근거를 나누어 검토한다.

## 권한·검증

현재 사이드 대화에서 승인된 기존 .env 키·비용 상한 없음, GPT-6 Luna medium을 사용한다. 답변 생성은 제외한다. 최대 검색 계획2×213×6=2,556회이며 자동 재시도하지 않는다. 테스트용 가짜 외부 경계로 출처 보존·환각 출처·예산 초과·기존 정책 재현을 검사하고 Ruff와 전체 공통/개인 TableRAG 테스트를 실행한다. 이 사이드 대화에서는 독립 에이전트가 금지되어 자체 리뷰를 수행하며 독립 리뷰로 표시하지 않는다.

## 구현·실행

- `TableAgent(preserve_evidence=True)`는 대상 불명확/가정 계산에 대한 지침을 추가한다. 최종 선택 출처는 지금까지 실제 검색된 페이지 합집합에서 검증한 뒤 먼저 후보20에 넣는다. 관측되지 않은 ID는 받아들이지 않으며, 선택한 출처가 최종 문맥에서 빠지면 충분 판정을 차단한다. 각 요구 사실의 의미 적합성을 코드로 보장하는 기능은 아니다.
- A는 같은 코드의 `preserve_evidence=False` 경로다. 새 정책의 기본값은 결과 채택 판단 전까지 변경하지 않는다. KURE-v3 모델은 두 조건과 기본 실행 모두 동일하다.
- 46개 사본 보정과43개 원래 모호성 대조군을 실행 전에 고정했다. 질문 작성에는 원래 일반형·참고답·원본을 사용했다. 실행기는 정답 파일을 읽지 않는다. 새 미사용 검증 세트라고 주장하지 않는다.
- 최초 A/B 연결 후 4개 작업자로 조건 순서를 교대하며 실행한다. 같은 장치·모델을 공유하지만 질문 계획은 각각 새로 호출한다. 순수 문맥 조립 효과는 저장된 동일 검색/동일 선택을 별도로 재생해 확인한다.
- 별도 답변 생성은 없으며, 모든 거짓 전제 결과와 일반형 지정 근거 실패만 최종 문맥에 기반한 AI 보조 검수를 수행한다. 인용의 실제 포함 여부를 로컬 검사하고 불확실/잘못된 인용은 통과시키지 않는다.

검수 호출 상한은 거짓 전제170개 설정별 출력과 일반형 지정 근거 실패 최대170개를 합친340회다. 검색 계획의 상한2,556회와 분리해 기록한다. 자동 재시도나 실제 답변 생성은 하지 않는다.

## 결과 확정

213문항×2조건의426개 검색 결과를 모두 저장했다. A의 계획 API 시간 초과1건은 자동 재시도하지 않았고 양쪽 정상 완료 쌍도 별도 집계했다. 근거 검수196회는 오류 없이 완료했다. 모든 거짓 전제 결과와 일반형 지정 근거 실패를 검수했고,36개 설정별 판정을 원문 재확인으로 정리했다. 추가 모호성을 발견해도 분모를 바꾸지 않았다.
