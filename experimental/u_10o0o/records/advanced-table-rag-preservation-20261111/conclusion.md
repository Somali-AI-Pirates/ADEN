# 채택 판단과 남은 문제

개인 TableRAG의 모델 기준선은 사용자가 선택한 **KURE-v3**로 고정한다. KURE-v2는 더 실행하지 않는다. 기존 A 흐름을 기본으로 유지하고, 추가 확인 지침과 선택 출처 보존을 결합한 B는 비교 옵션으로 남긴다. B는 모호한 질문의 불필요한 확정을 줄이고 지연도 낮췄지만, 전체 검색 근거 충족의 우위를 입증하지 못했고 일반형 두 문항에서 필요한 근거를 놓쳤다. `TableAgent`의 `preserve_evidence=False` 기본값을 유지한다.

보정한 거짓 전제85문항은 A/B 모두83개를 충족했다. 일반형85문항은 지정 페이지 기준으로 양쪽72개이며, 대체 근거와 추가 모호성을 검토하면 A74개, B72개다. 원래 모호성 목록9개를 제외한76개도 각각74개/72개다. 이76개가 완전히 검수된 유효 세트라는 뜻은 아니다. 새로 확인한 일반형 SY3-adv-031과 거짓 전제형 SYF4-adv-039의 모호성은 분모에서 임의 제외하지 않았다.

거짓 전제의 문항 보정과 검색 정책 변경은 구분한다. 보정46개에서 기존 A도45개를 충족했다. 과거 낮은 점수의 상당 부분은 대상·입력 부족과 참고답/검수 문제였다. 같은 수정 질문의 A/B가 같은83개를 충족했으므로, 이를 임베딩 또는 새 검색 정책의 성능 상승으로 해석하지 않는다.

현재 도구 관측은 검색 후보20개 중 상위8개의 본문 발췌를 제공한다. B가 보존하는 것은 **계획자가 선택한 관측 출처**다. 필요한 페이지를 검색했어도 모델이 본문을 읽지 못해 선택하지 않으면 보존 정책으로 해결되지 않는다. 표 스키마는 별도로 제공되지만 위 사례에서는 그것만으로 대상별 필수 기록을 최종 선택하지 못했다.

따라서 다음에 검증할 후보는 모델 교체가 아니라 **20개 후보 안에서 요청 대상의 행·문단을 읽게 하는 기능**이다. 필요한 출처를 지정해 원문을 읽는 도구 또는 질문 대상과 일치하는 표 행을 보여주는 방식을 검토할 수 있다. 이번 실행 결과를 본 뒤 같은 벤치의 규칙을 추가 조정하지 않았다.

## 점수 해석

실제 답변을 생성하지 않았다. 모호성의 성공은 계획자가 needs_clarification으로 종료했는지로 측정하며, 사용자에게 적절한 표현으로 되묻는지까지 검증한 결과는 아니다. 의미 검수는 GPT-6 Luna와 어시스턴트의 원문 재확인으로 수행했다. 독립 사람 검수가 아니고, 일반형의 모든 지정 페이지 통과 결과를 전부 의미 검수한 것도 아니다.
