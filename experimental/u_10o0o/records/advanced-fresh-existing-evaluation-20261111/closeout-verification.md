# 커밋 전 종료 검사

종료 대상은 `fresh_record_hybrid` 패키지, 그 패키지의 A/B/C·D·E·F·기록 선택·기존 평가·중단한 미사용 평가 계획의 일곱 기록 폴더, 두 개인 README의 해당 실험 링크다. 최신 원격 main `d93e3e4`에서 만든 `chore/advanced-experiments-closeout-20261111` 브랜치에 해당 파일만 복사했다. 원래 작업 트리의 다른 실험·제품 변경은 포함하지 않았다.

## 수행한 검사

| 검사 | 결과 | 범위 |
|---|---|---|
| 공통 Ruff | 통과 | 새 작업 트리 전체, 프로젝트 설정 |
| 개인 실험 Ruff | 통과 | 프로젝트와 같은 E4/E7/E9/F 규칙 |
| 공통 pytest | 291 passed, 15 subtests passed | 최신 main 기반 새 작업 트리 |
| 개인 실험 pytest | 121 passed, 2 skipped | 새 작업 트리; 원본 산출물이 필요한 두 검사는 건너뜀 |
| 개인 실험 pytest + 원본 | 123 passed | 원본 PDF가 있는 기존 작업 트리, 새 작업 트리와 Python 파일 바이트 동일 확인 |
| sdist·wheel 빌드 | 통과 | 제품 패키지에 개인 실험이 포함되지 않는 기존 경계 유지 |
| CLI 도움말 | 11개 통과 | 추출·단위 구성·벡터 빌드·검색·채점·보고서·E/F·선택·기존 평가 |
| 기존 평가 prepare | 원본 환경에서 통과 | 280개 질문의 SHA-256이 실제 실행 입력과 동일 |
| 정책 동결 | 5개 Python 파일 SHA 일치 | 검색·병합·최종 선택·모델·채점 정책 |
| 원래 작업 트리 보존 | 5개 검사 대상 SHA 일치 | 두 README, advanced_search.py, bm25.py, decisions.md |

빌드 과정에서 저장소 루트의 표준 README가 없다는 sdist 경고가 있었다. 이번 실험은 패키징 설정을 바꾸지 않았고 두 배포 파일은 정상 생성됐다. 기존 실험 보고서의 과거 테스트 수는 당시 환경 기록으로 유지하며 이번 최신 main의 291개 검사와 혼동하지 않는다.

새 작업 트리의 실제 `prepare` 실행은 Git에 포함되지 않은 `data/advanced/evaluation/development_questions.json`이 없어 멈췄다. 이를 통과로 세지 않았다. 같은 코드를 원본 데이터가 있는 환경에서 실행해 질문 파일 해시 `b9c7486b7949884a43347723034086eace0f21b0217399d128d870d7af8cf791`이 재현되는지 확인했다. 새 체크아웃에서 전체 실험을 다시 실행하려면 로컬 원본·평가 파일·색인·고정 모델 캐시가 필요하다.

## 독립 확인과 공유 범위

별도 검토자가 패키지의 외부 의존성, 커밋 범위, 민감 자료 유무와 문서 링크를 점검했다. 패키지 밖의 Python 의존성은 기존 추적 파일인 `context_evidence.py`이며 다른 미커밋 실험 모듈을 요구하지 않는다. 실제 import 위치도 새 작업 트리인지 확인했다.

공유 JSON은 수치·문항 ID·출처 ID·순위·지문을 담는다. 질문·정답 인용, 원문 PDF, 전체 검색 문맥, 벡터·모델·DB·키와 캐시는 포함하지 않는다. 과거 기록의 로컬 비공개 감사 파일 링크는 원본 환경에서만 열리며, 그 파일은 새 체크아웃에 복사하지 않았다. 로컬 문서 링크 280개 중 공유 문서 누락은 0개이며 비공개 산출물 링크 1개만 새 체크아웃에서 열리지 않는다. JSON 133개와 공식 58문항×E/F·184개 근거 그룹의 집계 일치도 확인했다.

이번 종료 단계에서는 모델 검색·답변 생성·유료 API를 새로 실행하지 않았다. 기존 결과를 재집계하고 종료 이유·한계·레퍼런스·실패 단계만 보강했다. 운영 기준선 변경, PR 생성, main 병합은 수행 범위가 아니다.

명령별 결과와 보존 지문은 [종료 검사 JSON](closeout-checks.json), 실험 결론은 [종료 기록](../advanced-fresh-record-hybrid-20261111/closeout.md)에 있다.

`git diff --cached --check`에서는 과거 생성된 A/B/C·D의 `changes.md` 두 파일 끝에 빈 줄이 있다는 서식 경고가 남았다. 숫자나 동작의 문제는 아니며 동결된 생성 코드와 과거 출력은 보존했다. 이를 무경고 통과로 표시하지 않는다.

최초 범위 감사가 끝난 뒤 사용자가 TableRAG를 제외한 다른 실험도 함께 게시하도록 범위를 확대했다. 이 문서는 첫 번째 fresh 실험 커밋만 설명한다. 추가 실험 범위와 검사는 별도 종료 기록으로 남기고 같은 게시 브랜치의 다음 커밋으로 구분한다.
