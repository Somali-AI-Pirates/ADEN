# 같은 기준으로 검수한 A/B 결론

공식은 A/B 모두 **57/58(98.3%)**, 카테고리 근거형은 **A 195/200(97.5%), B 196/200(98.0%)**다. 이번 출력에서 B가 더 확보한 문항은 일상 표현·여러 문서의 AS-SEM-30 한 개다. 검수 반영 후 하락 문항은 없다. 지정 근거만 볼 때의 공식48→49, 카테고리188→184를 그대로 실제 근거 충족 차이라고 해석하면 안 된다. 전체 표는 [보고서](report.md)에 있다.

## 무엇을 보정했나

어느 한 조건이라도 지정 근거를 놓친 28문항에서 양쪽 출력56개를 모두 확인했다. A16개, B21개의 지정 실패는 최종 문맥의 대체 근거로 질문의 요구를 충족했다. 반대로 B가 지정 근거를 찾았던 AS-SEM-32는 적용 계약을 확정할 수 없어 성공에서 제외했다. 정답 페이지·참고답·기존 지정 점수는 수정하지 않았다. [문항별 보정과 이유](correction-changes.json)

대체 근거는 일반 업무 규칙을 다른 유효한 쪽에서 찾은 경우, 같은 요청 절차를 다른 설명으로 확인할 수 있는 경우에 인정했다. 다른 사건의 값·조건을 옮겨 답할 수 있다는 뜻이 아니다. 참고답이 덧붙인 설명을 질문의 필수 조건으로 부풀려 실패 처리한 판정도 바로잡았다.

자동 검수56회 중48회가 완료됐고8회는 시간 초과였다. 시간 초과는 재호출하지 않았다. 56개 최종 출력 모두 자체 검수하고 실제 반환 출처의 해시·인용을 확인했다. 자동 검수의 인용 오류나 과도한 요구도 그대로 채택하지 않았다. 독립 사람 검수는 아니다. 둘 다 지정 통과했던 나머지230문항은 기존 채점을 유지했으므로 전체 문항을 별도 의미 검수했다는 주장도 하지 않는다.

## B를 채택할 만큼 차이가 큰가

현재 결과만으로 기본 설정을 바꿀 근거는 부족하다. 같은 최초 검색은278/278문항에서 재현됐지만 이후 Luna 계획과 검색은 A/B에서 별도로 실행했다. 따라서1문항 개선을 보존 정책 하나의 효과로 분리할 수 없다. 같은 A의 계획·검색을 고정한 재생에서는 선택된 관측 근거의 손실이 두 정책 모두0건이었고 지정 근거 충족 개선도0개였다.

공식 검색 지연 p50/p95는 A5.53/20.87초, B6.17/20.66초였다. 카테고리 근거형은 A7.09/24.12초, B7.15/20.67초였다. 동시4요청·단회 관측이며 답변 생성과 사후 검수는 제외했다. p95 차이를 안정적인 속도 우위로 확정하지 않는다. 검색 모델과 현재 기본 설정은 유지했다.

## 앞으로의 기본 절차

[개인 평가 기준](../../evaluation-policy.md)을 추가하고 개인 AGENTS·실행 안내·기록 시작점에 연결했다. 앞으로는 실패 문항과 비교 상대의 대체 근거 검수까지 끝내고 지정 점수와 검수 반영 점수를 같이 보고한다. 보정은 근거 부족을 모두 정답으로 바꾸는 절차가 아니다.

이번 finalize는 필수 검수 누락·중복, 원문 지문 변경, 반환되지 않은 인용, 근거 없는 성공 판정을 거절한다. 과거 모든 CLI에 유료 검수를 자동 연결하거나 과거 결과를 일괄 수정하지 않았다. 최종 보고 업무의 기본 절차를 고정하고 이번 실행에는 보고 확정 검사까지 적용했다.
