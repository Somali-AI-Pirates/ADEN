# 공식·카테고리 KURE-v3 A/B

## 범위와 고정 조건

기존 A(기존 질문 계획·병합)와 B(추가 확인 지침·관측한 선택 출처 보존)를 그대로 비교한다. KURE-v3·전체 코드 BM25 5:5·KURE nano, 검색별 후보20·최종 후보20·최종8쪽·8,000토큰을 고정한다. 임베딩/리랭커 입력은 이번 TableRAG 기준2048/2048이다. v2·새 리랭커·본문 추가 읽기 기능은 사용하지 않는다. 현재 기본 실행과 운영 API는 수정하지 않는다.

공식58문항과 카테고리220문항의 원래 질문을 변경 없이 사용한다. 공식 AS-DEV12/AS-ADD12는 기존 평가에서 근거 없는2문항으로 제외돼 온 기준을 따른다. 카테고리의 자료 범위 밖 대조군20개는 일반 근거 충족률에서 분리한다. 참고 파일은 바이트 복사·해시만 수행하고 두 조건의 모든 검색 저장 후에 채점기가 내용을 읽는다. 새로운 미사용 검증 세트는 아니다.

## 실행과 검증

현재 사이드 대화의 기존 .env 키·비용 무제한 승인을 사용한다. GPT-6 Luna medium으로 두 조건의 계획을 새로 호출한다. 최대278×2×6=3,336회이며 자동 재시도와 답변 생성은 없다. A/B 순서를 교대하고4작업자로 실행한다. 동일 검색을 이용한 후처리 재생도 별도로 수행해 순수 병합 효과와 계획 변동을 구분한다. 공유 기록에는 원문·정답 인용을 복사하지 않는다. 같은 경로의 기존 실행은 덮어쓰지 않는다.

기존 채점기(book_id+page, 카테고리 필수·대체 근거)를 재사용한다. 지정 근거 실패가 실제 의미 실패인지 확인하는 보조 검수는 별도 수치로 구분한다. 독립 에이전트를 사용하지 않고 자체 검토한다.

사후 검수는 지정 근거 실패가 한쪽이라도 있는 문항의 A/B를 모두 대상으로 하며 최대516회(근거형258×2)다. 모호성 자체를 오류로 채점하지 않고6번은 두 후보의 요구 기록,7번은 확정 근거가 부족하다는 기록을 평가한다. 범위 밖20개는 분리한다. 실제 답변 생성은 없다.

## 후속 요청: 실패 검수 완료와 기본 평가 절차

저장된556개 검색 출력과56개 자동 검수를 재사용한다. 자동 검수의 시간 초과8건도 최종 문맥 자체를 직접 확인하며 재호출하지 않는다. 모든 지정 실패와 비교 상대를 같은 기준으로 자체 판정하고 인용·출처 지문을 저장한 뒤에만 최종 보고서를 생성한다. 실제 근거 부족, 대상/적용 범위의 모호성, 검수 오류를 구분하며 억지로 정답 처리하거나 분모에서 빼지 않는다. 기존 검색기·모델·프롬프트·원본 질문·정답 파일·과거 결과를 변경하지 않는다. 개인 실험의 평가/보고 기본 절차만 문서와 결과 확정 검사에 반영한다. 운영 API·다른 실험자의 절차는 범위 밖이다. 보정 전후 결과는 별도로 보존하며, 기존 score 명령은 보정 전 진단으로 계속 사용할 수 있다.

## 완료: 대체 근거 검수와 같은 기준의 재집계

- 지정 실패가 한쪽이라도 있는28문항의 A/B56개 출력을 모두 자체 검수했다. 자동 검수48완료·8시간 초과를 보존했으며 시간 초과를 재호출하지 않았다. 반환된 원문에 대한 인용과 지문은 로컬 manual-review.json에 저장했다.
- 최종 판정은 근거 충분45개·실제 부족9개·적용 범위 모호2개(동일 문항의 A/B)다. 다른 지정 통과 출력은 기존 채점을 유지했다. A16개·B21개 실패를 대체 근거로 회복했고, B의 AS-SEM-32 지정 통과1개는 적용 계약 모호성으로 성공에서 제외했다.
- 공식 A/B57/58, 카테고리 A195/200·B196/200으로 확정했다. 카테고리의 모호1개는 분모에 남겼다. AS-SEM-30만 B의 개선이며 보정 후 하락은 없다.
- 모든 최초 검색278개는 A/B에서 동일했다. 후속 계획·검색은 별도 호출했고 순수 출처 보존 재생에서는 지정 점수 변화가 없었다.1문항 개선을 근거 보존만의 효과라고 결론 내리지 않았다. 기준선은 바꾸지 않았다.
- 보정 전후 점수·문항별 이유·남은 부족 근거·검수 사용량·지문과 재현 명령을 저장했다. 개인 evaluation-policy.md와 AGENTS.md, 안내 문서에 실패 검수 완료를 기본 최종 보고 절차로 반영했다. 과거 결과와 평가 정답은 변경하지 않았다.
- 공통/개인 Ruff, pytest359개·subtests15개, CLI help, 검수 확정 경계13개를 통과했다. 실행과 자체 검토 범위는 verification.md에 기록했다. 커밋·푸시는 하지 않았다.
