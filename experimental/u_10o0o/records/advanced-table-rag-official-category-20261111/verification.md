# 검증 기록

2026-11-11, Ubuntu-26.04의 프로젝트 가상환경에서 실행했다. 저장된 검색 결과를 검수·집계하는 변경이며 새 검색이나 답변 생성은 실행하지 않았다. 기존 실험의 검색·모델 검수 사용량은 report와 usage에 별도로 보존했다.

| 검사 | 결과 |
|---|---|
| 공통 Ruff: `.venv/bin/python -B -m ruff check .` | 통과 |
| 개인 기록 Ruff: `ruff check --isolated --select E4,E7,E9,F experimental/u_10o0o/records/advanced-table-rag-official-category-20261111` | 통과 |
| 수정한 finalize의 `ruff format --isolated --check` | 통과 |
| `.venv/bin/python -B -m pytest -q tests experimental/u_10o0o/table_rag` | 359 passed, 15 subtests passed |
| 실험 `run_benchmark --help` | 통과, API 호출 없음 |
| 보관 검색556개·입력 지문·검수 파일 지문 | finalize에서 모두 대조 |
| 최종 검수56개, 출처 해시와 인용 존재 | 모두 통과 |
| 검수 확정 검사·집계 경계13개 | 모두 통과, [세부 결과](finalization-checks.json) |

확정 검사에서는 누락·중복·미완료 검수, 변경된 최종 출처 해시, 근거 없는 성공, 없는 인용, 반환되지 않은 출처, 미완료 판정, 판정 불일치를 거절하는지 확인했다. 258개 근거형과20개 범위 밖의 분리, 모호 문항 분모 유지와 집계도 대조했다.

자체 최종 검토에서 검수 대상의 대칭성, 보정 전 점수 보존, 실제 누락·적용 범위 모호성 구분, 인용·정답의 검색 입력 유입 여부, 보고서와 JSON 수치 일치를 점검했다. 독립 에이전트·독립 사람 리뷰는 수행하지 않았다. 사이드 대화의 독립 에이전트 사용 제한을 따랐다. 검색 자체나 모델을 바꾸지 않았으므로 새 모델 성능 검증 또는 답변 정확도 검증으로 해석하지 않는다.

코드 변경 후 Ruff와 확정 검사 및 보고 생성을 다시 실행했다. 이후 변경은 결과 문서와 링크뿐이다. 패키징·의존성·운영 API 변경은 없다.

새 문서의 상대 링크 16개와 기존 안내에 추가한 정책 링크3개를 확인했다. 보고서 집계와 정책·최종 집계 코드·보정 전 점수의 지문도 일치했다.
