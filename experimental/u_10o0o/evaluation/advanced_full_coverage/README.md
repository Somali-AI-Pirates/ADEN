# Advanced 전 페이지 근거 세트

Advanced 원본 PDF 120개, 18,000쪽을 대상으로 만든 전체 범위 점검용 세트다. 공식 평가, 기존 [추가 280문항](../advanced_holdout/README.md), [파일럿 40문항과 블라인드 후보 410문항](../advanced_coverage_v2/README.md)에 없는 근거 16,398쪽을 새 문항으로 채웠다. 새 세트의 필수 근거는 17,816쪽이다. 기존 근거와 합하면 120개 PDF 모두 150쪽씩, 총 18,000쪽을 참조한다. [PDF별 집계](coverage.csv)

| 유형 | 신규 문항 | 문항당 기본 근거 | 처음 참조한 쪽 |
| --- | ---: | ---: | ---: |
| 비용 사건의 계약·현장·승인·청구·수납 대조 | 2,730 | 5쪽 | 12,259 |
| 터미널 특수 사례의 조건·사건·정산 대조 | 198 | 3쪽 | 567 |
| 안내·서류·원장에 기재된 개별 항목 확인 | 3,572 | 1쪽 | 3,572 |
| **합계** | **6,500** | | **16,398** |

페이지 하나마다 채점 가능한 근거를 확보했다. 표 전체 행과 페이지의 모든 사실을 각각 묻는 범위는 별도다.

## 파일과 실행 범위

- [questions.json](questions.json)은 기존 평가 로더가 받는 `id`와 `question`을 담는다. [references.json](references.json)은 정답, 필수 사실, PDF·쪽·인용문과 사실별 근거를 담는다. 질문과 정답에는 자료의 식별 정보가 있어 로컬에서 보관한다. [공통 평가 입력 계약](../../../../docs/guides/c-module-guide.md#실제-연결)
- [page_ledger.jsonl](page_ledger.jsonl)은 원본 18,000쪽 각각에 이전 문항 ID, 신규 기본 근거 문항 ID와 근거 역할, 신규 대체 근거 문항 ID를 연결한다. 이전 문항의 정답과 인용문은 해당 평가 세트에서 조회한다.
- [blind_related_question_ids.json](blind_related_question_ids.json)은 기존 블라인드 후보와 확인된 사건 키·기록 번호·출처를 공유하는 신규 397문항이다. 이 문항은 전 페이지 점검에는 포함하고, 기존 블라인드 후보를 평가하기 전 검색 설정을 고르는 데서는 제외한다. 기존 후보의 질문·정답 파일은 그대로 사용한다.
- [manifest.json](manifest.json)과 [validation.log](validation.log)는 입력·산출물 지문, 구성, 실행 및 검증 건수를 기록한다.

## 출제와 근거 처리

연결 사건은 같은 사건 ID의 다섯 기록을 묶었다. 최초 보관료 무료일과 첫 구간 단가, 실제 적입 장비 반출일, 조건 대조와 승인 상태, 청구 보관료 유료일, 회계 인계 수납 기록을 각각 별도 필수 사실로 두었다. 특수 사례는 같은 사례의 세 기록에서 서로 다른 사실을 묻는다. 업무 자료집은 표의 원본 열과 행 범위를 확인해 항목을 골랐다. 코드가 여러 곳에 나올 때는 해당 기록 종류나 업무 구분을 함께 제시한다.

질문은 검증된 필드와 통제된 한국어 문장 패턴으로 작성했다. 사건이 유일하게 식별되는 경우 화주·화물·규격을 단서로 사용했고, 나머지는 식별자를 썼다. 직접 식별 5,120문항, 간접 식별 1,380문항이다. 증빙이 미결인 항목은 그 상태 자체를 묻는다.

`evidence_requirements`의 각 항목은 필수 사실 하나, 기본 출처, 대체 출처로 구성된다. 같은 기록 식별자 범위에서 기본 근거의 인용문 묶음이 모두 똑같이 나타나는 쪽을 대체 근거로 기록했다. 총 84쪽에 112개 연결이 있다. 대체 후보는 근거 없이 늘리지 않았고, 의미가 같은 표현을 전체 코퍼스에서 찾아 합치는 검수는 별도로 남아 있다.

## 검증과 후속 벤치

- 신규 인용문 20,546개가 Poppler PDF 추출문과 검색에 쓰는 복원 페이지 양쪽에 있는지 확인했다. 연결 사건 2,730건의 산입·무료·유료일 합계와 날짜를 검사했다. 업무 자료집 표 레코드 50개 파일의 지문을 대조했다.
- 공통 로더로 6,500개 질문과 참고 정답의 ID 대응을 확인했다. 기존과 신규의 기본 근거를 합쳐 미참조 페이지가 0쪽임을 확인했다.
- 기본 근거 페이지 전부를 출처 표시와 함께 묶었을 때 6,500문항 모두 현재의 4,000토큰 예산에 들어갔다. 최대 2,476토큰이었다. 검색 결과에 다른 페이지가 끼어드는 상황의 문맥 포함률은 별도 측정 대상이다.
- 현행 채점기의 `evidence_groups`는 기본 근거를 사용한다. 대체 근거를 반영할 때는 사실별로 기본·대체 중 한 묶음이면 충족으로 집계한다. 필수 페이지 5쪽 문항은 페이지 기준 Top 3에서 전체 확보가 불가능하므로, Recall@8과 필수 사실의 근거를 전부 확보한 비율@8을 함께 본다.

자동 원문 검증을 완료했다. 사람의 문항별 자연스러움·의미 검수와 검색 성능 측정은 이후 단계다.
