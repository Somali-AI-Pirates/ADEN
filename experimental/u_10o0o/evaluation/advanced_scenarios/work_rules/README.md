# Advanced 업무 절차·규정 검색 평가 · 20문항

기록번호나 문서 제목을 모르는 사용자가 업무 절차와 적용 규정을 찾는 상황을 다룬다. [전체 비교 가이드](../README.md#다음-비교의-데이터와-집계)의 검색 본 평가에 추가하는 20문항이며, 기존 상황별 140문항과 범위 밖 대조 20문항의 결과와 구분해 집계한다.

| 유형 | 문항 | 범위 |
| --- | ---: | --- |
| 절차·필요 서류 | 10 | 예약 신청·변경·취소, SI 작성·정정, 부산 반입 준비, 선하증권 승인·발행, 도착 예정 변경, 감액 승인 확인, 월말 인계 |
| 적용 조건·예외 | 10 | SI 마감 개정, VGM 신규·정정 경로, LA 보관료 적용 범위, 터미널별 요율, 보관일수 산입, 적용 기준일, 무료기간과 감액 승인, 상담·준비 메모의 권한 |

[질문 파일](questions.json)은 `id`와 `question`만 담는다. 검색을 저장한 뒤 [참고 근거](references.json)의 `evidence_requirements`로 후보 20쪽과 최종 최대 8쪽·8,000토큰에서 모든 필수 근거가 확보됐는지 두 유형별로 집계한다. 문항 수와 파일 지문은 [manifest.json](manifest.json)에 기록했다.

20문항의 근거는 PDF 17개, 27쪽에 있다. 모든 인용이 원본 PDF 추출문과 검색용 복원 페이지에 들어 있는지 확인했다. 정답 쪽만으로 20문항을 전부 채점할 수 있었고 가장 긴 문맥은 1,501토큰이었다. 기존 상황별 160문항과 겹치는 근거 페이지는 0쪽이다. 과제 제공 공식 세트와는 13쪽이 겹치므로, 공식 세트와 독립된 검증으로 해석하지 않는다.

문항은 원문에 연결해 작성한 업무 상황 가정 표본이다. 표현의 자연스러움과 대체 근거의 적절성은 사람 검수 대기 상태다. 검증 범위는 데이터와 인용 대조까지이며 외부 API 호출은 0회다.
