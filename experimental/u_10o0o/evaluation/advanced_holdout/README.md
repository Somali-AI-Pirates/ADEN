# Advanced 추가 검증 세트

원본 Advanced PDF에서 만든 개인 검색 실험용 280문항이다. 기존 Development·Additional 결과와 분리해 집계한다. 같은 사건에서 여러 말투로 문항을 복제하는 대신, 식별할 수 있는 사건은 사건당 한 문항을 선택했다.

## 파일

- 로컬 질문 파일 `advanced_holdout_questions.json`은 실행 입력인 `id`와 `question`만 담는다.
- 로컬 참고 정답 `advanced_holdout.json`은 질문별 정답, 기대 행동, 필수 사실, PDF ID·쪽·인용문, 유형과 말투 태그를 담는다. 검색이 끝난 후 채점할 때 읽는다.
- [집계와 입력 지문](manifest.json)에는 문항 분포, 원본 PDF별 SHA-256, 두 데이터 파일의 SHA-256이 있다.

두 문항 JSON에는 원본에서 추출한 근거와 사례 정보가 들어 있어 이 폴더에서 Git 추적을 제외한다. 공통 평가 CLI에는 두 파일을 각각 `--questions`와 `--references`로 넘길 수 있다. 개인 페이지 실험에서는 같은 입력에 [기존 페이지 채점 함수](../../evaluate.py)를 적용하고, 검색 결과가 문서 청크라면 문서 단위와 페이지 단위를 구분해 기록한다. [평가 입력 계약](../../../../docs/guides/c-module-guide.md#실제-연결)

- 질문에 직접 식별자가 있는 72문항, 화주·화물·수량 등 단서로 기록을 찾는 173문항, 일반 업무·규칙 35문항이다. 직접 식별자에는 예약·장비 번호와 자료집의 기록 코드가 포함된다.
- 참고 PDF 수는 1개 88문항, 2개 171문항, 3개 9문항, 4개 12문항이다. 답변이 기대되는 271문항과 확정 보류가 기대되는 9문항 모두 채점할 검색 근거가 있다.
- 말투는 구어체, 짧은 질의, 이메일, 인계 요청, 비교 요청, 메모, 검토 요청, 요약 요청, 재확인, 원문 대조 요청으로 나눴다.

## 출제와 검증

120개 PDF의 18,000쪽을 추출해 제목·섹션·본문과 사건별 자료 연결을 분석했다. 업무 안내·원장과 별도 터미널 사례에서 58문항을 작성했고, 계약·현장·승인·청구·수납이 연결된 기록에서 222문항을 구조화된 값과 실제 상태를 이용해 생성했다. 연결 기록 문항 중 42개는 특정 원장에 있는 값이나 날짜를 직접 확인하고, 180개는 30가지 업무 시나리오를 묻는다. 일부는 여러 원문의 값을 대조해야 한다.

기존 평가 질문과의 텍스트 중복, 확인된 사건 ID 중복, 등록된 근거 페이지 중복을 검사했다. 근거 인용 614개가 원본 PDF 추출문과 기존 복원 페이지 모두에 있는지 확인했다. 참조 범위는 120개 PDF의 505쪽이다. 구조화된 문항에서는 날짜·금액을 원문에서 읽고, 산식이나 차액을 묻는 유형은 값의 일관성도 확인했다.

이 세트는 실제 문의 분포를 추정하기 위한 표본과 별개인 합성 검증 세트다. 업무 유형을 의도적으로 배분했으므로 전체 평균과 함께 식별자 유무·근거 문서 수별 결과를 확인한다. 근거 일치와 형식을 자동 검증했고, 의미와 표현은 유형별 예시를 점검했다. 280문항 전체에 대한 독립적인 사람 검수는 별도 단계다. 검색 결과는 [Advanced 재벤치 보고서](../../records/advanced-factor-ablation-20261108/report.md)에 기록했다.
