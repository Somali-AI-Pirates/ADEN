# 개인 실험 공간

`experimental/<GitHub 사용자명>/`에 개인 실험·노트북·스크립트·메모·작업 기록을 둔다. 각 사용자 폴더의 내부 구조·도구·기록 형식은 자율이며 필수 파일·일지 양식은 없다. `.gitkeep`은 빈 폴더의 위치 표시일 뿐 삭제해도 된다.

- 실험은 `app/`·`shared/`를 사용할 수 있지만 공통 제품·기본 테스트·설치는 개인 실험에 의존하지 않는다.
- 이 공간은 공통 Ruff·pytest·제품 패키징에서 제외한다. 개인 검사·의존성 도구는 각자 선택한다.
- 채택 절차와 공식 결과·Git 추적 기준은 [CONTRIBUTING](../CONTRIBUTING.md#2-개인-실험과-공통-코드-반영)을 따른다.
- 공식 작업일지·TIL의 의무는 개인 실험의 자유 형식과 별개다. 기록 위치는 [문서 목차](../docs/README.md)에서 확인한다.
