# 개인 실험 공간

`experimental/<GitHub 사용자명>/`에 개인 실험과 작업 기록을 보관한다.
각 사용자 폴더 안의 파일·하위 폴더·도구·기록 형식은 자율이다. 노트북,
스크립트, 메모, 작업일지 등에 정해진 양식이나 필수 파일을 두지 않는다.
빈 사용자 폴더의 `.gitkeep`은 Git에 위치를 남기는 표시이며 삭제해도 된다.

## 공통 코드와의 연결

- 실험에서 `app/`과 `shared/`를 가져다 사용할 수 있다. 공통 제품 코드와
  기본 테스트·설치 과정은 `experimental/`에 의존하지 않는다.
- 기본 CI의 Ruff 검사와 pytest 수집, 제품 패키징은 이 공간을 제외한다.
  개인 실험에 필요한 실행·검사는 각자 선택한다.
- 채택할 기능은 해당 `app/` 모듈과 공통 테스트·설정·문서에 반영해 PR로
  공유한다. 개인 실험 파일을 제품 코드에서 직접 불러오지 않는다.
- 팀 비교·제출에 채택하는 결과는 코드 버전·설정·질문셋과 결과의 관계를
  확인할 수 있게 `reports/`에 정리한다. 개인 폴더의 기록 형식은 바꾸지 않아도 된다.
- 원본 데이터·모델·대형 실행 산출물·비밀값에는 저장소의 기존 Git 제외
  규칙을 적용한다. 공용 산출물 위치는 `artifacts/`와 `reports/`를 유지한다.

협업 절차와 결과 관리 기준은 [Git 협업 가이드](../docs/guides/git-workflow.md)를 따른다.
