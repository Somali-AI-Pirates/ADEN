# B 리뷰 — PR #54

대상: `app/generation/chain.py`의 #53→#54 부정 표현 처리, `generate_answer()`의 검증·재시도,
`answer_query()`의 오류 계약, `tests/generation/test_incomplete_consistency.py`.

확인한 동작:

- 이유가 검산 미완료를 명시했지만 본문이 ‘미완료가 아닙니다/아니라 완료/미완료 상태가 아닙니다’로 부정하면 재시도한다.
- 재시도에는 같은 질문·문맥을 유지하고 표기 보완 피드백을 추가한다. 모의 trace에 두 시도가 기록된다.
- 강조·코드·괄호 및 비용별 완료/미완료가 섞인 정상 표기는 불필요하게 재시도하지 않는다.
- 이유에서 미완료를 부정한 경우 이 검사로 재시도를 요구하지 않는다.
- 한도를 소진하면 ValueError, 서비스 502 및 시도 기록을 유지한다.

관련 모의 테스트 14개가 통과했다. 실행 명령·커밋·출력 해시는 manifest와 checks/pytest.txt에 남겼다.

한계: 이유의 특정 미완료 표현을 계기로 본문 표기를 확인하는 검사다. 모든 한국어 문법·의미를 이해하거나
비용별 주장 전체의 모순·근거 충분성·금액 정확성을 판정하지 않는다. 실제 #54 생성 답변 검증은 C 재평가에서 확인한다.
이번 자료 공유에서는 제품 코드·생성 프롬프트·채점 기준을 추가 수정하지 않았다.
