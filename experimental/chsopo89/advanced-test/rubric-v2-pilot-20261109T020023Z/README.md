## 4. 해석과 범위

- 점수가 변한 것은 같은 답변을 다른 기준으로 평가했기 때문이다. 생성 모델 성능이 개선됐다는 뜻이 아니다.
- S07·S09는 질문에서 요구하지 않은 항목을 추가 필수로 취급하던 감점이 줄었는지 확인한다. 필수 답 자체가 빠진 사례는 계속 감점해야 한다.
- M01·M19는 최종 금액의 일치와 사건·계약·수납에 근거한 검산을 구분한다. 값이 맞더라도 어떤 필수 검산 정보가 빠졌는지 항목 ID로 확인한다.
- 이 4문항은 과거 오답을 보고 고른 개발용 사례다. 실행 1회이므로 Judge 변동이 포함되고, 전체 Advanced 40문항이나 독립 평가 결과로 일반화하지 않는다.
- v2의 필수 항목 판정 역시 LLM 기반 의미 평가다. 숫자로 표시돼도 완전 자동 객관 판정은 아니며 사람의 대조가 필요하다.
- 사람 대조에서 추가 검토 지점을 확인했다. M19/hybrid는 v2 fact=1이지만 해당 계약 약정 AS095.pdf 149쪽은 실제 문맥에 없다. 사건·청구 명세·계약 대조 회신은 있다. 청구서의 산입일수·산식을 옮기는 것과 최초 계약의 기간 규칙으로 독립 검산하는 것을 R01이 충분히 구분하는지 추가 확인해야 한다. 계약 페이지가 없다는 사실만으로 자동 오답 처리하지는 않으며, 동등한 계산 규칙이 다른 실제 문맥에 있는지도 확인한다.
- M19/hybrid_rerank는 금액·산식·대사는 맞지만 산입/무료/유료일수 미표기로 fact가 1→0이 됐다. 이 항목을 검산 필수 정보로 요구할지, 동등한 표·산식에서 재현되면 인정할지 전체 평가 전에 확정해야 한다. 이번 점수는 수정하지 않고 원 판정을 보존한다.
- 전체 40문항 재채점, 검색 개선 실험(#19), 공유 색인·클라우드 PDF 연결은 이번에 수행하지 않았다.
