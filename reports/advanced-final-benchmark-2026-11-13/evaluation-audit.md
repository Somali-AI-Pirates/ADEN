# 평가 결과를 읽을 때 확인할 사항

이 문서는 2026-11-13 최종 벤치의 평가기와 원인 진단을 독립 AI 검토한 기록이다. 사람 검수가 완료됐다는 뜻은 아니다. [전체 보고서](report.md)의 자동 점수는 원본대로 보존하고 아래 판정 한계를 함께 읽는다.

## 1. Faithfulness가 낮으면 모두 환각인가

아니다. Faithfulness는 **답변의 사실 주장이 제공된 최종 문맥으로 뒷받침되는지**를 측정한다. 질문에 필요한 답을 빠짐없이 했는지, 참고답과 맞는지, 올바르게 거절했는지는 별도 지표다.

범위 밖 대조군 20문항은 정답 페이지가 없다. 이 그룹의 원 채점 평균은 0.274이며 14문항이 0.30 이하다. 독립 검토에서는 업무 범위 안내, 질문 종류 분류, 자료 부재 설명이 해운 문서에 쓰여 있지 않아 낮은 점수를 받은 사례가 확인됐다. 이 점수를 일반적인 업무 사실 환각률이나 검색 실패율로 바꾸어 해석하면 안 된다.

- AS-S08-01·09: 거절 답변의 범위·분류 설명을 문서가 직접 지지하지 않는 것이 주된 저점 원인이다.
- AS-S08-12·16: 자료가 한계나 부재를 명시해 Faithfulness 1.0을 받았다.
- AS-S08-17·18: 기준 행동은 답변 보류인데 실제 상태는 추가 확인이었다. 이 행동 불일치는 별도로 남는다. 17은 날짜·자료 범위 오류도 관찰됐다.
- AS-S08-18: 사용자의 자료 준비 상태가 문맥에 없다는 것과 그 상태가 거짓이라는 것은 다르다.

전체 평균에서 이 20문항을 사후 제거하지 않는다. 범위 밖 그룹을 따로 표시하고 Judge의 판단·거절 지표와 함께 본다. 보강 프롬프트도 이 한계를 완전히 해결하지 못했다.

## 2. 평가 불가와 0점은 다르다

출처·인용 검증에 실패한 모델 판정은 평가 불가로 두었다. 점수를 0으로 바꾸지 않는다. 일부 판정은 출처 ID를 대괄호로 감싸 출력해 실제 문맥에 있는 출처임에도 원 검증기에서 거절됐다.

후속 재검증은 다음 경계를 지킨다.

1. 이미 끝난 모델 응답의 구조화 출력만 다시 읽는다. 새 평가 모델 호출은 하지 않는다.
2. 원 ID 또는 대괄호 한 쌍을 제거한 ID가 해당 요청의 최종 문맥 출처 목록에 정확히 있을 때만 인정한다.
3. 인용 문자열, 주장 순서·개수, 0/1 판정, 허용 출처 검사 조건은 바꾸지 않는다.
4. 공백을 모두 지우거나 문장을 느슨하게 일치시키지 않는다. 인용이 여전히 맞지 않으면 평가 불가를 유지한다.
5. 원 채점과 형식 정규화 후 파생 채점은 별도 파일·지문·분모로 보관한다. 이미 유효했던 점수는 바꾸지 않는다.

이는 검색·답변 성능의 개선이 아니라 평가 출력 형식 처리의 수정이다. 교정에서 발견한 산술 오판도 별도로 남으며, 출처 문자열이 실제로 존재한다고 해서 모델의 의미 판정까지 옳아지는 것은 아니다.

## 3. 공식 문항의 자동 실패 원인과 독립 검토

자동 원인 태그가 붙은 공식 문항 6개를 질문, 답변, 후보, 최종 문맥, 원본 PDF와 대조했다.

| 문항 | 자동 기록의 요지 | 독립 검토 |
| --- | --- | --- |
| AS-ADD09 | 검색 누락 | 요청된 기록이 후보 20쪽에 없어 실제 검색 누락 확인 |
| AS-DEV13 | 최종 문맥 손실 | 필요한 날짜 기록이 후보 9위에 있었으나 최종 8쪽에서 빠짐 |
| AS-ADD12 | 검색 종료 판단 | 보류는 적절하며, 확인 질문 일부가 빠진 불완전성 |
| AS-ADD18 | 최종 답변 누락 | 질문이 요구하지 않은 이전 번호까지 요구한 채점 오탐 |
| AS-ADD13 | 최종 답변 누락 | 이유 설명은 충족했으나 세부 문서 종류까지 요구한 과잉 채점 가능성 |
| AS-ADD29 | 최종 답변 누락 | 결과와 금액은 맞고 적용일 기준 설명이 빠졌을 가능성 |

따라서 자동 기록의 최종 답변 누락 3건을 모두 확정된 생성 오류로 세지 않는다. 원 점수는 수정하지 않았고, 이 검토를 별도 해석으로 제공한다. 전체 자동 원인 표에도 미확정 건수를 함께 표시한다.

## 4. 페이지 Recall의 분모

이 보고서의 페이지 Recall은 질문마다 정답의 **고유한 book_id+page 집합**을 만들고, 그중 후보 또는 최종 문맥에 남은 비율을 계산한 뒤 문항 평균을 낸 값이다. 해당 구현 필드는 table_rag_metrics의 candidate_page_recall / final_page_recall이다.

공식 문항에는 페이지 정답이 있는 질문 58개, 근거 그룹 184개, 질문별 중복 제거 페이지 수 합 170개가 있다. 같은 페이지를 여러 필수 사실의 근거로 반복 기재한 10문항 때문에 분모가 달라진다. evidence_diagnostics의 동명 page_recall은 근거 그룹 커버리지이므로 이 보고서의 페이지 Recall로 대체하지 않는다.

필수 페이지 전체 충족은 모든 근거 그룹의 허용 출처가 남았는지를 보는 문항별 0/1 지표다. 의미상 사실 충족은 실제 문장·표·SQL을 읽는 AI 판정이다. 두 지표는 정답 페이지 유무만으로 서로 대체할 수 없다.
