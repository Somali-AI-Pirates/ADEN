## 평가 설정

- 확정 질문 합본: 고유 문항 280개, 페이지 정답 보유 문항 258개.
- 제품 답변 생성은 GPT-6 Luna `medium`이다. 평가 실행의 model/effort는 별도 기록한다.
- 평가 모델은 GPT-6 Luna `max`를 요청하며, 명시적인 미지원 거절이 있을 때만 `xhigh`로 전환한다. Responses API 연결과 `max` 호출은 교정 실행에서 확인됐다. YAML 실행값은 출력 상한 128,000, timeout 600초, SDK 재시도 최대 2회다.
- Ragas Faithfulness는 Judge의 답변 판정과 독립적으로 실행한다. **`default` 대 `advanced` 비교는 20문항 교정에만 적용했고, 전체 280문항은 advanced 프로필만 채점한다.** 교정 20문항의 결과를 본평가 점수와 합치지 않는다.
- 페이지 정답 지표와 의미상 필수 사실 평가는 서로 다른 증거·분모로 보고한다.


## 교정 실행 구분과 평가 한계

프로필 비교는 20개 Faithfulness 교정 문항에서만 수행했다. 교정은 같은 질문을 쓰되 실행 설정과 프롬프트 revision이 서로 다르므로 별도 기록으로 다루며, 아래 실행을 합산하지 않는다.

| 교정 실행 | 출력 상한 | 프로필 범위 | 상태 |
| --- | ---: | --- | --- |
| `advanced-final-20261113` | 32,768 | default 20개 + advanced 20개 | 완료 |
| `advanced-final-20261113-v2` | 32,768 | advanced 20개만 | 완료 |
| `advanced-final-128k-20261113` | 128,000 | default 20개 + advanced 20개 | 완료 |
| `explicit-interval-128k-20261113` | 128,000 | advanced 표적 3개 | 완료, 교정 세트 평균과 분리 |

이 사례군에는 해석 한계가 있다. `SYN-FTH-05`는 gold label이 하나의 판정으로 고정되지 않는 모호성이 확인됐다. `SYN-FTH-10`은 v2에서 산술 근거가 지원한다고 잘못 긍정 판정한 확정 오탐으로 확인됐다. 민감한 문항·문맥·인용은 이 보고서에 싣지 않는다. 따라서 교정 점수는 프롬프트 판정 경계를 살피는 진단치이며, 모델의 일반 정확도나 전체 RAG 답변 정확도를 뜻하지 않는다. unlabeled historical 사례는 정답 라벨이 없어 정확도 계산에 포함하지 않는다.

전체 280문항 본평가에는 **advanced 프로필만** 사용한다. 전체 280문항 `default` 결과 행이나 default/advanced 전체 비교는 존재하지 않는다.
